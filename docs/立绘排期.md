## 四、每批固定 SOP（自动执行，无需逐步确认）

1. **建档**（缺档案时）：3+3+2 波次 fresh 子代理穷尽提取 → `analysis/着装档案/<人物>-着装档案.md`；身份甄别（泛称/位阶混入即剔）；原文不回流。
2. **蒸馏**：4+4 波次，每代理只读自己档案 + 李周巍基准（prompt/checklist）；产出 `<id>.prompt.txt` + `<id>.checklist.md`；强制携带防复发纪律（正向描述/连鞘/颜料肌理/场景落点/末尾风格锚/静态时刻）。
3. **生成**：`gen-batch.mjs` 补 slug 串行出图（自动去水印），服务掉线自动重启。
4. **盲审**：一人一图一清单独立子代理，verdict 落 `reviews/<id>.r<N>.md`。
5. **整改**：mustFix 发回原蒸馏代理定向修订（结构性问题直接改合同/去X化）；重生→复审，单图上限 5 轮，超限挂起转人工不阻塞批次。
6. **入库**：转 1024px PNG 三副本 → images.json 白名单 → sync-data → vite build → 全量测试 → 台账登记。

## 五、自动执行纪律

- 批内每步产物先核存在再进下一步（前科：蒸馏代理虚报落盘、后台任务中途截断）。
- 高危材料簇触发 1301 即整簇隔离转人工（SKILL 规则 13），不重试。
- 任何一步的失败重试不静默吞——失败留痕，批次继续其余人。
