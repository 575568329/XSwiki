## 二、各视角独有关键发现

- **读者**：势力卡脉络带是全书最高级剧透却在最浅层级（P0-2）；修为以终局展示=对进度读者既是剧透也是错误答案（P0-4）；速答缺第三要素"最近出场章"；t2 有 240 条硬截断句比空白更伤；补 7 个遗漏场景（生死直达/支脉branch字段/诨号进aliases/按首现章浏览/双人对照/最近查看/**进度游标线**——时间带加这根线是"好看变好用"的关键）
- **前端**：file:// 四条硬约束（ES module 不可用/pushState 抛异常/动态import禁用/hash不跨会话）；**两个现有 bug**（Esc 返回死代码、uTools 搜索 searchBlob 与浏览器 fallback 行为不一致）；世家纵表真实规模仅 90-270 节点（797 是误判）HTML 纵表为主图为辅；给出 10 文件拆分结构与 7 步迁移路径（v2 全量 7-10 人日）
- **数据**：plugin/data 是构建产物——**LLM 产出必须落 analysis overlay 再 build 合并，否则下次重建全丢**（P0-1）；t2 stages 只能锚定到 chunk 粒度（±66章）需 chapterApprox 标记；role 判定规则写实（"仅提及"是 chunk 局部语义不能当全局 role，戚览堰实证）；cultivation 要"拆四"不是清洗（cultivationNow/ Stages/immortalBase/divineArts），境界枚举表先定稿；faction 实际 22 值归一为 ~17 实体而非 13；W0 数据卫生批次是硬前置 + 完整验收清单（stages 区间校验/防编造抽检法）
- **生图**：CogView-4 无 seed/img2img/负面词字段——一致性只能靠逐字复用基调串+锚前置+采样2张取优；同人判定用"两图同送4.5V打分"当参考图验收；现 lizhouwei.png 是 JPEG 字节挂 .png 名；**尺寸口径实为 720x1440 非文档的 864x1152**；水印方案=构图预留脚下边距+批量裁右下6-8%；三基调对比测试方案已可执行（李清虹/李周巍/崔决吟 ×3基调×2采样=18张+40次4.5V质检）
