## 三层拼装方案评估

### 1.1 实证：服从度衰减已经发生，且与位置完全相关

6 张样图 prompt 的实际结构 = 长基调前缀（约150字：构图/质感/画风）→ "：" → 人物段（appearance+identity，截断80字）→ 负面词。QA 结果与 token 位置严格对应：

| prompt 位置 | 内容 | 执行结果 |
|---|---|---|
| 最前 ~150字 | 全身/头脚完整/单人站姿/写实质感 | 6/6 全部执行——前部权重高 |
| 尾部 ~80字 | 人物外貌锚 | 大量丢失：李清虹"白毫九寸"完全缺失、杏眼画成凤眼；李周巍"金灿灿的血"画成红血（QA 原话"人设灵魂，错误等同于废稿"） |
| 最末尾 | "没有水印、没有印章、没有落款、没有签名" | 全部失效：右下角印章 6/6 存在；李周巍另有左上"袁桐"汉字乱入 |

结论：**CogView-4 对长 prompt 存在明显的前部优先/尾部衰减，正向位写否定句基本无效，且枚举"印章/落款/签名"概念疑似反向注入**（"袁桐"手写签名与 prompt 反复提及"签名/落款"高度相关）。§9.3 把基调前缀放最前、人物锚放中后的拼装顺序，恰好把最不该丢的东西放在最弱的位置。

### 1.2 拼装顺序修订（核心建议）

prompt 四段重排，总长硬上限 **200 字**（现状约 230–260 字）：

```
[基调短语]   ≤20字，全员逐字一致，只允许一个风格体系的词
+ [固定锚]    人物特征锚 1-2 条置顶（最重要锚放最前），原文逐字复用
+ [阶段增量]  年龄感/服饰/场景差异，无则整段省略
+ [构图画质]  全身/单人/站姿等不变项，压缩为一句话
+ [负面极简]  "画面无文字"一句封顶，删除 印章/落款/签名 枚举
```

三条配套规则：

1. **基调短而唯一**。现前缀同时含"写实摄影级质感""电影级自然光影""水墨云雾"三种互相矛盾的画风指令，模型回落到自身先验（新国风二次元厚涂）——这就是"提示词目标工笔水墨、实际产出厚涂"的直接原因之一。基调拍板（A/B/C）后全串只保留一个体系的词。
2. **同义强化**：每人的 P0 锚允许在句中换一种说法复述一次（如"暗金瞳孔，眼中金红流光流转"），低优先锚不重复，以此控制总长。
3. **度量可视化**："头顶白毫九寸"的"九寸"是文言度量，模型无法执行——改写为"眉心垂下一缕白色长毫，长约及眉"。所有长度/数量换算成画面可执行描述。

### 1.3 锚点预算（对抗衰减的取舍规则）

单张图可执行锚 **≤4**：固定锚 2（跨阶段复用）+ 阶段锚 2。李清虹现 prompt 实塞了 杏眼/红唇/纤手/白毫/杜若枪/鹿皮靴/中年/雷霆 共 8 项，QA 显示只活下来 1 项（雷光，因为视觉最显著）。取舍标准：固定锚只选"丢了就不认人"的（瞳色/异象/标志物），装饰性细节（纤手/靴子）放弃或降级为阶段锚。

### 1.4 多角色一致性的真实结论

- 风格统一（8/10）已由"逐字相同的模板串"达成，这条路有效，保留。
- 但 CogView-4 API **无 seed 参数、无独立负面词字段、无图生图**，跨角色一致性只能靠：逐字复用基调串 + 全员个人 palette 色彩词（避免"人人黑白灰道袍"的均值化，palette 写入 visualLine）。
- 人物身份一致性靠 1.2 的锚前置 + 1.3 的锚预算，而不是靠再加长 prompt。

### 1.5 同人多阶段一致性（`{id}-stg{n}`）

仅靠固定锚文本：**必要但不充分**。增强手段按性价比排序：

1. **基线原文复用**：stg 图 = visualLine 固定锚原文逐字 + 阶段增量；绝不改写基础句（任何改写都是漂移源）。
2. **只动三类变量**：年龄感/服饰/场景。构图、背景、palette、锚的顺序在所有阶段完全一致。
3. **每阶段采样 2 张取优**（无 seed，方差只能靠采样覆盖）；t1 每人 ≤3 张阶段图——数量越多漂移越显性。
4. **验收加同人判定**：把 `{id}.png` 与 `{id}-stg{n}.png` 两图同送 GLM-4.5V，问"是否同一人物的不同时期，1-10 打分"，<7 重抽。这是没有图生图时最实际的"参考图"用法——**参考图不参与生成、参与验收**。

图生图/垫图：CogView-4 官方 API 不支持 img2img（`/v4/images/generations` 仅收 prompt+size）。外部垫图（通义万相/即梦/SD）会破坏"单管线+零网络依赖插件"原则，不建议进 v2。

命名与验收：`{id}-stg{n}.png` 可用，但建议直接 `{id}-{stageId}.png`（如 `liximing-stg2.png`，与 §9.1 schema 的 `stg-2` 对齐，避免 n 与 stages 数组下标错位）；配套 sidecar `{id}.json` 记录 promptHash/基调版本/QA 分/采样张数，回归对比与批量验收都依赖它。

### 1.6 质检核对表模板（GLM-4.5V base64）

现状问题：`qa-vision.mjs` 是自由评论+总分；`gen-images.mjs` 内嵌 `qa()` 只回一个总分——**丢掉白毫的李清虹图只要总分≥7 照样入库**。改为结构化核对表（GLM-4.5V 强制 JSON 输出）：

```jsonc
// analysis/qa/{id}.json
{
  "id": "liqinghong", "tone": "A", "file": "plugin/data/images/liqinghong.png",
  "promptHash": "sha1前8位",
  "style":  { "hit": "新国风厚涂", "score": 8 },          // 与拍板基调串比对
  "anchors": [                                            // 直接来自 visualLine.anchors
    { "t": "眉心白色长毫垂至眉下", "w": 3, "pass": false, "seen": "无" },
    { "t": "琥珀色杏眼",           "w": 2, "pass": true,  "seen": "细长凤眼" }
  ],
  "checks": { "fullBody": true, "hands": false, "text": true, "watermark": true },
  "sameFace": null,                                       // 仅阶段图填：与基线同人判定 0-10
  "score": 5.5, "verdict": "reject"
}
```

QA prompt 要点：

- 锚点逐条给定义并要求"✅/❌ + 图中所见"（如"白毫=眉心长出的白色毫毛，非头饰"），防止 4.5V 不识术语；
- 最后强制输出可 parse 的 JSON；
- **一票否决**（独立于总分）：任一 w=3 锚 fail / 多指畸形 / 文字乱入 → 直接 reject。现 PASS=7 一维分制已实际放行过丢锚图；
- `gen-images.mjs` 的"重试1次取高分"逻辑保留，但判定改由核对表驱动。

### 1.7 水印与文字乱入处理

事实：右下角平台印章 6/6；李周巍另有左上"袁桐"手写体乱入。三个方案：

| 方案 | 评估 |
|---|---|
| **裁切（推荐）** | 构图侧配合：把"双脚踩地位于画面底部"改为"脚下留出约一成画面边距"（当前脚贴底边，直接裁会切脚），产出后统一脚本裁右下+底部 6–8%。确定性、零额外成本、可全量批处理 |
| 接受 | 仅当明确把印章当平台签名；不推荐——另有随机汉字乱入不可控 |
| 局部重绘 | 无 img2img API，外部工具破坏管线，v2 不做 |

预防侧：负面词收缩为"画面无文字"一句，不再枚举"印章/落款/签名"（枚举即概念注入）。

## visualLine 模板修订

### 2.1 现句式缺口

现模板"性别年龄+服饰+2-3外貌特征+标志物"缺四类信息，QA 已付学费：

- **神态/气质**：李清虹被画成"魔门妖女"而非宗师、李周巍"倔强少年"而非魏王——6 份 QA 中 4 份气质错位，这是最大缺口；
- **个人色彩倾向 palette**：全员深色道袍 → 均值脸，多人不可分辨；
- **身形**：高瘦/壮硕/苍老单薄（萧初庭的"苍老单薄"就是有效身形词）；
- 构图/视角：**不建议进 visualLine**——属全局层（全员一致），塞进来只会膨胀句长；表情并入"神态"一条即可。

另有两个数据病：

- 幼时/成年外貌混写一句（李曦明只有幼时描写却被拿去生成成年像）；
- 事件性描述混入外貌（"负伤时流出金灿灿的血"是剧情事件非常态外貌，进了 prompt 就只会生成带血战损图——李周巍 QA 证实）。`gen-portrait-prompts.mjs` 对空 appearance 的兜底句"束发道袍，腰间佩剑"属程序性编造，同样违反 §9.1 硬规则。

### 2.2 t1 信息密度审计（24 人实测）

"23/24 有 appearance"≠"23 人可生图"。实测三档：

| 档 | 人数 | 人物 | 处置 |
|---|---|---|---|
| 充分（≥3 可视锚） | 15 | 李清虹/李曦峻/萧初庭/李阙宛/崔决吟/李绛迁/杨锐仪/李尺泾/刘长迭/萧归鸾/陈冬河/李木田/李项平/李遂宁/李周巍 | 直接生图（部分需先挑阶段） |
| 稀薄（1-2 锚） | 6 | 李曦明（仅"幼时眸子透亮"11字）/李通崖/李玄宣/李曦治（成年未着墨）/李渊修（仅幼时行为）/陆江仙（镜→白衣男子，特殊形态） | 降级（见 2.5） |
| 无据/非人形 | 3 | 安鹧宇（"素材无容貌描写"）/李渊蛟（appearance 空）/备海龙王（生灵） | 不生成或独立分支 |

### 2.3 新模板（schema + 合成句式）

```jsonc
"visual": {
  "level": "full | partial | none",        // 证据等级，驱动 UI 生图入口与降级策略
  "line": "…",                             // 拼装用整句，≤60字，由下列字段按序合成
  "anchors": [                             // 固定锚（跨阶段不变），按重要性排序
    { "p": 0, "t": "暗金色瞳孔，金红流光" }, // p0=丢了就不认人（QA weight=3）
    { "p": 1, "t": "眉心白色长毫垂至眉下" }
  ],
  "palette": ["暗金", "玄黑", "月白"],      // 个人主色 2-3 个
  "aura": "沉静威仪",                       // 神态气质 4-6 字
  "build": "高瘦挺拔",                      // 身形，无据留空
  "form": "human | spirit | beast"         // 人形/器灵/灵兽，走不同模板分支
}
```

`line` 合成句式（顺序即权重）：**性别+年龄段 → 身形 → 神态 → 发型发色（如据）→ 服饰形制与主色 → 固定锚1 → 固定锚2 → 标志物 → 异象（至多1）**。

### 2.4 三个示例

1. **李清虹**（full，中年基线）
   anchors：[p0 "眉心一缕白色长毫垂至眉下"、p0 "琥珀色杏眼"、p1 "手持素杆红缨长枪"]；palette[月白/棕/银]；aura "端庄慈严"；build "高挑健朗"
   line：`中年女修，高挑健朗，神态端庄慈严，月白镶棕边劲装束发，琥珀色杏眼含威，眉心一缕白色长毫垂至眉下，手持素杆红缨长枪，发梢衣角隐有细碎银色电光`
   （红唇/纤手/鹿皮靴按锚预算让位；雷霆是唯一异象位）

2. **李曦明**（partial，降级到少年期——成年无据，挑证据最多的阶段）
   line：`十二三岁少年修士，身形清瘦，神态沉静好奇，靛青道袍束发，双目乌黑透亮有神`
   （"眸子透亮"是幼时描写，就把立绘定在少年期，UI 标注"少年期"；不补写任何无据服饰细节）

3. **李周巍**（full，王侯期阶段）
   anchors：[p0 "暗金色瞳孔，瞳中金红流光"、p1 "玄底金蟒纹王袍"]；palette[玄黑/暗金/朱红]；aura "睥睨沉雄"；build "肩宽魁伟"
   line：`青年男修，肩宽体魁，神态睥睨沉雄，玄底金蟒纹王袍束玉冠，暗金色瞳孔中金红流光流转，负手而立`
   （"负伤流金血"从 visualLine 剥离，仅进特定剧情图）

### 2.5 降级策略（建议写进 §9.1）

- **L0 full**：锚≥3 → 正常立绘；
- **L1 partial**：锚 1-2 → 二选一：a) 换阶段——挑视觉证据最多的生命阶段生成（李曦明→少年期）；b) 弱化构图——背影/远景 + 标志物，不编脸；UI 标注"少年期"或"远影"；
- **L2 none**：无据 → 不调 CogView；UI 隐藏生图入口，或用统一矢量剪影占位（非 AI 生成，杜绝"看似官方设定"的误导）；
- **form≠human**：备海龙王走"东方龙形"分支、陆江仙走"古镜+白衣人影"分支，禁套"明代服饰形制考据/双脚踩地"模板。

## 基调对比测试方案（可直接执行）

目标：A/B/C 同台对比产出 3×3 看板供拍板。**变量控制**：同一人物用同一份新模板 visualLine（2.3 版重写）、同一拼装顺序（1.2 版）、同尺寸 720x1440；唯一变量 = 基调串。每人每基调 2 张采样（无 seed，以采样估方差）。总量 3×3×2 = 18 张 + 约 40 次 GLM-4.5V 调用，成本可忽略。

### 选人（全部 L0 证据充分，排除人物因素干扰）

- 李清虹（女，锚最多；白毫是画风敏感特征——水墨/工笔下浅色细节是否还能立住，是关键观测点）
- 李周巍（男，暗金瞳+金红流光，色彩倾向极强，测重彩/淡彩对金属色的处理）
- 崔决吟（男，儒雅+墨笔，测"淡雅系"人物在三种基调下的区分度）

### 三基调串（基调层逐字固定，其余段完全一致）

```
A 新国风厚涂（现款基线，已验证稳定）
   新国风厚涂插画角色立绘，笔触厚实饱满，色彩通透，柔和体积光

B 水墨淡彩
   水墨淡彩人物立绘，生宣纸肌理，毛笔线条勾勒，墨色晕染，淡彩敷色，大量留白
   （注意：与"全身占画面三分之二"构图存在张力——留白要吃画面占比，看板重点看构图是否被压缩）
```
