# 画像卡子代理提示词模板

用法：每代理读 4 份 dossier 素材写 4 张卡。dossier 由 `dossier.mjs` 生成（首现 3 章全句 + 高密度 12 章抽样 + 末现 2 章）。

```
你在为《{书名}》（{题材}）人物数据库写档案卡。逐一读取以下素材文件（每个是一份人物的出场句摘录，含章节号）：
- {工作目录}/dossiers/{人名1}.md
- {工作目录}/dossiers/{人名2}.md
- {工作目录}/dossiers/{人名3}.md
- {工作目录}/dossiers/{人名4}.md

对每个人物，把档案卡写到 {工作目录}/cards/{姓名}.json（UTF-8），字段：
{
  "name": "姓名", "tier": 1, "aliases": ["别名/道号/称号"], "importance": "major",
  "gender": "男|女", "identity": "身份", "faction": "势力",
  "generation": "{家族字辈世代；非家族为空串}",
  "cultivation": "{境界/实力（最高或最终状态）}", "status": "在世/陨落/未知（有明确证据才填）",
  "oneLiner": "一句话概括",
  "persona": { "appearance": "外貌综合", "personality": ["3-5词"], "motivation": "核心动机", "arc": "人物轨迹2-3句" },
  "relationships": [{"name": "姓名", "relation": "关系（含方向）"}],
  "timeline": [{"chapter": 章号, "event": "关键事件一句话"}],
  "evidence": ["原文逐字摘录，最多3条，每条≤80字"]
}
硬性要求：
1. 只用素材里有证据的信息，不确定的字段留空/空数组，禁止编造。
2. timeline 按章号升序 5-12 条，事件必须具体（谁做了什么）。
3. relationships 只列素材中明确出现的人。
4. 若素材显示陨落/身死，status 填陨落并记入 timeline。
完成后只回一句：done 共X张卡
```

产出校验（node 一把过）：
- JSON 可解析、必备字段齐全（name/tier/oneLiner/relationships/timeline/evidence）
- timeline 章号严格升序
- evidence 每条 ≤120 字
- 主角卡 importance=protagonist

生图提示词与质检（写实立绘实战，CogView + GLM-4.5V，2026-10 验证）：

- **统一基调模板**（画风段全人物一致，只换人物段）：
  `中国古装写实人物全身像，全身远景构图，单人站姿，人物从头到脚完整呈现：头顶位于画面上部、双脚踩地位于画面底部，全身与鞋履完整可见，占画面高度三分之二以上，写实摄影级质感，真实面部结构与皮肤纹理，电影级自然光影，明代服饰形制考据，深色淡雅背景微带水墨云雾远山，构图庄重简洁：{男/女}性修士，{外貌+身份特征}，画面纯净，背景与服装上没有任何书法字、题诗、题字、落款、印章、签名、水印`
- **踩坑**：
  1. 提示词里**不能有人名**——CogView 会把名字画进图里
  2. CogView-4 的 API **不支持 negative_prompt**，负面清单只能正向反向表达（"没有任何书法字"比"无文字"更压得住写实风自带的题字冲动）
  3. 竖长画幅(720x1440)默认出**胸像**，必须用"头顶位于画面上部、双脚踩地位于画面底部、占画面高度三分之二以上"三重锚定构图
  4. 玄幻特征（金瞳/金血）在写实倾向下会被压掉，接受妥协或单独手写强化
- **免费方案**：cogview-3-flash 完全免费且写实人像质量 ≈ cogview-4 的 85-90%（8.7 vs 10 分），支持 768x1344 竖版；批量首选免费模型
- **视觉质检**：`qa-vision.mjs` 模式 = 直调 glm-4.5v API + **base64 直传**（`data:image/png;base64,...`），无需图床无需 URL。注意：glm-4.5v-flash 模型名不存在，用 `glm-4.5v`。质检 prompt 要给**评分锚点**（基础5分+扣分项）减少打分波动，重要图再加一次自由评审交叉验证
- **uTools 的 4_5v MCP analyze_image 工具不可用**：它的拉图链路只对智谱自家可达域名有效，第三方 URL（含 github/baidu/127.0.0.1）一律 1210"图片输入格式/解析错误"——直接走 API
