# dbst (DBST) — 小说成名场景/人物插图生成（doubao2api 管线）

一句话流程：**起服务 → 扫码登录一次（持久）→ 原文取"成名场景" → 查着装档案（优先成年阶段）→ 按小说类型适配画风组装提示词 → 生成+去水印 → 独立盲审 → 用户终审**。
参考实现脚本：`scripts/gen-portrait.mjs`（health / t2i / i2i 一条龙：b64_json 取图→落盘→自动去水印，优先用它，别手写 curl 重踩坑）。

## 一、前置：服务状态与登录

```bash
cd tools/doubao2api && ./.venv/Scripts/python.exe -m doubao2api   # 后台常驻
curl http://127.0.0.1:9090/auth/status   # logged_in:true 且 is_ready_flag:true 才能用
```

- 长驻用 PowerShell 分离进程（会话后台任务跨回合会被回收）：`Start-Process -FilePath <venv python> -ArgumentList '-m','doubao2api' -WorkingDirectory <tools/doubao2api> -WindowStyle Hidden`，接着用时先 curl 健康检查。
- **登录**：浏览器开 [http://127.0.0.1:9090/admin](http://127.0.0.1:9090/admin) 扫码面板（已打补丁：二维码过期自动换新码、确认失败自动重试≤5 次）→ 豆包 App 扫码。**静态截图贴码 2 分钟作废，别用**。
- 登录态持久化在 `~/.doubao_browser`：重启服务不掉登录，只有豆包云端踢会话才重扫。生成偶发 `502 No images generated` → 直接重试即可。

## 二、生产主线：成名场景图（2026-10-23 用户定稿）

**不做定妆照/影棚摆拍**。每个重要角色的产出 = **成年阶段 + 成名场景**（书中最具辨识度、让读者一看就想起"这是第几幕"的场景）。人物图允许是场景中的定格式站姿，但必须带场景语义（环境/天气/时刻），禁止纯棚拍背景。

### 1. 原文取景

在 `plugin/data/text/<书id>/t*.json`（每章 `{n:章号, t:标题, x:正文}`，json 对象键为序号；玄鉴原文块已按版权拍板删除，重取走 `analysis/doupo/fetch-book-text.mjs` 落 analysis/<书>/text/，只落盘不入库）中检索：**人物名 + 标志动作/兵器 + 环境词** 同段共现（如"李清虹+枪+雪/月/院"），段落长度 30~300 字、画面要素（环境/时刻/动作/道具）越全越好。样例见 `analysis/生图测试/场景*.jpg` 对应的 #204/#211 段落。

### 2. 着装档案（`analysis/着装档案/<人物>-着装档案.md`）

- 格式样板：`analysis/着装档案/李清虹-着装档案.md`——按**年龄/人生阶段**从原文汇总外貌/着装/兵器/神态，只记原文写过的，标注章节号可回溯。
- **优先成年阶段**：能确定角色成年后外形就生成成年后（用户定稿）；童年/少女段仅当场景本身发生在该年龄段时使用。
- 回退规则：场景原文有外貌着装描述 → 用场景原文；没写 → 按人物当时年龄从档案就近取。

### 3. 画风适配（该奇幻奇幻该玄幻玄幻该科幻科幻）

**首选：handraw-style 风格库垫图（2026-10-26 定稿）**。从 `tools/handraw-style/skills/handdraw-style-prompter/references/styles.json` 按角色气质选**风格编号**（366 个，各配库内参考图 `tools/handraw-style/images/individual/<首字母>/<编号>.webp`），出图走 **i2i 垫参考图**；提示词带该编号的双语正向特征 + **风格隔离声明**（"参考图仅用于提取笔触/媒介/色彩，不得延续其画面内容与人物"）。模型校准表里没有豆包 → 按 unknown 兜底（全特征+垫图实测有效）。**同书锁定同一编号，换=全书重出**。

| 小说类型 | 现用编号 |
|---|---|
| 玄幻/仙侠/古风（玄鉴仙族 ✅） | **FE-013 伊吹五月·Freehand Ink-Wash Ancient Figure**（水墨古风人物，`images/individual/FE/FE-013.webp`） |
| 其他类型 | 建新书时从库内按气质另选，登记在此 |

**fallback（无参考图场景）**：技法底盘统一为**半写实厚涂/概念艺术插画**（与真人保持距离、不过度坐实原文、给读者想象空间），文化氛围词按小说类型换装。

| 小说类型 | 画风定位块（句式模板） |
|---|---|
| **玄幻/仙侠/古风** | `国风厚涂插画，半写实厚涂画风，油画式笔触，无描线，体积光影厚重，国风游戏CG质感` |
| 西方奇幻 | `史诗奇幻概念艺术，油画厚涂笔触，戏剧性体积光，魔幻质感` |
| 科幻 | `科幻概念设计，电影概念图质感，硬表面工业细节，体积光雾，冷色调` |
| 都市/现代 | `电影感写实插画，影视剧照构图，自然光，细腻胶片质感` |

氛围词随类型换：仙侠用"云海仙山/灵气粒子/月华寒霜"，科幻用"星舰残骸/全息光影/尘埃粒子"……只换氛围与场景词汇，**结构与品质词不变**。

### 4. 提示词组装模板（槽位化，顺序实测有效）

```
[画风定位块]，[全身立绘正面站姿/场景构图]：
[人物：档案成年阶段——年龄感/眸子眉眼/气质/发型发饰]。
[着装：档案或场景原文，逐件列出]。
[道具：正向描述法，见下]。
[场景：原文要素直译——环境/天气/时刻]，[氛围：该类型氛围词]。
[光影：体积光/逆光轮廓等]，[画质：超高细节，发丝级细节]。
```

**兵器/道具正向描述法（实测定稿，全风格通病"双头枪"的唯一有效解）**：
- ❌ 否定式约束（`另一端不是矛头，是枪镦`）→ 3/3 失败；❌ 图生图定向修结构 → 木杆仍削尖+背景瑕疵
- ✅ 只正向描述每一端是什么、用常见意象：`她拄着一杆普通的长枪：枪杆是一根通直完整无断裂的白腊木杆，整支长枪全部在画面内；只有向上的一端装有金属矛头，矛头下方垂着一束红缨；向下的一端（握把尾端）没有任何金属件，只是用白色布条缠绕收口的木杆，握把尾端点地。`
- 其他兵器/道具同理：只说每端是什么，不说"不是什么"；生僻词（枪镦）模型不认识。

## 三、验证 SOP（生成者自查不算验收）

**审计教训**：同题四风格样张，生成者自查判两图道具正确；独立盲审发现 **4/4 全部**枪尾偷加矛尖（两处假阳性）。同一会话看自己的图存在系统性漏检。

1. **要素清单**：从档案+场景原文生成 ~10 项可判定清单（年龄感/着装/发饰/兵器形制/背景/画质），硬性条款一票否决；条款精确到无歧义（如"另一端只允许平钝枪镦/布条收口，尖锐矛头状即 fail"）。
2. **独立盲审**（二选一）：fresh 子代理 Read 图+清单逐项 pass/fail/partial+证据，整体 accept/reject；或 glm-4.5v API（`skills/novel-characters-db/scripts/qa-vision.mjs`，需智谱 key，评分锚点 <7 重试）。
3. **缺陷率结论 n≥3**：换风格/参数/提示词后至少出 3 张再下"某错误高发"结论。
4. **定向整改**：单项 fail → 只补对应约束词重出；随机伪影（断裂/裁切）→ 补完整性词重试，不改提示词结构；**面部微特征/随机伪影类也可直接"重摇骰子"**——同提示词原样再出 1~2 张（生成便宜，模型有随机性），比改词快且不引入新变量。
5. **人工终审保留**：独立评审通过后，图与原文/档案并排交用户终审。

## 四、硬性规则（每条实测踩过）

1. **原文忠实 > 华丽 > 跨图一致性**；着装器物季节以场景原文为准，场景没写查档案按年龄取；华丽词只渲染光影氛围，不得改变设定。
2. **同书同模型同风格**；换风格=全书重出。
3. 中文 JSON 走文件/Node fetch；Windows curl `-d '中文'` 会编码损坏。
4. 参考图（i2i 时）先压 ~1024px/~100KB，否则豆包 `params invalid`。
5. 水印只有 `remove_wm.py` 一条路（CDN 模板签名绕不过、重叠合并无变体可用）；去水印图仅个人展示用，公开传播保留 AI 标识。
6. 生成 12~25s/张，超时 ≥170s；RPM 30；偶发 502 重试即可；**批量生成前当场 `curl /auth/status`，缓检不算数**（2026-10-27 实锤：健康检查 40 分钟后服务已掉，8 张全部 fetch failed 空转一轮）。
7. 出图必须过 §三 独立盲审，人工终审保留。
8. **先验对抗不过就顺势改合同（2026-10-26 二批实证）**：生成模型对「画面中有剑=必须拔出」「长柄兵器=矛」「虎=橙黑」「镜面=要刻纹映物」的先验极强，否定式/计数式约束压不住时（连败 2 轮），直接改姿势合同（按剑→连鞘拄剑）或删元素（去剑/去镜/去锏化），识别锚点在人脸着装场景，不在单件兵器；「玄虎」这类深色名直接改叫「霜白巨虎、虎纹淡金」。**场景词同样自带道具先验**（2026-10-27 B7-B9 实证）：「站台」召唤铁路（赫蒂 4 轮）、「酒馆」自带门楣招牌（克莱恩 4 轮）、「马戏团」人群两轮不散（梅丽莎）——对抗手段=换该人物的**候选场景**（赫蒂→加冕观礼、克莱恩→码头虚化光斑、梅丽莎→教堂仪式），换景即破局，别在原场景里烧轮次。
9. **兵器长度是模型真正理解的判别特征**：锏/鞭类短兵器写「二尺、仅及手臂长短」仍 4/4 画成长杆尖锋——短兵器类直接放弃入画；立绘兵器优先剑/枪/弓（样本充足，弓修一轮过）。
10. **高能量场面把画风推向 CG**：爆炸/击打瞬间/电光劈落/金光横扫天际等词会盖过风格块（3 轮不改），改写为阵后余韵类静态时刻 + 在提示词**末尾**（权重位）重复一句全图水墨手绘锚，立竿见影。
11. **风格块须含「颜料肌理」句且构图块后补场景落点**：缺颜料肌理句=照片漂移；占比近满幅/脚出画=补「人物在画面中占比收小、脚下<具体地面>完整可见、袍摆与双脚全部入画」。
12. **清单是合同，可校准**：面部微特征（颊疤/精确年龄感）模型 3 轮画不准时降 [软]（先例：陆江仙颊疤）；识别锚点全亮的图按校准后清单复审即收，单图轮次上限 5，不为单点微特征无限烧轮次；超限转人工，人工拍板换画法后按新画法再给 1-2 轮（先例：赫拉伯根第 6 轮根除眼部先验）。
13. **GLM 上下文敏感簇隔离**：李曦明材料的档案/清单/成图对 GLM 过滤器单测均触发 1301（文本与视觉都炸），同批其余 12 人全部安全——某人物材料炸过一次，整簇（档案+清单+成图）列入隔离名单不再进任何 GLM 上下文，其盲审转人工。
14. **违禁物词根零出现（含场景命名与否定句）**（2026-10-28 奥黛丽案）：场景名「烛光宴会厅」+「不出现任何灯具、烛台、吊灯」的否定列举，3 轮召出火苗烛台；根治=提示词里「烛/灯/吊/火」字根一个都不许出现，光源只写「暮色般的柔和暖光自四野弥漫、光的来处隐于画外」。**否定式反噬的完整形态：被禁物连名字都不能提，被隐藏物连部位都不能提**。
15. **光源写光路，不写光效**（2026-10-28 欧弥贝拉/赫拉伯根案）：只要提示词出现「灯光/马灯/壁灯」等发光体名词，必画出灯体实体甚至光柱（欧弥贝拉壁灯、赫拉伯根鼻梁受光显五官）。正确写法三件套：①删发光体名词，改「殿堂深处漫出柔和光晕，如空气本身在微微发亮」；②写光线落点（「光只落在袍身褶皱与白须的外侧」）；③需要暗部吞噬细节时写光路排除（「帽檐之内没有光线进入，兜帽内部如剪影般纯黑不反光」）——赫拉伯根 6 轮眼部先验即靠此根除。
16. **器官名词只许在正向描述出现**（2026-10-28 欧弥贝拉案）：「襁褓之外不出现婴儿的面孔与手足特写」一句直接召出婴儿脸；正确=只描述可见物（「层层布料缠绕系紧，视线所及只有布褶与系带结扣」），被隐藏对象（面孔/手足/婴儿）零提及。
17. **图像学先验不可对抗，改清单随语义**（2026-10-28 赫拉伯根案）：「全知之眼=睁眼+虹膜瞳孔」是整个训练语料的图像学共识，清单要求「闭合眼睑造型」3 轮全败——凡与图像学语义冲突的器物要求直接随语义改清单，别烧轮次。同案沉淀**先验破局动作序列**：改姿势合同→删元素→换画法/视角/光路（兜帽+老者=露眼 4 轮不可逆，「整脸沉入纯黑剪影+光路排除」一击根除）。
18. **人工收货=第三条合法入库路径**（2026-10-28 挂起清账定式）：挂起项交用户三选一——看图收货 / 放弃 / 拍板新画法（新画法=清单条款同步修订后重生 1-2 轮）。用户口头决定记 `analysis/立绘成品/人工验收.json`，audit.mjs 视人工收货与盲审过审同级（含 1301 隔离图的无盲审记录收货）。
