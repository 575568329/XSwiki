# 李曦峻 · 筑基出关（松上雪踏雪而来）立绘 · 盲审清单（去剑版）

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄与容貌：青年男性修士，面相二十余岁，冷清俊美、肤色极白、唇红齿白，无少年稚气、无老年衰相。
2. [硬] 瞳色：双眼眸子为明亮灰白色——浅灰如覆霜之雪、清透发亮、眸光如霜雪映日，是面部最醒目的焦点；瞳色画成黑/深灰/棕/暗红棕/金/蓝等任何非明亮灰白之色即 fail。
3. [硬] 眉眼锚点：剑眉星目可辨，与灰白眸子共同构成面部识别点；眉毛形态与眸色冲突（如浓黑粗眉压暗眼神）即 fail。
4. [硬] 白衣主体：一袭素白长袍为绝对主色，轻软丝缎质感，衣缘袖口有银线滚边与疏朗抽象纹样；主色画成黑/红/金袍或画成铠甲布甲即 fail。
5. [硬] 腰饰：腰束素白丝绦，垂一枚温润圆形玉佩；无腰带或无玉佩即 fail。
6. [硬] 无兵器：画面中不出现任何兵器，剑/刀/矛/弓等一律不得出现；两手交叠拢在袖前、左手轻扶身旁低垂的积雪松枝，手中、腰间或身侧任何位置出现兵器即 fail。
7. [硬] 场景要素：高山雪峰之巅、漫山霜雪、压雪雪松、足底薄雪云、周身霜雪寒气、远处云海群山——六要素至少呈现五项。
8. [硬] 全身完整与占比：人物头顶到双脚完整入画、无裁切，全身约占画面三分之二，脚下留出一身位空白、脚下雪面完整可见；人物在画面中偏小、四周雪景留白舒朗，占画面近满幅或比例失衡即 fail。
9. [硬] 水墨手绘风格：开头宣纸手绘宣言须落实——可见毛笔笔触、颜料肌理、宣纸纸纹、大面积留白与透明叠染的松软纸上质感；呈现厚涂CG感/照片写实/赛璐璐动画感即 fail。
10. [软] 最小设定宽容：黑发束起插素白发簪、身形颀长清瘦为最小设定（原文未见），形制合理即 pass、不计 fail；仅当出现异色头发、披发狂客或魁梧壮汉体型时作质量提示。
