# A先生 · 聚会屋的阴影主宰（★定型期·皇后区聚会屋召集者）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 兜帽黑袍（恒定装束）：通身一件带兜帽的黑色长袍，厚重呢绒布料、自颈际垂落覆没全身，兜帽帽形偏大略夸张、帽口前倾；袍色画成白/红/深蓝等其他主色、改画披风斗篷或正装短打、或长袍只及膝露出大面积长裤即 fail（档案红线：「身穿带兜帽的黑色长袍」为全书贯穿识别点）。
2. [硬] 阴影覆面（第一识别点）：帽口内为纯黑剪影、无任何肤色与五官痕迹为 pass；帽口内出现肤色、鼻唇下颌轮廓或任何眼睛痕迹即 fail——画成清晰面孔、俊朗男性脸、漂亮妖异宛若女性的容貌同样 fail（妖异真容为备用锚点、血色瞳孔属大雾霾战斗形态专属，本图一律禁用。r2 教训注记：纯「阴影藏面」写法不成立，必须写光路排除——帽檐深深前倾、无任何光线进入帽檐之内、光晕只落肩头袍褶与兜帽外轮廓）。
3. [硬] 沙发翘腿姿态：深坐于会场最前方一张材质一般的单人布面沙发，右腿架于左腿翘腿而坐、身后靠进沙发靠背、一条手臂搭扶手，居高临下俯视全场；画成站立、坐普通木椅、双腿并拢规矩下垂、身体前倾或姿态僵直即 fail（档案锚点：「戴着兜帽，翘腿而坐」「独坐最前方单人沙发」）。
4. [硬] 聚会屋场景要素：傍晚室内隐秘聚会屋——昏黄光晕弥漫（光的来处隐于画外）、材质一般的沙发茶几若干、一块黑板靠墙自立（板面模糊粉笔条目）、远处背对剪影的兜帽长袍客；场景画成教堂、街头、贵族宴会厅即 fail；出现倒吊巨人神像即 fail（神殿元素属私下场景 #258，非本图）。
5. [硬] 无伪文字：全图任何位置无可辨读的文字、字母、名单、题字、印章、徽记符号；黑板板面条目一律虚化成浅白划痕，字迹可辨读（哪怕局部一两个字符）即 fail。
6. [硬] 无灯具器物与焰状光源：画面中不出现任何灯具器物实体与焰状光源——无火焰、明火、烛火、火星、灰烬、自燃特效等任何燃烧元素，室内光照一律为来处隐于画外的均匀弥漫光晕；出现立柱灯、壁灯、吊灯、玻璃灯罩、灯座、灯焰等任何灯具器物实体即 fail（r1 教训：提示词提「煤气灯」即召出立柱灯具＋玻璃罩＋焰状光源，光只可写光晕弥漫、来处隐于画外，提示词全文已无「灯」字根）。
7. [硬] 全场无第二清晰人形：除 A 先生外无任何清晰人形，远处兜帽客一律背对剪影、完全虚化、无一人面向观者；任何配角露五官、面向观者或实色细描即 fail（尤其女性面孔；档案锚点：来客入场一律套兜帽长袍、彼此不见脸）。
8. [硬] 战斗异态禁入：长袍为素净黑色布料——不出现血肉长袍、蠕动鲜血披风、鲜红袍色、血色瞳孔、面部鳞片鳃口、触手、半透明书册虚影及任何神秘学法术特效；出现上述任一元素即 fail（均为大雾霾战斗形态或能力投影 #485-#490，定型期常态不携带）。
9. [硬] 克莱恩系物件区分：不出现礼帽（含手持）、手杖、雨伞、正装马甲、单片镜、金边眼镜、怀表链等绅士佩饰物件；出现上述任一即 fail（档案红线：A先生无礼帽、无手杖、无正装马甲、无单片镜，通身黑袍兜帽为与克莱恩体系的零撞车区分）。
10. [硬] 构图完整与静态：主体全身完整入画，头顶与搭起的鞋尖、触地双足清晰可见，不触画面上下边缘、脚前地面留白；主体连同单人沙发落于画面中央偏前、约占画面二分之一，背景兜帽剪影与黑板约占三分之一并整体虚化；头顶、足部或沙发被裁切即 fail；全画为静态定格，无起身、挥臂、袍摆剧烈翻飞等动态混乱。
11. [软] FH-040 风格锚：精密细腻的钢笔交错排线、暗调羊皮纸暖赭底色、做旧纸纹质感，如一页古老典籍中的整幅插图；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail；不得混入东方古风水墨写意笔触（软性风格提示）。
12. [软] 色彩与气质细节：全画唯一点睛亮色为昏黄光晕的一线暖黄与黑板浅淡粉笔白痕，其余为墨线与深褐、暖赭、沉黑层次，出现其他鲜艳亮色块仅作提示；气质锚为悠闲淡漠稳如山＋兜帽口微侧向某道坐姿端正的剪影方向、透出黏腻而危险的注视意味（神秘与轻佻并存），画成正气凛然或狰狞恶鬼脸谱感仅作提示不计 fail。
