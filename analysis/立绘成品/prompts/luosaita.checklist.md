# 罗塞塔·奥古斯都 · 诸王会议厅的金边黑衣皇帝（★定妆·金镶边黑外套/第378章诸王会议）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 黑发黑眼与深邃平静目光（第一识别点）：黑发浓密、发量丰厚；黑色的眼珠；目光深邃平静、如深潭无波，克制而洞彻——发色画成金/银/棕红、瞳色画成蓝/绿/金/红即 fail；目光画成凶相毕露、狰狞外露或浮夸大笑即 fail（深沉平静为档案锚点，不可戏剧化）。
2. [硬] 下巴胡茬：下巴覆一层短促胡茬；画成光洁无须的嫩脸即 fail，画成浓密络腮大胡子亦 fail。
3. [硬] 身形与面孔：身形消瘦、高瘦挺拔、肩背单薄，画成壮硕魁伟宽肩体格即 fail；面孔阴郁僵硬少变、消瘦面庞、如石雕/冰冷大理石雕刻，约五十岁上下的中年感（年龄为档案推定）；画成青春俊朗小生脸或臃肿老态即 fail。
4. [硬] 金镶边黑色外套（唯一明文着装）：黑色长外套，衣缘/领口/前襟镶一线沉稳收敛的金色滚边，剪裁朴素、几乎可以用朴素形容，朴素之中气势慑人；主色画成白/红/紫、金边漫化成满身华丽金纹刺绣、或改画铠甲军装/教士神职袍/东方长袍即 fail（服饰明文仅【378】一处，金边面积夸大为过度演绎；内衬裤鞋为档案推定自拟，画成其他深色仅提示）。红宝石戒指为可选细节锚：左手一点暗红内敛、右手轻搭摩挲之姿，缺失仅计 partial、不单独否决；画成蓝宝石/翡翠等他色宝石即 fail。
5. [硬] 场景（诸王会议大厅）：高阔庄严的王庭会议厅——深色木质长条会议桌、空置高背座椅、石砌墙面与高阔穹顶隐入幽暗、高处深色彩窗透清冷天光且窗上无可辨纹章、无源式柔和暖光晕；场景画成黑铁王座大殿、书房、宴会厅、战场即 fail（本图取第378章会议厅，非王座厅）；彩窗或墙面出现清晰纹章徽记即 fail（厅内桌椅穹顶陈设样式为合理推定，不作硬性限定）。
6. [硬] 无铠甲（档案红线）：画面任何位置不出现铠甲、盔甲、护肩、胸甲，尤其不得出现"披覆铁灰色铠甲的巨人"形象——那是神之眼显形，严禁当作罗塞塔形态；出现任何甲片或铠甲巨人即整图 reject；亦不得混入骑士、牛角铠甲、石阶遗迹等 FH-040 风格参考残留意象。
7. [硬] 无王冠：他免冠；头部不出现王冠、冠冕、头环、额饰等任何实体头冠——档案中王冠仅"王冠的阴影"、全书无实体细写，画出任何实体冠冕即 fail。
8. [硬] 全局负面（无伪文字/无火焰灯体/无长杆）：画面任何位置不出现文字、题字、匾额、印章、旗帜纹章、徽记符号（出现任何可辨文字或伪文字笔画即 fail）；不出现火焰、火苗、烛体、灯座、灯体等燃烧或灯具实体，厅内光效一律为无源式柔和暖光晕与高窗天光（出现烛台火苗即 fail）；不出现权杖、手杖、长杆类物品与神秘学法术特效（权杖属第1019章火盆审判场景，勿串场）。
9. [硬] 独处红线（无第二人）：画面除罗塞塔外不出现任何其他人物或人影——无其他君王、贵族、卫兵、仆从，无女仆长戴安娜、无皇储玛蒂尔达；长桌旁座椅全部空置；出现任何清晰或半清晰第二人影即 fail。
10. [硬] 构图完整与静态：人物全身完整入画，头顶与双脚清晰可见，双脚不触画面底缘、脚下石板地面留白，头顶或双脚被裁切即 fail；全画为静态定格，无转身、挥手、衣摆剧烈飘动等动态混乱。
11. [软] FH-040 风格锚：精密细腻的钢笔交错排线、暗调羊皮纸暖赭底色、做旧纸纹质感，如一页古老典籍中的整幅插图；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail；不得混入东方古风水墨写意笔触（软性风格提示）。
12. [软] 阴影捕食者·帝王威压：周身一圈沉滞阴暗如散不去、明处暖光身周暗的"与阴影伴生的捕食者"构图，威严沉郁、摄人气势；压迫感不足或画成亲和暖男气场仅作提示、不否决。
