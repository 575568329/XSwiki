# 炫烨王 · 石棺静立（人形真容）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄体态：人物为中年男性修士，身形瘦削挺拔；无少年稚气、无老态龙钟，不臃肿不肥硕；气质威严沉静、不怒自威，无狰狞表情、无夸张怒相。
2. [硬] 高冠：头戴一顶高高的古式玉冠，冠体高耸、轮廓清晰可辨（冠之形制为自拟，样式细节不作否决依据）；无冠、冠矮平塌或仅画普通束发即 fail。
3. [硬] 面容：面色苍白如纸，双目泛着淡淡的暗红色；画成红润健康肤色或正常黑瞳即 fail；面部不得出现獠牙、干瘪凹陷、腐坏纹路、裂纹等任何恐怖特征。
4. [硬] 袍服：身穿玄墨色（深色）宽袖古袍，袍长曳地，形制为上古王侯宽袍；画成甲胄、僧道法衣、现代服装或鲜艳花袍即 fail。
5. [硬] 纯人形：人物为完全人形，呈常态修士模样；不得出现绿色毛发、獠牙、紫黑色长发、紫黑色利爪、额前黑色符文、身形异常拔高等任何尸王原形／变身态特征。
6. [硬] 无血腥无他人：画面无白骨、骷髅、腐肉、尸斑、血迹、断肢等血腥恐怖符号；无干尸、无第二个人物或人影（两侧石棺棺盖严合，不出现开棺露尸）。
7. [硬] 场景要素：昏暗幽深的上古巨墓石室，四壁有斑驳上古壁画；四角各一尊巨大铜缸，缸中燃碧绿色冷焰、焰苗笔直静止；三具巨大石棺并列，中央石棺棺盖斜飞落在棺旁；人物静立于中央石棺前（场景为 #910 静态帧改编）。
8. [硬] 灰白雾气：人物周身萦绕一层淡淡的灰白色雾气，如薄纱缓缓浮动；画成浓黑烟柱、绿色毒雾或火光裹身即 fail。
9. [硬] 静态无兵器：画面为静止瞬间，人物呈静立姿态（双臂自然垂放或拢袖），无打斗动作、无飞散碎石、无能量光效爆发；画面无剑、刀、幡旗、葫芦、宝珠等任何兵器法宝器物。
10. [硬] 全身完整：人物头顶到双脚完整入画、无裁切，全身约占画面三分之二，脚下留有一身位空白。
11. [硬] 无文字：画面任何位置（含壁画、袍面、棺面、铜缸、背景）不出现文字、题字、印章、徽记符号；壁画仅作斑驳图案纹样。
12. [软] 水墨风格与颜料肌理：笔触潇洒写意、有大面积留白与宣纸纸纹质感、透明叠染色调；浓墨见颜料堆叠厚度、淡彩见水痕晕染边缘；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。袍服纹样（暗银云雷纹、深灰滚边）与玉冠形制均为自拟（非原文），细节允许合理出入，不单独否决。
