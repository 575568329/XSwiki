# 安鹧宇 · 白绸殿庆宴（得意宴饮）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄感：人物为五十多岁中年男子，面庞丰润、体态微胖带富态酒色感；画成青年俊朗、少年稚气或龙钟老朽即 fail。
2. [硬] 阶段状态：为得意宴饮期的整肃形象——头发束起、冠带齐整、端坐宝座；呈现披头散发、衣袍冠带纠结凌乱、跪伏惊惶即 fail（此为惊变/末路状态，禁用）。
3. [硬] 神态：面上带着志得意满的笑意，眉眼间有新贵得色的神气；画成惊恐、面色青白、双唇颤、狰狞或哀戚即 fail。
4. [硬] 场景要素：骅山大殿内，人物端坐上首宝座；身前有食案、案上陈酒盏（手中亦举一盏）；殿宇梁间垂挂素白长绸；有金黄雕饰与白玉台阶——主要素缺任一即 fail。
5. [硬] 无血腥符号：全画任何位置无血迹、血水、伤口、白骨、尸骸、刑具、囚具、绳索捆缚；不得出现镶金玉盒及盒中暗红晶片等食人暗示物。
6. [硬] 无燃烧元素：画面任何位置无火盆、汤锅、烛火、明火、火光、火星等燃烧与沸煮元素；殿内光效只允许柔和天光与收敛暖光。
7. [硬] 无文字：画面任何位置（匾额、幔绸、衣饰、器物、背景）不出现文字、题字、印章、徽记符号。
8. [硬] 全身入画：人物头顶到双脚完整入画、无裁切；端坐姿态下双脚皂靴清晰可见、踏于脚踏或地面；四周与脚下留有余白。
9. [硬] 水墨风格：伊吹五月式自由手绘水墨古风，潇洒写意墨线、宣纸纸纹质感、透明叠染、大面积留白；呈现照片写实、厚涂油画感、赛璐璐动画感即 fail。
10. [软] 补全项（服色/冠带/须发）：绛色团花锦袍、泥金团花纹样、镶玉金带、泥金束发冠、黑发短须均为通则补全、无原文依据；画成其他华贵深色锦袍与金冠玉带仅作提示不否决。
11. [软] 画面次序与光色：阶下陪坐宾客以淡墨虚影处理、不喧宾夺主；金彩高光收敛、无刺目光斑；全画静态、无激烈动势。
