# 李渊修 · 冬雪祭坛（冬祭静立）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄与眉目：人物为十八九岁的青年男性，修长的眉毛、眉目清秀、眼角线条温润；无孩童稚气、无中年老态，不得画成凶戾狭目或锋利恶相。
2. [硬] 白色雁羽篷披风：肩披一件通体纯白色的雁羽篷披风，为全身着装主色与画面最亮着装块；披风画成黑/青/红等其他主色，或披风缺失即 fail。
3. [硬] 无兵器：画面任何位置不出现剑、刀、枪、弓等任何兵器，人物周身无佩剑、无剑鞘、无剑穗、无任何兵刃轮廓；出现任何兵器（含出鞘或连鞘）即 fail。
4. [硬] 静立姿态：人物立在祭坛旁的雪地上，双足并拢不移动，双手拢于白色披风内；出现行走、迈步、单腿承重的行进重心、抬手拭掌、施法、跳跃等任何动作姿态即 fail。
5. [硬] 石坛锁妖·伏卧：画面中有一座石坛，两只体型庞大的狼形妖物被粗重的玄色锁链捆缚在石坛台座上，深深伏卧，头颅低垂贴地、姿态驯服；判据：狼形妖物四肢站立、抬头或张口即 fail，头颅贴地伏卧为 pass；石坛或妖物缺失即 fail，仅画出一只且贴地伏卧捆于坛上可计 partial。
6. [硬] 冬雪冰湖：场景为冬雪时节，坛石与地面覆雪、空中可见落雪，远处湖岸冰封；画面无雪、无冰面或改为春夏秋景即 fail。
7. [硬] 无燃烧元素：画面任何位置无火焰、明火、火光、烛火、紫火、燃烧粒子或火星；雪天光效只允许清冷天光与清亮微光。
8. [硬] 全身完整：人物头顶到双脚完整入画、无裁切。
9. [硬] 无文字：画面任何位置（含衣饰、祭坛、锁链、背景）不出现文字、题字、印章、徽记符号。
10. [软] 发式发饰：黑发束起、头戴素色发冠（原文无明文，系从简自拟；"束发+素冠/素带"方向正确即可，繁金重玉扣分但仅计 soft fail）。
11. [软] 人潮仰望：远处山脚集市隐约有人潮遥遥翘首仰望；作远景淡墨弱化处理即可，缺失或淡化不计 fail。
12. [软] 雪地留白：人物身后与脚下留出大面积雪地留白，画面整体保留宣纸留白与纸纹质感；留白不足仅扣分不否决。
13. [软] 水墨风格：笔触潇洒写意、有宣纸纸纹质感、透明叠染色调；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
