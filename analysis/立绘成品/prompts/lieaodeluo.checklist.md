# 列奥德罗 · 遗迹造像厅（第四纪造像）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 造像属性：画面主体是一尊静止的古代石雕像（第四纪遗迹造像），具石材质感与雕刻感；画成活人肉身、真神显圣、发光神影或灵体虚影即 fail。
2. [硬] 形象气质：威严的中年男子，面容端正庄重，神情威严深沉、不怒自威而非狰狞，头部端正、正面直立、双目平视前方；画成狰狞怒目、獠牙异相、老朽衰颓或少年稚气即 fail。
3. [硬] 变体禁用：雕像除头盔上的简洁盔冠外不佩戴任何冠冕、头饰（亵渎之牌"教皇式"三重冠冕变体禁用）；画面不出现章鱼头、触手、鸟类羽毛披风（救赎蔷薇扭曲壁画变体禁用）；出现任一变体特征即 fail。
4. [硬] 黑色盔甲：雕像身穿全套黑色盔甲，覆盖躯干与四肢，甲片层叠、以钢笔细线刻画甲缘纹路；主色画成白/银/红/蓝、画成布袍法衣、长袍或袒甲缺甲即 fail。
5. [硬] 三叉戟：右手握着一柄三叉戟，戟尖向上、戟杆拄地，持物静立；画成左手持戟、双手横持、高举挥掷、劈刺等攻击动态，或戟消失、替换为权杖/剑/矛即 fail。
6. [硬] 纯静态大理石雕像、身姿笔直、无任何翻卷飘动元素（飘动/破布/真实闪电/浪沫即 fail）。
7. [硬] 场景要素：一座空旷静默的石殿展厅，雕像立于简洁的多层方形石座上（空旷石殿展厅+简洁方形石座）；展厅画成海边/雷雨环境，或石座画成海浪、山岩等异形底座即 fail。
8. [硬] 风浪元素禁用：画面不出现任何闪电、雷光、暴风、乌云、海浪、浪花、风纹等风浪元素，无论是真实天象还是石雕浮雕造型；出现即 fail。
9. [硬] 静态与显圣禁用：场景为一帧静态画面，无战斗、挥戟、雷劈等动态；除雕像外不出现神灵显圣、圣光光柱、天使虚影、雷云神目等意象；不出现火焰、明火、烛火等任何燃烧元素。
10. [硬] 全局负面与构图落点：画面任何位置（含墙面、基座、甲片）不出现文字、字母、题字、水印、印章符号；雕像自头顶至脚下多层方形石座完整入画、无裁切，雕像全身约占画面三分之二，脚下留出一身位空白。
11. [软] 自拟项与 FH-040 风格锚：三叉戟金色、盔冠样式、大理石材质与展厅陈设为档案未明写的自拟设计（档案注明造像材质未明写），不作否决依据，但不得与正典冲突；风格上应呈现中世纪暗黑奇幻墨线插画——精密细腻钢笔交错排线、暗调羊皮纸底色与暖赭统调、做旧纸感，淡金与冷银白仅作点睛，呈现为写意水墨、厚涂油画、赛璐璐动画或照片写实即提示，且画面不得残留牛角铠甲骑士等风格参考意象。
