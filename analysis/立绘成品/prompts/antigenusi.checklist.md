# 安提哥努斯 · 石椅上的沉睡者（★人形定妆·永眠静置）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 人形主形态（形态红线）：画面必须为人形本体——以人的模样端坐、四肢俱全、形貌完整如常人；画成透明蠕虫合抱成团、滑腻触手、八腿魔狼、半狼兽人或深黑斗篷蒙面人即 fail（蠕虫团与触手属疯狂形态，八腿狼属记忆回溯形态，深黑斗篷属"诡秘之主"意志形象，均不进本图）。
2. [硬] 年轻面容（锚点一）：面容颇为年轻、五官端正清俊；画成皱纹密布的老翁或粗粝中年脸即 fail；"苍老"只作气质矛盾感的细微处理（眉目沧桑），不得实际老相化。
3. [硬] 半白长发（锚点二）：长发近半霜白、近半墨黑、二色混缠，头颅后仰时发丝顺高耸椅背垂落散开；画成全黑、全白或均匀银灰渐变即 fail。
4. [硬] 幽黑眼眸（锚点三）：正解为双眼紧闭沉睡，眼睑与眉骨下晕染深浓幽黑阴影、蕴沧桑余韵；若画成睁眼版本，瞳色必须幽黑近墨、比夜更沉，画成蓝/金/红/褐/灰等任何他色即 fail。
5. [硬] 狼毫颊毛（锚点四·血统识别点）：两侧颊面（眼与嘴角之间）各有一小片明确的深色短毛区、可读作延长的鬓角为 pass；唇周下颌出现人类胡型（山羊胡/络腮胡/唇上髭）仍为 fail 条；下巴/唇周出现任何斑点状须色块即 fail（r3 教训）；两侧颊面完全光洁无毛即 fail（r2 教训："狼毫刷刺状颊毛"抽象描述不成立，"延长的鬓角"是模型可执行的视觉锚）。
6. [硬] 石椅沉睡姿态（场景主锚）：独坐巨大石椅，双肘撑于石质扶手、脑袋后靠椅背、双眼紧闭如沉睡；画成站立、端坐睁眼、侧卧瘫倒即 fail；石椅须为整块巨石凿成的高背巨椅（形制庄严如神座、尺度贴合人身），画成普通木椅、软垫王座或断椅即 fail。
7. [硬] 无尖顶软帽与单片镜（特殊红线·最高优先）：头部不出现尖顶软帽，面部不出现单片眼镜、夹鼻镜及任何眼镜——帽镜组合为阿蒙专属锚点（【第1204、1425章】两度同场标志，安提哥努斯识别靠半白长发＋颊侧狼毫，阿蒙靠单片镜），出现任一即整图 reject，不因其余全对而豁免。
8. [硬] 全局负面（无伪文字/无火焰/无风格残留）：画面任何位置不出现文字、铭文、符文、徽记、竖眼符号等刻痕图案——石椅、石柱、地面皆为素净无镌石面，黄铜书与家族笔记不入画，出现任何可辨文字符号即 fail；不出现火焰、烛火、火盆、灯焰等任何燃烧元素，全画唯一光源为虚幻星光与石面冷辉，出现火光即 fail；柱龛内出现任何火焰/焰状光源/照明物即 fail（r4 教训：泪滴状焰体+焰尾+灯杆柱身+暖橙光晕的壁龛灯具造型亦属违例）；不出现骑士、牛角铠甲、古老石阶遗迹等 FH-040 风格参考残留意象。
9. [硬] 独处红线（无他人无虫）：大厅空寂无人，画面除沉睡者外不出现任何其他人影、悬吊尸体或衣物、秘偶、蠕虫、触手等异质元素（悬尸"倒长的森林"属同殿他景，本图不入画）；出现任何清晰或半清晰第二身影或虫形元素即 fail。
10. [硬] 构图完整与场景占比：石椅与沉睡者约居画面中轴略偏下，两者合计约占画幅五分之二，四周留出大厅幽暗纵深、石柱剪影与星光光柱；人物全身完整入画，头顶与椅背顶端清晰可见、不被裁切，占比失衡（特写过近或渺不可辨）计 partial；全画为静态定格，发丝、衣袍、雾缕凝滞，无动态混乱。
11. [软] FH-040 风格锚：精密细腻的钢笔交错排线、暗调羊皮纸暖赭底色、薄透墨层与做旧纸纹质感，如一页古老典籍中的整幅插图；呈现厚涂油画感、赛璐璐动画感或照片写实即计 fail（软性提示）；不得混入东方水墨写意笔触。
12. [软] 自拟长袍与气质细节：素灰近霜白宽大旧长袍为自拟推定项（原著无服装明文，按档案"弱光素净"方向自拟），颜色或形制偏离仅作提示、不计 fail，但袍面须素净无纹章刺绣；气质须兼顾"既苍老又青春、既理智又疯狂"的矛盾感与沉睡的静谧压迫，画成安详圣洁的圣徒睡颜或狰狞痛苦脸即计提示偏移（软性）。
