# 萧炎 · 三年之约（云岚宗石阶立约）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄气质：人物为成年青年男性（约二十岁上下），身姿挺拔，气质沉静坚定、从容不惧；画成稚气少年、孩童或中年/老者即 fail。
2. [硬] 瞳色：双眼瞳孔为漆黑色；画成金/红/蓝/紫/银等任何其他瞳色即 fail。
3. [硬] 主装：身穿玄黑色长袍，主色为黑、布袍制式；主色画成白/红/蓝，或画成铠甲、短打劲装即 fail。
4. [硬] 发色：头发为墨黑色深色发；画成银白、金棕等浅色发即 fail（束发/半束/散发的样式差异不作否决）。
5. [硬] 单人定格：画面中仅萧炎一人，无纳兰嫣然、白袍老者、宗门弟子等任何其他人物；人物为静立收势姿态，无挥拳、腾空等打斗动作。
6. [硬] 场景要素：云岚宗石阶场景——画面中有一道宽阔石阶，人物立于石阶之前，石阶上方为开阔雾气与天光，无门楼；缺石阶环境即 fail。
7. [硬] 青莲火焰形态：人物指间有一缕青莲色辉光火焰，形态小巧安静、层瓣如莲、属静态点睛小元素；画成爆炸、喷发、火柱、漫天火光或包裹周身的大火即 fail。
8. [硬] 无其他燃烧元素：除指间那一缕青莲色辉光火焰外，画面任何位置（含背景、衣饰、山门）无其他火焰、明火、火光、火星或燃烧粒子。
9. [硬] 全身完整：人物头顶到双脚完整入画、无裁切，脚下石阶与留白舒展。
10. [硬] 无文字：画面任何位置（含衣饰、石栏、背景）不出现文字、题字、印章、徽记符号；画面中不得出现门匾/匾额/楹联/碑刻，凡属牌匾类构件一律 fail。
11. [软] 水墨风格：笔触潇洒写意、有大面积留白与宣纸纸纹质感、透明叠染色调；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
12. [软] 自拟细节（档案原文未写、按气质从简自拟）：半束发与素色发带、领袖云纹细边、腰间素玉佩、石栏石柱样式、阶下山雾；与提示词有出入但不违背上述硬项时仅作提示，不否决。
