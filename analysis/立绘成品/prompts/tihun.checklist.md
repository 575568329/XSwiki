# 啼魂 · 化形静立（#1324 黑袍化形）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 人形甄别（最高优先）：画面主体为一名站立的人类青年男子——人类面部、人类耳形、露出的手为人类手形、全身人类体态；出现猿/猴/兽形、兽脸兽身、黑毛巨猿剪影或猴类蜷蹲姿态即 fail。
2. [硬] 无兽形残留：人物头上无兽耳、无兽角、无第三只眼，无獠牙、利爪、兽尾、鳞片，体表无兽毛覆盖；背后无血色恶鬼图腾、无恶鬼刺青、无三根黑色骨刺。
3. [硬] 黑色长袍：身穿漆黑色长袍（修士常服式样，交领宽袖、腰间束带），袍色主色为黑；画成青/白/红等他色长袍，或画成短衫劲装、无袍即 fail。
4. [硬] 无兵器：双手空垂或拢于袖中，画面任何位置无兵器法器（黄濛濛巨叉、黑骨刺骨矛、飞剑、法珠等均不得出现）。
5. [硬] 场景要素：画面为古朴洞府石室（青石殿宇、石壁石柱），上空乌云低垂凝聚成漩、黑色闪电在云间蜿蜒明灭，闪电呈冷青色清亮辉光而非火焰。
6. [硬] 场景静态：人物保持静立姿态，无变身过程、无撕袍动作、无毛发暴涨、无腾跃打斗等动态；乌云闪电仅作背景氛围，不劈落人物身上。
7. [硬] 单人构图：画面仅有这一名黑袍青年，无第二个人物（不得出现青袍男子同框、双"韩立"镜像对峙构图）。
8. [硬] 全局负面：画面任何位置（含衣饰、石壁、背景）不出现文字、题字、印章、徽记符号；不出现火焰、明火、火光、烛火等燃烧元素，一切光效为冷青辉光/流光。
9. [硬] 全身完整与落点：人物头顶到双脚完整入画、无裁切，全身约占画面三分之二，脚下留出一身位空白。
10. [软] 面容细节：面容平和沉静的青年，眉目清朗端正、五官协调，神情安静，可隐带一丝憨厚之意；无凶相戾气、无阴森鬼气，无明显少年稚气或衰老感。
11. [软] 发式仪态：黑发束起成髻、素簪固定，身姿挺拔自然；衣纹笔触写意流畅、袍摆垂坠合理（发式系自拟补全，档案无原文描写，不作硬性要求）。
12. [软] 水墨风格：笔触潇洒写意、有大面积留白与宣纸纸纹质感、透明叠染色调，冷青电光仅作点睛；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
