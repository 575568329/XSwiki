# 琥珀 · 墓室初擒（#2）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 尖耳：发间有一双比人类略尖的长耳，耳形清晰可辨且短巧（原文"尖尖的，却不像精灵那般欣长"）；画成普通圆人耳（无尖）计 fail，画成超长飘精灵耳亦计 fail。
2. [硬] 琥珀色大眼：双眼为大大的琥珀色（蜜金/金褐色），明亮醒目、是画面眼部焦点；画成黑/棕/蓝/绿/红瞳，或画成细小无神的眼睛即 fail。
3. [硬] 齐耳短发：短发齐耳、发梢微乱；发色深褐为自拟软项（原文未写，不作否决依据）；画成长发、披肩发、马尾，或出现黑色长发（后期暗影神选形态混入）即 fail。
4. [硬] 娇小体型：身形娇小灵巧的少女体型，头身比偏圆润（约五至六头身）；画成高挑窈窕的成年女性身材即 fail。
5. [硬] 陈旧皮甲：身穿贴身的旧皮甲，甲面有磨损、划痕、磨白等做旧质感（深棕色为自拟软项）；画成布袍、裙装、锁子甲、板甲或华丽魔法装束即 fail。
6. [硬] 无兵器：画面中不出现任何兵器、刀剑、匕首、鞘类物品，少女双手空空无持物、身上不挂任何武器；出现任何兵器形（含腰间挂刀、手持械、背景兵器架）即 fail。
7. [硬] 就擒跪姿：双膝跪坐于石地，双肩微垂、微微缩脖塌肩，就擒感全靠姿态与神情表达（桀骜不甘、狼狈不服）；画成站立、战斗动作或潇洒亮相即 fail。
8. [硬] 场景要素与单人构图：画面为火把照明的古老墓室内部（粗糙石壁、石砌结构、暖赭火光与排线长影）；画面中除琥珀本人外出现任何其他人物即 fail。
9. [硬] 无文字：画面任何位置（含石壁刻痕、服饰、腰带、火把、背景）不出现文字、题字、印章、徽记符号。
10. [硬] 全身完整：人物头顶到双脚完整入画、无裁切，跪坐全身约占画面三分之二，脚下石板留出一身位空白。
11. [软] 宽皮带：腰间仅系一条简单的宽皮带，无任何悬挂物；画成细绳、多条腰带或附挂小件（袋、包、扣饰繁复）仅计 partial。
12. [软] FH-040 风格执行：暗调羊皮纸暖赭色调统一全画、钢笔交错排线细密、手绘墨线质感与纸纹清晰；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
13. [软] 灰污与狼狈感：脸上沾有少许灰污、发丝微乱、狼狈之中可见秀气底子（"美人坯子"）；完全干净整齐仅计 partial。
