# 欧弥贝拉 · 祈祷室圣像（地下遗迹）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 石雕像材质（本图根本识别项）：画面主体是一座洁白石材雕成的高大女性雕像，石质温润细腻，为无生命的雕塑而非活人；出现真实血肉肤色、体温质感或活人化渲染即 fail。
2. [硬] 体量与身形：雕像高四五米、明显超出真人尺度，立于三层台阶之上；身形丰腴柔美、体态端庄圣洁，有丰饶母亲的温厚体量感；画成常人尺寸、瘦削少女或干瘪老妇即 fail。
3. [硬] 怀抱襁褓婴儿：双手环抱一个藏于襁褓中的婴儿，头微低俯望怀中婴儿；婴儿必须藏于襁褓之内，襁褓外出现婴儿面孔或手足特写、怀抱姿势缺失即 fail。
4. [硬] 衣裙花草与动物浮雕：衣裙飘逸外荡，其间插缀草药与花朵，衣纹上浮雕着温和动物（鹿、羊、飞鸟一类）的形象；衣裙素白无饰、动物纹缺失或画成凶兽猛禽即 fail。
5. [硬] 足下麦穗环泉：雕像足底与基座周围有麦穗生长的雕刻与泉水环绕的浅浮雕，麦穗为金黄暖色；要素缺失即 fail，麦穗画成黑色即 fail。
6. [硬] 场景要素：地下小型祈祷室——麦穗色石板地面、石板道尽处的三层台阶、古老石材四壁与低矮穹顶，昏黄柔和的殿堂暖光笼罩雕像；无台阶、无殿堂空间感即 fail；画面中不得出现任何活人、朝拜者或其他人物身影，雕像为唯一主体。
7. [硬] 面容红线：雕像面容圆润温和且完整无破损，绝不出现竖直独眼、深棕色披发、皮甲等壁画相特征，也无腐烂、污秽、狰狞等堕落镜像元素；出现竖直独眼即 fail。
8. [硬] 全局负面与色彩纪律：画面任何位置无文字、题字、碑铭、印章与徽记符号；无火焰、明火、烛火、火苗形态（灯光只以柔和暖晕呈现），无光柱、圣光粒子与能量特效；无血迹、骷髅、白骨、黑色麦穗、腐烂婴儿、袒露胸口、脓液等恐怖与污化元素；无银甲面甲长剑（战神）、六臂繁星长裙漆黑巨镰黄金鸟饰（黑夜女神）、三叉戟与黑甲海浪（风暴之主）、白袍金球契约书（永恒烈阳）、兜帽书册全知之眼（知识与智慧之神）、深褐木杖与缠绕藤蔓（神战终局形态）等其他标志物；全画以洁白石色、暖赭、深褐的沉郁层次为基调，唯一点睛暖亮色为足下麦穗的金黄，泉水仅作清浅灰蓝的低调点缀、衣裙花草为深绿与土黄的收敛石彩，出现第二处鲜艳异色亮斑即 fail。
9. [硬] 构图完整与静态：雕像从头顶到足下麦穗基座完整入画、无裁切，全身约占画面三分之二，画面下方留出一身位空白；全画为一帧静止定格，无人物走动、衣裙飘飞等动态混乱。
10. [软] 面容五官（自拟软项）：圆润丰腴、温和慈和的母性面容与双目低阖等五官细节原文零描写，属自拟项，只要符合丰腴母性、圣洁端庄基调即可；细节与预期有出入仅作质量提示，不单独否决。
11. [软] FH-040 风格锚：精密细腻的钢笔交错排线、暗调羊皮纸底色、暖赭统调与做旧纸感，如一页远古地下神殿探索古卷里的整幅插图；呈现为厚涂油画、赛璐璐动画或照片写实即计 fail（软性风格提示）；画面不得残留牛角铠甲骑士等风格参考意象，不得混入东方古风水墨写意笔触。
