# 堕落母神 · 月背血海·无数之眼（绯红巨月与血海多眼虚影）· 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 画面主体判定：画面主体为一轮被赤红大海淹没的巨大绯红月亮，血海翻涌流淌、包容整片月面，位于画面中央偏上、占主要视觉比重；月面画成正常灰白月亮、环形山坑洼清晰，血海仅成薄薄一层红光，或出现第二颗红色月亮即 fail。
2. [硬] 血海虚影形态：血海沸腾向中央凝聚出一个比月亮更大的通体血红虚影，边缘朦胧流动、呈剪影状，其上隐约布满无数只眼睛的暗红轮廓（多眼点睛）；虚影明显小于月亮、实化为有清晰躯干肢体边界、或多眼细节缺失即 fail。
3. [硬] 蔚蓝行星陪衬：画面下方三分之一处有一颗小巧完整的蔚蓝色行星，体量明显小于血月与虚影，以悬殊对比衬托压倒性威压；行星画得过大抢夺主体、带地表细节特写，或缺失即 fail。
4. [硬] 宇宙深空场景：背景为漆黑深空与疏落冷白星点，照明仅为血海绯红辉光与星空冷光；出现地平线、地表眺望视角（屋顶、树影、山脊），或火把、灯笼、烛火等任何火焰灯体光源即 fail。
5. [硬] 虚影无清晰五官：虚影无法看清具体模样，仅有眼睛轮廓点睛，无清晰面部五官、口鼻与表情；画出明确人脸、五官细节、表情即 fail。
6. [硬] 无拟人神像：画面无任何人形神像、拟人化形体、雕像，也无翅膀与天使形象；出现即 fail。
7. [硬] 无信徒庙宇：画面无信徒与任何人物，无庙宇、神殿、祭坛等任何建筑元素；出现即 fail。
8. [硬] 无伪文字：画面任何位置无文字、符文、题字、印章、徽记符号；出现即 fail。
9. [硬] 构图完整：绯红巨月与血海虚影完整入画、无明显裁切，蔚蓝行星位置得当，四周留出漆黑深空呼吸空间，画面重心沉稳庄重。
10. [软] 风格锚（FH-040）：中世纪暗黑奇幻墨线插画——钢笔交错排线、暗调羊皮纸暖赭色调、纸纹质感与留白；呈现日式动漫赛璐璐感/厚涂油画感/照片写实即计 fail（软性风格提示）。
11. [软] 宇宙恐怖威压感：静态古老异象式构图，沉默庄严，威压来自体量悬殊与俯临视角而非表情动作；画面轻快明亮、失去恐怖威压感即计 partial（软性提示）。
