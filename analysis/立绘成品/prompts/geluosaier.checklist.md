# 格罗塞尔 · 营地初见·憨厚巨灵（★定型·游记书中世界冰霜之国营地）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 额头竖直独眼（第一识别点·恒定锚）：额头正中央一枚竖直长缝状独眼，眼裂纵向、深暗色瞳，全脸仅此一眼；画成双眼、面部另添成对眼睛、或独眼横置如常规双眼之一即 fail（档案红线：全书恒定单眼，画成双眼即整图 reject）。
2. [硬] 近四米巨人体格与灰蓝肤：近四米高的魁伟巨灵、小山般压倒性体量、通体灰蓝色皮肤；手脚比例夸张近乎畸长、赤裸双足无护具；肤色画成人类肉色/深棕/灰绿等即 fail，身高画成普通人比例、无巨人体量感即 fail。
3. [硬] 憨厚咧嘴笑：宽厚大嘴向两侧咧开、憨厚坦率的哈哈笑容，竖眼温和向下俯视（双手扶石台、微前倾低头的迎客姿态）；画成凶残暴虐、怒目咆哮、阴沉冷笑即 fail（气质红线：热情和蔼、憨厚乐观，"看起来有点傻"的温厚感）。
4. [硬] 厚野兽毛皮裹身（唯一服装·r5 修订：整幅披挂自锁骨下方直覆大腿根）：厚实原色野兽毛皮自两肩绕颈后罩下、在胸口正中以骨针交叠扣拢，整幅垂覆覆盖整个胸腹并直达腰胯与大腿根部；胸口或腹部裸露灰蓝皮肤即 fail；毛皮之外另出现盔甲、锁甲、头盔、布衣、饰物任何一件即 fail（无盔甲红线：兽皮是他唯一的衣物，王庭卫兵铁黑盔甲另有其人）；肩头、大臂与小腿露在毛皮边缘之外为正确状态。
5. [硬] 无兵器·石台巨杯尺度锚（r5 终轮去剑化裁定，随语义改清单）：画面不出现任何剑、斧、锤、杖等兵器，巨人双手交叠扶在齐腰高的矮石台边缘；矮石台上搁一只比木桶还夸张的巨杯，与近四米身躯共同构成器物尺度锚；出现任何兵器即 fail（原"门板宽巨剑"条款废止：剑宽先验 r1-r4 四轮 1/6 胸宽不可对抗，按 SKILL 规则 17/去X化终局删元素）。
6. [硬] 山洞火堆场景（无焰写法）：黑幽幽的巨大山洞营地，粗粝岩壁隐入阴影，脚下低处一团暖橙火光光晕铺地镀身（无源暖光），洞口远处一线冰蓝雪光作冷暖对照，矮石台上木桶巨杯；场景画成露天雪原、王庭宫殿、街道铁匠铺即 fail；出现清晰火苗、火舌、火炬灯体等成型燃烧物即 fail（火堆只作暖光光晕，无火焰纪律）。
7. [硬] 无战斗特效（静态定妆）：常态无光——画面无晨曦光墙、无形墙壁、掌中光剑、体表发光、周身光环等任何守护者战斗特效与神秘学光效；出现任一光效即 fail（光墙须插剑跪地战斗态才触发，本图为日常定妆）。
8. [硬] 无冰霜巨龙：画面无冰霜巨龙、龙影、龙骨龙尸、雪白对开大门及任何龙形残迹；出现即 fail（猎龙战死属后续剧情，非本定妆时刻）。
9. [硬] 独处红线（无第二人）：画面除格罗塞尔外不出现任何其他人物或人影——来访人类与精灵女猎手一律不入画，无剪影、无黑影、无队友；与人类的体量差应借矮石台与木桶巨杯的器物尺度呈现；出现任何清晰或半清晰第二人影即 fail。
10. [硬] 全局负面：任何位置不出现文字、符文、铭刻、徽记符号（石壁、石台均素净无纹），出现任何伪文字即 fail；不出现王冠、王座、权杖（他非巨人王，见王位须跪）；不出现骑士、牛角铠甲、石阶遗迹等 FH-040 参考残留意象；全画唯一点睛冷暖为火晕暖橙与灰蓝肤冷调，出现其他鲜艳亮色块即 fail。
11. [硬] 构图完整与静态：巨人全身完整入画，头顶与双脚清晰可见，头顶或双脚被裁切即 fail；人物占画面竖幅约七成、山洞环境约三成；全画为静态定格（扶石台俯身迎客的静止姿态），无奔跑挥砍、兽皮毛发剧烈翻飞等动态混乱。
12. [软] FH-040 风格锚与温厚感：精密细腻的钢笔交错排线、暗调羊皮纸暖赭底色、墨色与颜料层叠肌理及做旧纸纹，如一页古老游记典籍中的整幅插图；呈现厚涂油画感、赛璐璐动画感或照片写实为强提示；整体传递憨厚巨人温厚可靠、沉稳亲和的暖意（软性风格与气质提示，不否决）。
