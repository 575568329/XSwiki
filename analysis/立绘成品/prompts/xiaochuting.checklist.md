# 萧初庭 · 平原风雨蓑笠行（溪上翁定型像）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄感：人物为苍老老者（仙道老祖），面容苍老、身形单薄、脊背微佝偻；画成中年/壮年/青年、出现少年感即 fail。
2. [硬] 眉胡：眉毛与胡须皆为花白色（眉毛偏雪白），眉、胡均明显可见；黑眉黑须或无须即 fail。
3. [软] 发式：斗笠下露出白发，脑后挽简单发髻、束一根素灰色布带（发式为自拟软项，原文未写；白发有据）。
4. [硬] 竹笠：头戴宽沿竹编斗笠，笠沿镶有一圈青边；无斗笠、或笠沿无青色边即 fail。
5. [硬] 蓑衣：外披棕中带青的蓑衣，一缕缕草叶纤维层层分明披挂；画成普通布质斗篷、或蓑衣为纯黑/纯棕而无青色倾向即 fail。
6. [硬] 内衬白衣：蓑衣之下可见素白色交领宽袖长袍（胸襟或下摆处露出白色衣料）；通体只见蓑衣而无白衣即 fail。
7. [硬] 青铜小鼎：腰间悬挂一枚小型三足两耳青铜鼎，青铜色泽明亮，鼎身仅有抽象云纹曲线装饰；鼎画成瓶/炉/印等其他器物即 fail，鼎身出现文字或徽记刻痕即 fail。
8. [硬] 玉钓竿：肩上横扛一根细长玉钓竿，色泽为白中透青的温润玉色，竿梢垂下一缕纤细透明钓线；竿画成深色竹竿/金属杖/木杖即 fail；画面出现剑或其他任何兵器即 fail；钓竿竿梢与竿尾均完整可见、不裁切、不没入地面。
9. [硬] 场景要素：天色暗沉、可见斜织雨丝的潇潇风雨、沃野平原、远处低云压着朦胧山影，四要素齐备；缺雨或缺平原远景即 fail。
10. [硬] 无施法特效：画面无施法动作、无爆炸、无金光爆发，人物整体气息如凡人老翁；最多允许雨野间一层极淡的水蓝色清亮辉光，出现火焰/光爆/雷电特效即 fail。
11. [硬] 全身完整：人物头顶到双脚完整入画、无裁切，全身约占画面三分之二，脚下湿润的青草田野与泥土小径完整可见。
12. [硬] 无文字：画面任何位置（含鼎身、笠面、蓑衣、衣料、背景天空）不出现文字、题字、匾额、印章、徽记符号。
13. [软] 水墨风格：潇洒写意墨线笔触、大面积留白、宣纸纸纹与颜料肌理质感、透明叠染淡彩；呈现照片写实/厚涂油画感/赛璐璐动画感即计 fail（软性风格提示）。
