# 因斯·赞格威尔 · 地下遗迹之门现身 立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄感：人物为四十岁上下的中年男子，普通中年体格；无青年稚气俊俏感、无老态龙钟的衰老特征。
2. [软] 独眼（终局降软）：一眼目光沉静、另一眼珠泛淡淡灰白浑浊为加分项；模型画成双眼正常仅计 partial，不否决整图；若出现眼罩、纱布等遮盖物或玻璃义眼，本项记 fail 并标记复发（提示词已无任何遮盖词，出现即模型自加）。
3. [硬] 发型发色（去帽化终局）：深棕近黑的头发向后梳理整齐（档案原文为暗金短发鬓角灰白，两色均可 pass）；全头白银/雪白即 fail（白发系证伪锚点），披散长发亦 fail。
4. [硬] 面部：鼻梁高挺、嘴唇紧抿，古典雕像般光滑紧致的轮廓——光滑无皱纹为 pass，明显皱纹即 fail（上轮复发项，重点盯防）；神情严肃凝重淡漠，松弛笑容或猥琐神情亦 fail。
5. [硬] 服装与无帽（去帽化终局）：纯黑双排扣神职人员长袍＋崭亮黑色皮靴，两件齐备；长袍画成红/白/蓝/紫等其他颜色、换成铠甲/风衣/便装即 fail；头上出现任何帽类（高顶礼帽、宽檐帽、fedora、软帽、兜帽等）即 fail；手掌略显苍白为应有细节，缺失计 partial。
6. [硬] 禁物：画面中无羽毛笔、无钢笔、无书本、无笔记本、无纸张手稿等一切书写道具与带字物（封印物"0—08"禁入画）；人物手持或身旁出现任何笔类、册页即 fail。
7. [硬] 场景要素：幽暗地底遗迹中有一座虚幻青铜巨门，门缝间丛生苍白血臂（苍白无毛手臂，僵止不蠕动成抓扑动态）；人物自门后步出、立于巨门前石阶。无巨门即 fail，门缝血臂缺失即 partial。
8. [硬] 静态：人物为伫立或步出定格的静态姿势，无挥臂施法、无战斗搏杀、无失重漂浮等强动态；门缝血臂静止不抓人。
9. [硬] 无文字：画面任何位置（含袍面、门面浮雕、帽面、背景岩壁）不出现文字、铭文、符文文字、题字、印章、徽记符号。
10. [硬] 全身完整与落点（规则式）：人物全身完整入画，头顶与双脚都清晰可见，双脚不触画面底缘，脚下石地留白，无任何裁切；全身约占画面三分之二；画面无火焰明火等燃烧元素，光效仅清冷幽光。
11. [软] FH-040 风格：精密细腻的钢笔交错排线、暗调羊皮纸暖赭色调、古老幽暗的遗迹氛围；呈现厚涂油画感/赛璐璐动画感/照片写实/日式动画平涂即计 fail（软性风格提示）。
