# 亚当 · 十字架下的布道者（卷七尸骨教堂 #1387）立绘 · 盲审清单（三轮修订）

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄与气质基底：成熟沉稳的男性神父，35-50 岁中年读感，中高身材、清瘦匀称；画成 18-25 岁青年、少年稚气或龙钟老态即 fail（档案实证：原著从未给亚当年轻描写，全部形象词为蓄须神父/布道牧师）。
2. [硬] 金色须幕遮唇（身份硬锚点，三轮复审重点）：淡金色的长发与长须连成一片，从头顶、两颊垂落覆盖整张下半张脸，像一层金色须幕；正面可见嘴唇或下巴皮肤即 fail；金色须幕+白色兜帽双重物理遮覆下半脸为 pass（复审记录：前两轮模型反复画成短髭+山羊须分体式即 reject；若三轮仍露唇，按轮次规则将本条降为软项或挂起转人工）。
3. [硬] 白色神父袍：简朴素白垂地长袍，无金线、无刺绣、无纹章、无徽记；主色画成黑/灰/金袍、加金线花纹或画成铠甲即 fail（白袍是与弟弟阿蒙"全套黑"区分的核心色系锚点）。
4. [硬] 银十字吊坠：胸前白袍外以一根简洁银链悬挂一枚朴素银质十字架吊坠（无宝石镶嵌、非金色），且人物右手轻轻按在吊坠上；身上出现第二枚十字架、链条小十字或领口十字纹饰，吊坠为金色/宝石华丽款，或无按持动作即 fail（二轮复审重点：画面出现另一枚链条小十字即 reject；身后巨大石十字架为场景要素，不与本条冲突）。
5. [硬] 面向与眼眸：人物面部朝向镜头（教堂中殿座椅方向），白色兜帽边缘压至眉骨上方、不遮挡双眼，露出一双清澈单纯、浅淡澄澈的眼眸；背对镜头、帽檐遮眼、闭目或眼神阴鸷即 fail（档案实证：「清澈单纯眼眸」与「和煦平静」为神态常量）。
6. [硬] 禁忌·阿蒙系物件：画面任何位置无单片眼镜、无眼镜、无挂绳链条、无礼帽、无风衣、无手杖雨伞；人物除白袍、兜帽与胸前银十字吊坠外无任何其他饰品、无第二套衣物（档案实证：亚当全书零次与单片眼镜同句，程序化核查为 0，此为兄弟区分硬项）。
7. [硬] 场景要素：尸骨教堂内部——柱拱穹顶密镶各族苍白头骨、人物身后矗立上百米高大十字架、面前一排排空置的黑色有靠背长椅、两侧彩绘玻璃花窗；场景画成普通整洁教堂、室外广场，或缺头骨穹顶与十字架即 fail。
8. [硬] 无文字无他人且静态：画面任何位置（彩绘玻璃、十字架、座椅、墙面）不出现文字、经文、铭文、印章、徽记符号，彩绘玻璃只以图案与剪影呈现；除主人公外无任何其他人物或人影（长椅全部空置）；全画为静止定格瞬间，无动态混乱。
9. [硬] 无燃烧元素：教堂内没有任何蜡烛或火光，只有高窗洒落的冷白天光；画面任何位置出现烛火、蜡烛、油灯、火把、火焰、明火即 fail（二轮 reject 项：柱基旁明火即 reject）。光效只允许高窗冷白天光与银十字一缕冷银微光。
10. [硬] 全身完整（规则式）：人物全身完整入画，头顶与双脚都清晰可见，双脚不触画面底缘，脚下石板留白；头脚任一被裁切、白袍下摆出画或双脚贴触画面底缘即 fail（二轮 reject 项：白袍裁脚即 reject）。
11. [软] 自拟与工程性叠加细节：白色兜帽为第三轮防露唇工程性叠加项（档案实证：原著兜帽仅查拉图使用 #1394，亚当无兜帽记载，非原著定妆要素，按修订指示叠加，兜帽须与袍体同为素白一体）；浅金色发须连片被兜帽与须幕覆盖；白袍立领形制按第五纪朴素教士袍补全；画得协调统一即 pass，出现金属额饰/冠饰即计 fail。
12. [软] 风格（FH-040）：中世纪暗黑奇幻墨线插画，精密细腻的钢笔交错排线、暗调羊皮纸暖赭色调、可见纸纹与轻微做旧；白色神父袍为全画最亮色块、银十字一缕冷银微光为点睛；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
