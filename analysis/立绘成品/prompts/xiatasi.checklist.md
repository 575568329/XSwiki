# 夏塔丝 · 营地暮色·持弓怒指（★常态定妆/游记书中世界期）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 略尖耳朵（种族第一识别点）：一对精灵标志性的略尖耳朵完整露出、耳廓与耳尖轮廓清晰可辨、不被发丝遮挡，耳尖弧度轻缓秀气；无耳、被头发完全遮盖即 fail；画成精灵王式"尖而高耸"的夸张拉长尖耳即 fail（档案红线：她的耳部为"略尖"，勿夸张形）。
2. [硬] 乌黑马尾（第一识别点）：乌黑长发在脑后束成一条马尾、发丝柔顺黑亮自然垂落肩后；散发披肩、盘发、双辫、短发即 fail；发色画成蓝发、银发或泛深蓝/银白光泽即 fail（发色恒为乌黑，深蓝只是激发态缠电发丝的光泽，常态禁入）。
3. [硬] 脸庞、瞳色与眼神：线条柔和的精致脸庞、五官轮廓温润柔和，与暴烈神情形成反差；眼神暴烈、目光锐利逼人，眉峰紧蹙、怒意未平；瞳色深棕（档案推定自拟项），画成金瞳/红瞳/异色瞳即 fail，画成深蓝等其他深色仅作提示不计 fail；画成棱角粗犷的汉子脸、温婉浅笑或悲伤低垂脸即 fail（本图为对峙怒指场景，情绪是画面核心）。
4. [硬] 猎人装束体系：棕色古代款猎人外套（长及大腿、皮革系带束合）＋同色系猎人长裤＋皮质腰带＋短筒皮质猎靴，古朴素净的实用猎装；画成华丽长裙、铠甲、王后式繁复宫装、现代装即 fail（与天灾女王高希纳姆的繁复长裙形象混同即整图 reject）。
5. [硬] 古拙长弓在手、弓不张箭不搭：一张古拙长弓由本人右手斜持于身侧偏前，弓弦松弛未张、弦上空无一物，箭只收纳于背后箭囊；弓整体缺失、弃置地上或背负即 fail；弓被拉开、弦上搭箭、箭矢缠电发光即 fail（常态持弓：不入战电光激发态）；左手食指怒指身前的斥责手势缺失计 partial。
6. [硬] 营地暮色场景：冰霜之国积雪山谷中的营地——兽皮营帐、木质货箱行装、半埋积雪的冰岩、远处层叠雪谷与冰峰暗影，天际暮色残照斜洒、暖光与青灰暗蓝交接；画成白天正午、船长室、珊瑚宫殿、酒馆街巷即 fail；背景出现清晰可辨的冰霜巨龙形象即 fail。
7. [硬] 无激发态特效（常态定妆红线）：画面任何位置不出现电光、闪电、银白电丝、深蓝发泽，无狂风缠绕、发丝上扬张扬，无体表幻鳞；马尾全程柔顺垂落、衣摆无风荡；出现任一激发态元素即整图 reject（档案红线：电光是激发态专属，常态马尾不带电，深蓝/银白电丝为最强误触发源）。
8. [硬] 全局负面（伪文字/火焰灯体/错配器物）：画面任何位置不出现文字、题字、符文、印章、徽记符号，弓身、箭囊、营帐与服饰上亦无可辨纹样文字；不出现篝火、火堆、火把、灯笼、烛火等任何燃烧或发光灯体，场景照明一律为暮色天光与雪地反光（原场景火堆已按暮色天光方案替换，出现火堆即 fail）；不出现黄金酒杯、骑士、牛角铠甲等错配器物与 FH-040 参考残留意象。
9. [硬] 无他人（独处红线）：画面除夏塔丝外不出现任何其他人物或人影——无苦修士、无巨人、无莫贝特、无王后高希纳姆；对峙对象不得入画，出现任何清晰或半清晰第二人影即 fail。
10. [硬] 构图完整与静态：人物全身完整入画、直立居画面主体（约占三分之二幅面），头顶与双脚清晰可见，双脚不触画面底缘、脚下积雪地面留白，头顶或双脚被裁切即 fail；营帐雪谷为背景衬景、不喧宾夺主；全画为静态定格，无奔跑、跳跃、发丝衣摆剧烈飘动等动态混乱。
11. [软] FH-040 风格锚：精密细腻的钢笔交错排线、暗调羊皮纸暖赭底色、做旧纸纹质感，如一页古老典籍中的整幅插图；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail；不得混入东方古风水墨写意笔触。
12. [软] 精灵气质：暴烈直接、用动作代替语言的年轻精灵女猎手，怒意中藏着对同伴的重情底色；画成温婉仙气、高贵冷艳的王室气质或老气横秋的中年感即作提示（气质为软性提示，不否决）。
