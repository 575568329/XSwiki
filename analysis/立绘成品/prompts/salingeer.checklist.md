# 萨林格尔 · 永暗之河畔的黑袍巨影（★X化终局·死亡烙印形态/终卷定妆）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 体量等高（第一识别点）：巨大身影与两侧苍白巨柱大致等高（档案锚「和周围的石柱差不多」），如一座黑塔矗立河畔；镜头大幅拉远，巨影自头顶至袍裾只占画面高度约三分之二；画成常规人形比例、明显矮于巨柱，或巨柱矮成栏杆矮墙即 fail；占画过满（超过画面高度五分之四、逼近满幅）计 partial。
2. [硬] 素黑重袍：素黑的重袍从肩到脚覆盖全身，厚重垂顺，通体乌黑无纹、无饰、无绣样、无镶边，袍面光洁无饰无羽，为画面唯一大面积深色块；袍面出现任何纹样、徽记、镶边花饰，或改画铠甲、王袍、东方袍服即 fail；袍色画成深蓝、深灰、深紫等非黑深色计 partial（素黑为档案服装恒量）。
3. [硬] 头面隐没：头颅低垂，兜帽般的袍影深深罩住头面部，头面完全隐没在黑暗中——头面完全隐没阴影为 pass；可见眼睛、面部细节（五官、面孔、肤色面容、任何面部光点或瞳光）即 fail（r1/r2 教训：苍白残焰眼两轮回潮为金橙全焰，本稿全面去眼，识别锚移交等高体量＋素黑重袍＋永暗之河＋苍白巨柱＋灰白雾）。
4. [硬] 袍身无羽：袍身出现任何羽毛即 fail（r1/r2 教训）；画面任何位置不出现白色羽毛、羽簇、羽翼结构，出现翅膀形态即整图 reject。
5. [硬] 永暗之河苍白巨柱场景：灵界卡尔德隆深处支流畔——灰白石阶收向水面、深暗与苍白交替的支流、两列苍白巨柱隔河夹峙且柱身素净、灰白雾气低弥、远景灰白石城虚化雾影；场景画成地面墓园、海底、宫殿大殿、荒野即 fail；巨柱出现文字、纹章、雕刻即 fail。
6. [硬] 独影红线（无眷属）：画面除祂外不出现任何第二身影——无活尸、无骷髅、无怨魂、无阴影、无河畔徘徊者的模糊人影；出现任何清晰或半清晰第二身影即 fail（死亡烙印唯一，身影只有一道）。
7. [硬] 无伪文字：画面任何位置不出现文字、铭文、题字、符文、印章、徽记与刻痕，巨柱、石阶、袍服一律素净；出现任何可辨文字或伪文字符号即 fail。
8. [硬] 无火焰灯体：场景中不出现灯、烛台、火炬、灯柱、吊灯、篝火等任何灯体或燃烧器物，苍白光一律来自雾气与河水等环境光，头面无任何光点；出现任何灯体、发光器物或面部光源即 fail。
9. [硬] 构图完整与静态压迫：全身自头顶至袍下摆完整入画，不触画面四缘、四周留有雾气空间，头顶被裁切即 fail；黑色重袍下摆收在脚踝上方，一双苍白赤足清晰可见、踏于河畔卵石滩上，袍裾触画面底缘或被裁切即 fail（r1 教训：长裾曳地触底被裁）；身躯侧身面向河面、一步一顿的沉重伫姿；全画为静态定格，无嘶吼跃动、衣袍剧烈翻卷等动态混乱。
10. [软] FH-040 风格锚：精密细腻钢笔交错排线、暗调羊皮纸暖赭底色、墨色分层与做旧纸纹颜料肌理，如一页古老典籍中的整幅插图；呈现厚涂油画感、赛璐璐动画感、照片写实即计 fail；不得混入东方古风水墨写意笔触（软性提示）。
11. [软] 死亡威压感：静态中传递神性死亡的沉默压迫——体量占画、黑袍唯一深色块与苍白雾光的明暗对峙、低垂隐没的头面、河畔空旷死寂；画面读来血浆恐怖猎奇、或威压感全无，仅作质量提示（软性）。
