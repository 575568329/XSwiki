# 王蝉 · 夜谒燕家（银面少主）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

袍色阶段说明：本图锁定阶段一（#254 夜谒）绿袍——阶段一有明文，★#260 踏叉临阵定型；阶段四黑衫变体（宗门改服，推断）不适用于本图，如需黑衫另行出图并在图题注明。

1. [硬] 银色恶鬼面具：脸上覆一张银色恶鬼面纹面具，覆住全脸、仅露双目；无面具、半截面具、面具褪挂颈侧或露出真容即 fail。
2. [硬] 暗红目光：面具双目孔后隐约透出一点暗红色目光；画成清晰完整的眼球特写、或瞳色为黑/棕/蓝/绿/金即 fail。
3. [硬] 绿袍：身穿青绿色（沉静偏墨绿）交领宽袖长袍；主袍色画成黑/紫/白/红即 fail。
4. [硬] 身材修长：青年男性、身形颀长清挺；画成壮硕武夫体格或少年稚气即 fail。
5. [硬] 无兵器无法器：画面无任何兵器与法器，尤其不得出现叉类长兵、碧绿巨叉、御叉飞行或坐骑；双手负于身后（或拢袖）静立。
6. [硬] 无血象凶物：画面无血云、血雾、血色浓雾、血鬼、骷髅（黑/金骷髅）及任何异兽凶物。
7. [硬] 场景与静态：深夜修仙家族大厅（幽深厅堂、木柱、案几屏风虚化剪影、冷月清光、地面留白），画面为静态定格；无战斗动势、无飞遁、无血色氛围、无火焰烛光（照明只允许冷月清光与昏暗墨色）。
8. [硬] 单人无混淆：画面仅银面具青年一人，无第二人物；不得出现紫衣艳容男子（田不缺）、貌美少妇（燕如嫣）、绿袍白发老者与双髻童子（李氏兄弟）等任何他人形象。
9. [硬] 全身完整：人物头顶到双脚完整入画、无裁切，全身约占画面三分之二，脚下留出一身位空白。
10. [硬] 无文字：画面任何位置（含匾额、衣饰、背景）不出现文字、题字、印章、徽记符号。
11. [软] 水墨风格：笔触潇洒写意、有大面积留白与宣纸纸纹质感、透明叠染色调；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
