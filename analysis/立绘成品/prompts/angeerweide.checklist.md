# 安格尔威德 · 诚实大厅史诗剪影（灰白巨龙螺旋盘柱）· 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 画面主体判定：画面主体为灰白色非人形巨龙，盘绕于大厅巨柱之间、位于画面中央并占主要视觉比重；画成空大厅风景、人形神祇或以其他物件为主体即 fail。
2. [软] 盘绕依托（规则 17/12 校准）：龙身在大厅场景中盘绕或有依附依托为 pass；依托物形制不限（巨柱／石柱／台基均可）——原"沿合抱巨柱螺旋三匝"口径三次不成（r3/r5/r6 中央细柱），校准为软性引导；大厅中央有柱不扣分。
3. [硬] 大厅场景：西幻古神居所的宏伟大厅——数十人合抱巨柱林立、四周色彩艳丽巨型壁画环列延伸、幽暗穹顶、无源幽暗微光；画成中式庙宇、洞窟、现代空间、户外天空或明亮白昼即 fail。
4. [硬] 龙首朝向规避（画法授权 r3）：允许巨龙形态完整细致刻画，鳞片、龙首、龙角均可辨，但龙首不得直视观者、口微闭、眼神朝向画面深处，以背对／侧对／俯瞰观者的构图规避"直视即失控"设定（2026-10-28 画法偏离授权路径，同亚当／赫拉伯根先例）；龙首直视观者、与观者对视，或出现正对观者的龙首面部特写即 fail。
5. [硬] 无侵蚀态特征：无竖瞳、无第三竖眼、无双瞳异色（淡金／鲜红一类的异色瞳）；出现任一侵蚀态眼睛特征即 fail（该特征为被侵蚀形态专属，剪影形态禁用）。
6. [硬] 无衣物王冠：巨龙为天然之躯，无衣物、饰品、鞍具、王冠、权杖等任何穿戴佩戴持握之物；出现即 fail。
7. [硬] 无他人：画面任何位置无人物、兽类或其他生灵（含柱下仰望的小人影），两侧壁画亦只有几何纹样与漩涡图案、不含任何人形图像；出现即 fail。
8. [硬] 无伪文字：画面无文字、符文、题字、印章、徽记符号，壁画之上只有图形与纹样；出现任何疑似文字的符号即 fail。
9. [硬] 无火焰灯体：无烛台、火盆、灯笼、火把等任何灯具与明火，采光为穹顶缝隙星光般清辉与壁画幽光；出现火焰光源即 fail。
10. [硬] 构图完整：远景构图，盘柱巨龙整体入画、无明显裁切，四周留出幽暗呼吸空间，画面重心沉稳庄重。
11. [软] 风格锚（FH-040）：中世纪暗黑奇幻墨线插画——钢笔交错排线、暗调羊皮纸暖赭色调、纸纹与颜料肌理、留白；呈现日式动漫赛璐璐感／厚涂油画感／照片写实即计 fail；画面整体呈光滑的数字厚涂渲染感计 partial（保持软性不否决，r1 教训：风格向数字厚涂漂移）。
12. [软] 史诗感：巨龙螺旋盘柱如史诗画卷、石化神灵般的时光沧桑与古神恢弘气度；画得比例渺小、气质平庸如普通巨兽或缺乏庄严感计 partial（不否决）。
