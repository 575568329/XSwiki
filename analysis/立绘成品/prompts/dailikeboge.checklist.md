# 戴里克·伯格 · 推门见光（祈光人推启巨门）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄体型气质：人物为尚未成年的少年，身高一米八上下、高大壮实而修长不臃肿，脸上残留稚气；气质沉默诚恳、质朴阳光，腰背挺直；不得画成成年壮汉或两米以上巨人，不得画成幼童，不得邪魅、阴郁、老成。
2. [硬] 发色发型：棕黄色的利落少年短发，清晰可辨；画成黑发/金发/红发/白发，或长发披落即 fail。
3. [硬] 黑色紧身衣：身穿一身黑色的贴身紧身衣裤，勾勒出高大壮实的身形，白银城特有常服、剪裁利落（领口袖型细节允许自拟）；主色必须为黑且贴身，画成宽松长袍、铠甲盔甲、银甲或其他色系服装即 fail。
4. [硬] 金芒双目（收敛口径）：双眸在暗处泛着淡淡的金色光芒；画成两轮微型太阳、刺目光球或自眼中射出光柱即 fail，画成红/蓝/绿瞳亦 fail。
5. [硬] 无兵器：画面无任何兵器——斧（含飓风之斧）、锤（含雷神怒吼）、枪矛（含无暗之枪）、剑、十字架（含无暗十字）、弓弩等均不得出现；手持、背负、别腰、倚门、遗落台阶均算 fail。
6. [硬] 场景要素：巨人王居所前的古老石阶洒满橘红黄昏光芒，少年双手按住一扇描绘黄昏场景的灰蓝色巨门奋力推顶，门上镶有一根根金色巨钉，门外白昼般的光明自门缝涌入、漫过少年全身；缺巨门、缺金钉或缺涌入光明即 fail。
7. [硬] 静态定格：整体为推门见光的静态定格——双手按门发力、身形稳定；出现挥击、奔跑、跳跃、腾空等剧烈动作或飞溅碎石等战斗特效即 fail；门外之光须为清亮白金辉光，画成火焰、爆炸或燃烧光效即 fail。
8. [硬] 构图规则：人物全身完整入画，头顶清晰可见，双脚不触画面底缘，脚下石阶留白；少年与巨门共占画面约三分之二且少年为绝对主体；头顶被裁或脚部完全不可见即 fail。
9. [硬] 全局负面：画面任何位置（含巨门壁画与服饰）不出现文字、标牌、铭文、徽记、印章、序列符号与卡牌；无火焰、明火、火光、火星等燃烧元素；除少年外不出现任何其他人物或人影（无白发老者、无队员剪影）；无东方古风飞檐、宫灯等东方构件。
10. [软] 瞳色与肤色自拟口径：虹膜本色自拟为与棕黄发协调的暖棕/琥珀色，肤色为健康的暖调少年肤色（原文均未明载，不得标注"原文复原"）。
11. [软] FH-040 风格锚：中世纪暗黑奇幻墨线插画——精密细腻的钢笔交错排线、暗调羊皮纸底色、暖赭色调与做旧纸感；呈现为写意古风水墨、厚涂油画、赛璐璐动画或照片写实即计 fail（软性风格提示）；画面中不得残留牛角铠甲骑士等风格参考意象。
