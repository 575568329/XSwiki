# 魏渊 · 午门青衣独立（卯时残夜）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄感：人物为面容白净俊朗的中年官员，成熟但不显老；画成白发老者即 fail，画成青年或少年即 fail。
2. [硬] 面部无须：唇下与颌下完全光滑、天生没有胡须（提示词已正向明写；年长官员先验易诱发白色长须，重点核对唇下与颌下）；出现任何胡须（唇须、山羊胡、络腮胡、胡渣青影、白色长须）即 fail。
3. [硬] 鬓发：乌黑长发为主、以白玉簪束起，仅两鬓微微染霜即 pass；全白头发或满头霜白即 fail；出现白色胡须即 fail。
4. [硬] 发饰：发间仅一支素色玉簪挽发；出现金冠、金束发冠或其他华丽头饰即 fail。
5. [硬] 主色与纹样：身穿一袭青色（青中偏深的天青色）长袍，衣身绣有繁复云纹；主色画成蓝/绿/灰黑等非青色系、或画成朱/紫官袍、或通体无云纹即 fail。
6. [硬] 制度性反差（核心）：全画面唯一穿青色衣衫者即主体魏渊本人；背景百官群像均为绯袍/紫袍，出现第二袭青衣即 fail。
7. [硬] 无兵器：全画面（含百官群像）无刀、剑、佩刀、刀鞘、兵器、甲胄；人物腰间出现兵刃或刀鞘即 fail。
8. [硬] 姿态与独处：双手自然垂于身侧、袖袍垂落，双手不握持绦带器物、不负于身后，独立于广场中央，身边无并肩人物，群像与主体保持明显距离（茕茕孑立、格格不入）；出现挥手/打斗/疾走等动态即 fail。
9. [硬] 场景要素：四要素齐备——残夜未尽的青灰天色、身后凹字形展开的午门城门楼（凹字形城台轮廓可见即 pass，形制近似即可不苛求）、宽阔广场石面、远处三五结队的绯紫百官虚化群像（群像不绘清晰面目）；缺任一即 partial/fail。
10. [硬] 无灯火光源：画面任何位置无灯笼、火把、烛火、灯火及其光晕，照明一律为残夜天光与雪光映照；出现任何灯火光源即 fail。
11. [硬] 静态与无文字：画面任何位置无文字、匾额题字、印章、徽记符号；人物静立，无打斗、挥手、疾走等动作。
12. [硬] 全身完整与落位：人物头顶与双脚均完整可见、双脚不触底缘（双脚位置高于画面底缘），无任何裁切，违反即 fail；画面底缘应为广场砖地而非人物袍摆，脚下有砖面留白；辅助判据：镜头位置与人物膝盖齐平，能同时看到头顶与双脚。
13. [软] 水墨风格：笔触潇洒写意、有大面积留白与宣纸纸纹质感、透明叠染色调，青色淡彩为主、绯紫仅作远景点睛；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
14. [软] 档案细节与缺项：高鼻薄唇、眼角浅浅鱼尾纹、双目深邃内蕴沧桑为档案细节，画不全仅作提示；腰带/靴履制度与身形骨架为档案空白项，按「清瘦文人身」默认处理，不作为否决依据。
