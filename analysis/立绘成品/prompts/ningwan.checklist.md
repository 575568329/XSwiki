# 宁婉 · 寒夜（紫府定型）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄感：人物为二十出头观感的年轻成年女子，容貌温婉绝美、身姿娉婷；画成少女稚气脸，或画成中年/老年面相即 fail。
2. [硬] 眼眸：双眼为黑白分明的柔和眼眸，瞳色为深黑；画成金色/紫色/蓝色/异色瞳即 fail。
3. [硬] 着装逐件：身穿雪白长裙（自肩及地、衣袂飘飘），腰间另系一条纤细白绸，全身主色为纯白；主色画成青/红/紫等其他色系，或画成铠甲、男装即 fail；画面中出现面纱/蒙面即 fail（面纱属练气期一次性行装，定型阶段不得出现）。
4. [硬] 姿态与无兵器：人物双手拢于身前袖中、垂眸静立，神态安静温婉；画面中不出现任何兵器（剑、刀、枪、旗、杖等），人物手中与身周均无兵器类物件，出现任何兵器即 fail；出现飞行、施法、化作飞雪的变形或战斗动作即 fail。
5. [软] 发式发饰（自拟软项）：黑发素雅挽起，发间有素白色发带与一支白玉簪，无钗环等重型华丽发饰；与描述有出入仅记 partial，不单独否决。
6. [硬] 场景要素：画面为青池峰顶月夜，须同时具备五要素——夜空中的明月、人物所立的青石石台及向下延伸的石阶、石阶旁松柏青影、脚下翻涌的云海、画面下方山石表面覆着的薄雪与点点青苔；缺任一要素即 fail。
7. [硬] 光效收敛：明月与画面中一切光效均为清冷柔和的辉光；出现火焰、明火、爆炸、施法爆发或刺眼强光即 fail。
8. [硬] 双脚可见：人物双脚并立、清晰可见踩在青石石面之上，裙裾分垂两侧、不掩双足；双脚被裙摆完全遮住、悬空或被裁切即 fail。
9. [硬] 全身完整：人物头顶到双脚完整入画、无裁切，人物全身约占画面三分之二。
10. [硬] 石面无伪印章：画面下方山石石面上除薄雪与青苔外干净无物，不出现红色印章图纹、落款印痕或任何红色圆形/方形图记；山石上出现任何红色图纹即 fail。
11. [硬] 无伪文字：画面任何位置（含衣饰、山石、背景）不出现文字、题字、印章、徽记及任何符号状图纹。
12. [硬] 画风非照片：整图为伊吹五月式手绘水墨淡彩，笔触潇洒写意、有宣纸纸纹质感与大面积留白；呈现照片写实、厚涂油画感、赛璐璐动画感或3D渲染质感即 fail。
