# 杨锐仪 · 雷暗青铜台阶（降临）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄感与相貌：男性，看上去三十岁上下、介于青年与中年之间，无少年稚气、无老年花白须发与皱纹衰态；面容平凡粗粝、肤色偏深、眉目平淡不起眼，颧骨与下颌线条硬朗、颌下隐有青色胡茬，带常年行伍的武人粗粝感；画成二十二三岁俊雅秀气的主角脸即 fail。
2. [硬] 黑袍本体：一身暗沉乌黑布质长袍，主色为黑、哑光发闷、带一层沉沉灰调；主色画成红/白/蓝紫等其他颜色、画成金属铠甲或利落劲装即 fail。
3. [硬] 连鞘负剑：背后斜负一柄连鞘长剑，剑鞘乌沉沉深色木质、鞘身平直，剑柄缠深色丝绦、柄首为圆形暗铜色剑首；剑刃任何部分露出鞘外、人物做出拔剑动作即 fail。
4. [硬] 抱拳见客：右手握拳、置于左手掌心，横于胸前，微微颔首，双臂双手完整可见；画成掐诀施法、负手而立、叉腰或按剑即 fail。
5. [硬] 泥牛灵宝：人物身后数级台阶处有一只小巧泥牛牛犊，通体深浅不一的湿润泥胎色（土黄至深褐），圆身短腿、泥壳带手塑肌理；画成带黑色皮毛的真牛、金属牛或大体型壮牛即 fail。
6. [硬] 青铜长阶：画面中有一道宽阔青铜台阶自高处铺展而下，阶面为带暗绿锈色的青铜金属质感；人物立于台阶中段某一级踏面上，画成站在平地或悬空即 fail。
7. [硬] 高处青铜大殿：青铜大殿高踞长阶尽头的平台之上，殿身古朴青铜色，殿身饰抽象云纹曲线纹样，殿顶轮廓明显高于人物头顶；殿宇缺失、悬空无平台或画成常规木构宫殿配色即 fail。
8. [硬] 暗色浓云天幕：天空为铁灰色浓云低压，云层中不得出现枝杈状闪电，只允许云缝间隐隐银白辉光；出现火光、爆炸、金色光柱或人物周身光环特效即 fail。
9. [硬] 全身完整：人物头顶到双脚完整入画、无裁切，全身约占画面三分之二，脚下所立青铜台阶踏面完整可见。
10. [硬] 无文字符号：画面任何位置（含殿身、阶面、衣袍、泥牛体表、云间）不出现文字、题字、匾额、印章、符箓字迹；装饰纹样只允许抽象云纹曲线。
11. [软] 束发素冠：黑发整齐束起、戴一枚素净深色小发冠（原文未写发式，为自拟软项，仅作提示不否决）。
12. [软] 水墨风格：笔触潇洒写意、有大面积留白与宣纸纸纹/颜料肌理、透明叠染色调；呈现厚涂油画感/赛璐璐动画感/照片写实仅作质量提示（软性风格提示）。
