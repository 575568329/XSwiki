# 安德森·胡德 · 街口口琴艺人立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 金发三七分：头发为金色短发，梳理整齐作三七分斜分、额前无碎发；画成白发/棕发、披发、无分缝乱发或寸头即 fail；额前碎发遮额即 partial 提示不否决。
2. [硬] 碧绿眼睛：双眼瞳色为碧绿色（翠绿/祖母绿），不得画成蓝/棕/黑/灰/红瞳。
3. [硬] 白衬衣×黑马甲：白衬衣领口最上两颗扣子敞开；黑马甲罩于衬衣外且前襟完全敞开不扣、内层白衬衣可见——马甲扣合、内衬不可见或领口全系到喉即 fail；通身不得出现披风与甲胄。
4. [硬] 双手均无手套：双手都不佩戴任何手套，双手肤色正常、五指裸露；任何一只手出现手套即 fail（档案原载"左掌单戴"经两轮生成实证屡致手套换位，手套元素整体移除，识别锚点改为金发三七分＋碧绿眼＋白衬衣黑马甲＋口琴）。
5. [硬] 口琴与唇位：一支银白色小口琴停在唇边，口琴为银白色金属小件；画成金色/深色、离唇远持或消失即 fail（持握左/右手不在此条判定，见软项 12）。
6. [硬] 无兵器：画面任何位置不出现刀剑、短剑、匕首等兵器（含手持、背负、腰后连鞘、倚墙、地面遗留）；出现任何刀剑形态即 fail（"死亡短牙"短剑按六批实证画不准的禁配决议整体不入画）。
7. [硬] 帽类配属：脚边石板路上有一顶倒扣的深色圆顶礼帽、帽内有黄铜硬币，礼帽不得戴在头上；不得出现猎鹿帽（前后双帽檐样式）。
8. [硬] 禁配清单：画面不出现圆领衫＋棕夹克＋鸭舌帽（格尔曼·斯帕罗海装）、不出现单片眼镜、不出现红焰羽翼；除主人公外无其他人物或人影。
9. [硬] 静态定格与全身完整：全画为一帧静止定格，口琴停在唇边无吹奏动态模糊，无挥舞、跳动等动态混乱；人物头顶到双脚完整入画、无裁切，约占画面三分之二，脚下留白。
10. [硬] 无文字：画面任何位置（含标牌、招牌、墙面、衣饰、硬币上）不出现文字、招牌字、铭文、印章、徽记符号。
11. [软] 年龄气质与自拟项：年轻男子（原文仅"年轻"，"二十岁上下"与"深色旧皮鞋"均为自拟软项）、身材中等、体态矫捷、容貌英俊，眉眼带笑、乐天戏谑带挑衅光环的气质；画成中年沉稳或稚气少年即计 partial（软性提示，不否决）。
12. [软] 左手持口琴：口琴由左手持握、右手五指裸露自然垂于身侧为 pass；持握手画反即 partial 提示不否决（软性提示）。
13. [软] FH-040 风格锚：中世纪暗黑奇幻墨线插画——精密细腻的钢笔交错排线、暗调羊皮纸底色、暖赭统调与做旧纸感，淡金与冷银白仅作点睛，如一页西幻旅行见闻录插图；呈现为写意古风水墨、厚涂油画、赛璐璐动画或照片写实即计 fail（软性风格提示），画面不得残留牛角铠甲骑士、石阶遗迹等风格参考意象。
