# 李项平 · 眉尺山试弓（掌兵家主定型像）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄感：成年青年男性修士（青年至中年之间的定型期），无少年稚气、无老年衰态；眉形平缓而长、两颊削瘦、肩膀宽大。
2. [硬] 灰黑眸色：双眼眸色为灰黑色，不得画成金瞳/蓝瞳/绿瞳/红瞳等任何异色瞳。
3. [硬] 皮甲：身上披挂深褐色皮甲，护肩护臂齐整、甲片皮索编缀、形制简朴；画成道袍/文士宽袍即 fail，甲面出现繁复鎏金纹或兽纹也计 fail。
4. [硬] 青乌弓：人物双手握持一把长弓，弓身青灰色、弓弦莹白；画成弩、短弓，或弓身通体乌黑（末代朽态）即 fail。
5. [硬] 箭与箭袋：腰后斜挂皮质箭袋，袋中插有数支木杆白羽箭；弦上所搭箭静止凝定，画面无飞行中的箭、无箭矢轨迹、无白芒命中特效。
6. [硬] 长刀连鞘：腰间悬一把连鞘长刀，仅见刀鞘与缠绳刀柄；出现拔刀出鞘、刀身外露即 fail。
7. [软] 发式（软项·自拟）：黑发以素色发带束起、簪原木色木簪为从简自拟设定（原文无发式记载）；束发/披发形态不作否决，但出现华丽金冠或珠翠满头即计 fail（软性提示）。
8. [硬] 场景要素：白日荒废山坡上有一块巨大的青石，人物一脚踩踏青石作引弓瞄准姿态，瞄准方向的远处有一座低缓小坡地；青石、荒坡、远坡三要素缺一即 fail。
9. [硬] 无燃烧元素：画面任何位置无火焰、明火、火光、烟气、火星；全画光源为清朗白日自然天光，出现任何火苗形态即 fail。
10. [硬] 全身完整：人物头顶到双脚完整入画、无裁切，全身约占画面三分之二，脚下青石石面与坡地草地完整可见。
11. [硬] 无文字：画面任何位置（含弓身、箭杆、甲片、刀鞘、发带、山石）不出现文字、题字、印章、徽记符号。
12. [软] 水墨风格：笔触潇洒写意、有大面积留白与宣纸纸纹质感、透明叠染色调；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
