# 贝尔纳黛·古斯塔夫 · 黎明号船头迎风暴（★海上定妆/翡翠城传承与黎明号远航期 #1293）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 发色与发型（第一识别点）：栗色长发自然披下、垂过肩背；发色画成金发/黑发/红发/银发即 fail；画成挽发盘发（陆地正式场合态）计 partial；短发即 fail（档案红线：栗色为全书唯一明示发色，不可偏移）。
2. [硬] 瞳色与眼神：蔚蓝深邃、如浓缩大海的湛蓝眼眸；画成紫/黑/绿/金/红瞳即 fail；眼神画成失焦蒙雾的预言态、湿润流泪或情绪激荡即 fail（此帧为平静从容的凝滞瞬间）。
3. [硬] 容貌与区分红线：又长又直的眉、美丽而高冷疏离的成熟女性（三十上下、身材高挑比例极好）；画成少女或老妇即 fail；出现厚重框架眼镜即整图 reject（嘉德丽雅专属封印道具，贝尔纳黛全文无戴镜记录）；出现黑色巫师长袍或星辰状独眼徽记即 fail（同属嘉德丽雅，勿混入）。
4. [硬] 海上四件套着装：蕾丝缎带花朵白衬衣＋深蓝色简单外套＋米色长裤＋黑色皮靴，缺一即 fail；改画橄榄绿长裙＋老气黑纱软帽（陆地定妆装）即 fail；改画中世纪袍服铠甲即 fail。
5. [硬] 器物禁配：画面不出现许愿神灯（#1281 已托付嘉德丽雅）、苍白金属面具、钻石竖眼额饰、隐身帽——任一出现即 fail（面具/额饰/隐身帽仅限原始岛屿行动特例，勿日常化）；出现钢笔腾空自书、豌豆藤等异场元素亦计 fail。
6. [硬] 船头姿态：独立于船头最前端，身姿挺拔、下巴微抬、平静注视远方风暴，气势内敛；画成抓握缆绳奋力挣扎、跌坐踉跄、奔跑挥手等剧烈动作即 fail；双眼紧闭或低头蜷缩即 fail。
7. [硬] 风暴海场景要素（静态化处理）：雷暴海面"风暴间隙"的凝滞瞬间——厚重风暴云层低垂、深色巨浪涌高而未垮塌、华丽巨大的维多利亚式帆船船头与帆桅在侧后；闪电只允许远处天际一线微弱冷光（不劈落、不触及人物、无扑面雨丝），闪电落人物身上或巨浪拍碎船身即 fail；场景画成平静港湾、港口码头、甲板室内即 fail。
8. [硬] 无他人红线：黎明号无船员自航，甲板空无一人，除贝尔纳黛外不出现任何水手、人影或第二张面孔，清晰或虚化均不允许；出现任何他人即 fail（尤其黑发紫眼年轻男子——克莱恩勿同框）。
9. [硬] 无伪文字：画面任何位置不出现文字、题字、旗帜字母、悬赏令、印章、徽记符号；船帆与船身上无可辨铭文即 pass。
10. [硬] 构图完整与占比：人物全身完整入画，头顶与双脚清晰可见，双脚不触画面底缘、脚下甲板木纹留有空隙，头顶或双脚被裁切即 fail；船头＋人物约占画幅三分之二、风暴海天约留三分之一，人物缩成远景小点即 fail。
11. [软] FH-040 风格锚：精密细腻的钢笔交错排线、暗调羊皮纸暖赭底色、做旧纸纹质感，如一页古老典籍中的整幅插图；海天冷蓝以"冷调薄罩不遮纸纹"的罩染处理、纸纹在冷色下仍可辨；呈现厚涂油画感/赛璐璐动画感/照片写实即提示；混入东方古风水墨写意笔触亦提示。
12. [软] 点睛与特效克制：全画唯一点睛冷色为深蓝外套与蔚蓝眼眸的一线湛蓝、周身童话魔法微光（极淡透明涟漪＋细碎虹彩光点）的克制点缀；出现重型奥术特效、大面积彩色光效或满屏虹彩即提示；闪电画成画面主光源、亮度压过人物即提示。
