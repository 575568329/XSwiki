# 赫拉伯根 · 烛下圣像（第四纪古殿 #269）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 造像语境与老者身形：画面主体为一尊巨型石雕圣像，形象为年迈老者（老者体态、垂落长须）；画成中青年、活人神祇显圣或真身临世即 fail（档案实证：全书无真身显圣，唯一人形锚点＝第四纪兜帽老者造像，#269/#603/#758 三处互证，人形生图必须停留造像语境）。
2. [硬] 兜帽覆面（身份硬锚点）：**整个面部完全沉入兜帽纯黑阴影、无任何五官可见为 pass**（2026-10-28 用户择定画法：阴影吞没全脸，替代原文「只露嘴角皱纹」定妆句，以根除眼部先验；此为经用户批准的画法偏离）——头深深低垂到胸前，兜帽阴影中唯一可见的是自阴影深处垂落的长长白色胡须；眉/眼/眼睑/嘴角任何可见均计 fail，抬眼正视观者或面部朝向镜头同罪；无须或须色画成黑/灰/棕亦 fail（档案实证：眼部全书从未呈现；四轮「帽檐压鼻梁」物理隐藏均失败——鼻梁以下留五官必然诱导画出眼部）。
3. [硬] 持物：书册嵌眼圣徽一体——双手在腹前捧着一本厚重的素色书册（纸黄色、页上无可读字符），低头注视书册，书封正中镶嵌一枚黄铜色全知之眼圣徽为 pass（睁眼/闭眼皆可——2026-10-28 用户授权按图像学语义校准：闭合眼睑对抗全图先验 3 轮全败，撤销该自拟约束）；眼圣徽脱离书封、与书分持两手仅 partial（二轮修订约束：两物合一，眼睛不单持）；出现第二本书册/卷轴/多余眼状物、书册画成卷轴或石碑、圣徽无铜色即 fail（档案实证：#269「拿着书册和全知之眼」，圣徽同构「位于摊开书本上的全知之眼」#567/#612；嵌眼于书封为合一处理，属自拟补全；首轮 reject 的双书册冗余即卡此项）。
4. [硬] 素白＋黄铜色系：圣像袍服与长须为素白，构成全画大面积亮色块；金属色仅限黄铜点缀（书封嵌眼圣徽、袍缘铜线、塔身铜睛、门楣徽记），克制收敛；主色画成黑袍/金袍/红袍，或画面主调偏出墨线暖赭加铜白体系即 fail（档案实证：色彩体系＝素白＋黄铜/铜金＋书册墨黑纸黄）。
5. [硬] 白塔背景：祈祷室后壁存在一幅白色高塔浮雕/壁画，塔身高耸、通体偏白；塔上黄铜眼睛仅零星数枚点缀，密布铺满塔身计 partial 及以下，画面完全没有白塔元素即 fail（档案实证：白塔为权柄象征「任何形象必带」，#1421「一座缀着诸多黄铜眼睛的白色高塔」；本图按约束将铜眼收敛为点缀，以殿内浮雕呈现属语境自拟）。
6. [硬] 场景要素与灯火约束：地下远古石殿祈祷室——圣像立于石阶高台、门楣刻「摊开书本＋眼睛」圣徽浮雕、马灯昏黄光晕、一线天光光柱与浮尘；灯火仅限马灯玻璃罩内一点昏黄，无火把烛台蔓延；缺石阶、画成露天或现代教堂即 fail；门楣圣徽浮雕未呈现仅计 partial（2026-10-28 自拟项降软：门楣刻徽为语境自拟补全非档案实证，两轮实画均出卷草纹）（档案实证：#269 原景「小型祈祷室和巨型雕像的完美融合，像前有台阶」，马灯昏黄光晕、尘埃浮于光柱）。
7. [硬] 禁龙形与逾矩持物：画面任何位置不出现龙、巨龙、龙鳞、龙角、龙翼或龙形剪影、龙纹浮雕；圣像除托持的嵌眼书册外不持武器、权杖、法球，不出现第二本书册或另持眼状物，头无冠冕头环；任一出现即 fail（档案实证：「智慧之龙」本尊鳞色、体量、角翼全书零描写，禁自绘龙形；神本体无武器、冠冕、权杖类描写）。
8. [硬] 无文字无他人且静态：画面任何位置（书页、门楣、塔身浮雕、袍面、墙面）不出现文字、铭文、字符、印章符号；除圣像外无任何其他人物或身影；全画为静止定格瞬间，灯火光晕凝定、浮尘悬停，无动态混乱。
9. [硬] 全身完整：圣像头顶到基座双脚完整入画、无裁切，圣像连同基座约占画面三分之二，像前石阶向下延展留出空区。
10. [软] 自拟细节（原文未述，按档案警示补全并标注非原文）：石材取素白偏灰（「洁白石雕」定语出自同厅大地母神像句，不可直接挪用，仅自拟近似色）；袍服形制参照教会「镶黄铜丝线的素白长袍」改作造像衣纹；书册开合厚薄、门楣圣徽刻法、白塔以殿内浮雕呈现的方式均为自拟；画得协调统一即 pass，出现明显穿帮混搭即计 fail。
