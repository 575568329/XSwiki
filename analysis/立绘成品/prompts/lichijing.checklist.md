# 李尺泾 · 倚山城头立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄容色：人物为观感二十上下的俊秀青年（逆龄少年脸，实际年岁三十出头），眉目俊秀、唇边带温和笑意；画成中年/老年，或面容凶戾阴沉即 fail。
2. [硬] 白袍：身着素白长袍且为唯一主体着装，主色为白；画成青色弟子袍、黑袍或杂色华服即 fail。
3. [硬] 束发：黑发长发束起（高束造型），无披发、散发遮面即 pass。
4. [硬] 无兵器：画面中不出现任何兵器（刀、剑、剑鞘、剑柄、弓、戟等一切武装元素），人物双手拢于宽大的袖中、手中无持物；画面任何位置出现剑/刀/鞘即 fail。
5. [硬] 静立姿态：人物为静立姿态，双手拢于袖中；出现跃起、挥砍、施法掐诀等动作瞬间即 fail。
6. [硬] 山城场景：画面中有一座依山而建的砖石山城，可见青灰色城墙与垛口，人物立于城头垛台之上；无城墙垛口或人物悬空无立足处即 fail。
7. [硬] 赤红剑气飞鸟：半空悬浮漫布多只（三只以上）赤红色飞鸟形剑气，羽翼分明、分布于人物四周；红鸟画成真实猛禽、或数量仅一只即 fail。
8. [硬] 光效收敛：画面任何位置无火焰、明火、火星等燃烧元素；赤红飞鸟与一切光效均为辉光/流光形态，出现火苗形态即 fail。
9. [硬] 无文字：画面任何位置（城墙、袍服、背景）不出现文字、匾额、题字、印章、徽记符号。
10. [硬] 全身完整：人物头顶到双脚完整入画、无裁切遮挡，脚下城头砖石地面完整可见。
11. [软] 水墨风格：潇洒写意墨线、透明叠染、大面积留白、宣纸纸纹与颜料肌理；呈现厚涂油画感/赛璐璐动画感/照片写实计 fail（软性风格提示）。
12. [软] 自拟软项：漆黑眼眸、交领广袖形制、素色腰带、修长身形、青灰色城砖均为原文未写、按气质从简自拟项，仅作符合度提示，不否决。
