# 弗兰克·李 · 船头的巨熊（★后期定妆·序列5"德鲁伊"期/第1261章）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 体格与浓密汗毛小臂（第一识别点）：三十岁左右健壮壮汉，肩宽背阔、胸膛厚实、双臂粗壮，静立如"人形巨熊"般敦实厚重（剪影体量厚重，但身形始终为人类）；袖口高高挽至肘上，裸露小臂覆满浓密棕色汗毛、密如一件棕色毛线套袖，以细密排线画清画实；画成瘦削身材、汗毛稀疏或小臂光洁即 fail（档案红线：小臂汗毛为全书贯穿识别点，不可弱化）。
2. [硬] 蓝色眼睛与人类面孔：蓝色瞳孔，画成褐/黑/金/绿/红瞳即 fail；面孔为人类憨厚方圆脸、五官清晰、十指清晰的人类双手，出现任何兽类五官轮廓即 fail（与第7条熊化红线联动）。
3. [硬] 敞领白衬衣＋淡蓝帆布裤：白色衬衣没系上面两颗扣子、领口敞开露出浓密棕色胸毛；下身为厚帆布淡蓝色直筒长裤，脚踩深褐色旧皮靴（推定色，画成其他深色仅提示）；衬衣扣到喉部遮住胸毛、主色画成深色大副制服或大衣、头上出现圆边帽（初登场专属，后期定妆不戴帽）即 fail。
4. [硬] 船头眺望姿态：独立于船首最前端甲板、面朝海平线远眺，双脚分开沉稳站立、双手自然扶于船首矮栏；背对大海、坐卧倚桅、攀爬帆索或任何剧烈动作即 fail。
5. [硬] 憨厚笑意：嘴角上扬、明朗纯真的憨厚笑容（"笑得像两百磅重的孩子"的转译），眼神澄澈无阴霾；画成阴郁沉思脸、谈实验的狂热脸、狞笑或痞气即 fail。
6. [硬] 晨光海面场景：薄雾清晨的巨帆船"未来号"船头——金橘色晨曦自海平线漫染天际海面、碎金反光铺向脚下、身后桅杆与米白巨帆层层隐入薄雾、脚下木质甲板；场景画成船舱、码头、夜航、正午强光或风雨浪涛即 fail。
7. [硬] 无熊化元素与兽毛严格限位（档案红线，r1 修订）：浓密的棕色汗毛只允许生长在两条小臂的手肘至手腕一段（棕色毛线套袖）；兽毛超出小臂范围——覆盖颈部、脸颊、下颌或双手手背——即 fail（r1 教训：熊化先验渗入）；全画不出现熊耳、兽爪、熊掌、兽吻獠牙等任何动物化突变；双手为十指清晰、手背干净光滑的人类双手；胸毛仅限领口敞开处、止于胸口，向上蔓延至颈项下颌即 fail（熊化半化仅第664章应激受击态，非常态，本图禁入）。
8. [硬] 无蘑菇菌类与无液体喷溅（档案红线）：不出现任何蘑菇、菌盖菌柄、菌类群落、孢子雾气等真菌意象；不出现牛奶、乳白液体喷泉与一切液体飞溅，衣衫甲板干燥；甲板帆缆无植物疯长、无藤蔓缠绕（产奶藤蔓名场面元素一并禁入，勿串场）。
9. [硬] 全局负面：不出现任何文字、题字、船名牌、印章、徽记与纹章符号（帆面船身无可辨图案，无伪文字）；不出现火焰、明火、烛火、灯笼、油灯、提灯等任何灯体与燃烧元素，全画光源一律为晨曦天光与海面反光（出现任何灯体火苗即 fail）；不出现刀剑、枪械、法杖、兽角头饰、神辉光环与翅膀等武器与特效（序列5无神性外显，"德鲁伊"仅为序列名，勿套 RPG 德鲁伊模板）；不出现骑士、牛角铠甲、石阶遗迹等 FH-040 参考残留意象。
10. [硬] 独处红线与构图完整：除他本人外不出现任何其他人物或人影——桅帆间无水手轮廓、甲板后方无人影，亦无海鸟与动物伙伴；人物全身完整入画，头顶与双脚清晰可见，双脚不触画面底缘、脚下木甲板留白，头顶或双脚被裁切即 fail；人物为画面绝对主体约占三分之二幅面，桅帆海天占比克制、不喧宾夺主；全画一帧静态定格，无奔跑挥手、衣发剧烈飘动等动态混乱。
11. [软] FH-040 风格锚：精密细腻的钢笔交错排线、暗调羊皮纸暖赭底色、做旧纸纹质感，如一页古老典籍中的整幅插图；呈现厚涂油画感、赛璐璐动画感或照片写实即提示（软性风格提示，不计硬性 fail）。
12. [软] 憨厚纯粹气质：爽朗大孩子般纯粹热忱的劳动者气质，"大海上最疯狂的农夫德鲁伊"的人物底色；画成阴郁反派、老学究或持杖长者模板仅作提示。
