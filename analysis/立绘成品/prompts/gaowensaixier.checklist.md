# 高文·塞西尔 · 伪神颅骨大典（开国大典）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 统一容貌锚点：成年壮年男性（约三十五岁武人感，无少年稚气、无衰老特征），国字脸、浓密络腮胡、棕色短发；深色眼睛（原文未写眼色，深色为推测处理）；无束发成髻、无发冠、无任何东方发饰。
2. [硬] 体格：身高近两米、肩宽背阔的魁梧重装骑士体格，双手扶碑站立沉稳如山岳；画成修长瘦削体型即 fail。
3. [硬] 黑色主色系：黑色板甲戎装、黑色高台、黑色徽记布幔构成画面主色，通体深沉质感；主色画成红/白/金或昔日王室华丽风即 fail。
4. [软] 甲胄形制：按西幻重型板甲惯例正向自拟（胸甲、肩甲、臂甲、护胫结构齐整），哑光黑钢质感；细节属推测补全不作硬判，但画成东方札甲、皮甲或布袍计 fail（软性形制提示）。
5. [硬] 无剑无刃：人物本人身上、手中及周边三尺内无任何剑/刃/鞘类物品（远景军阵的长兵剪影不算）；人物腰胯无鞘袋/挂囊；双手交叠扶碑、手中无武器，碑面无文字刻痕、无光效。
6. [硬] 无自发光：除天光外画面中无任何自发光物体，无发光武器、发光纹路、光带、光斑；出现爆发式火焰、蔓延火舌、照亮全场的强光即 fail。
7. [硬] 场景四要素：巨大伪神颅骨、顶端黑色高台、两侧静态展开的钢铁双翼、垂落至地的帝国徽记布幔；缺任一即 fail。
8. [硬] 军阵与静态：下方有全封闭式头盔的钢铁游骑兵方阵列队，远处观礼人群剪影；全场无战斗、施法、挥砍等任何动态动作。
9. [硬] 禁持禁戴：无王冠、冕旒、权杖；无盾牌（守护者之盾为遗失之物，现世线场景不得出现）。
10. [硬] 无文字：布幔徽记、甲片、旗帜、背景等画面任何位置无可读文字、题字、印章；帝国徽记仅作抽象几何图案。
11. [软] 构图完整：人物头顶到腿部完整入画、无裁切，碑体遮挡双脚按先例记 partial 不否决；镜头拉远，颅骨高台与下方军阵同现画面。
12. [软] FH-040 风格落地：精密细腻的钢笔交错排线、暗调羊皮纸暖赭色调、纸纹颗粒质感与沉稳留白；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
