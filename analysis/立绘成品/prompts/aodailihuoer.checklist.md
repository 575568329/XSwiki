# 奥黛丽 · 贵族宴会厅（宴会装定型）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄与气质：画面主体为一位年轻贵族少女，面容纯美甜美、五官精致，气质优雅端庄矜持，有养尊处优的名门闺秀感；画成幼态稚气孩童或成熟妇人、中年感即 fail。
2. [硬] 表情红线：唇边为浅淡矜持的微笑，绝不出现嘟嘴表情，亦无张口大笑等夸张表情；出现嘟嘴即 fail（作者声明全文嘟嘴描写另有其人，属档案避坑项）。
3. [硬] 金发碧眼：金色长发柔顺润泽似暖金，优雅盘束成髻并缀珠宝发饰，画成散发披落、发色棕/黑/银/红即 fail；双眼为碧绿色/绿宝石般晶莹清澈，画成蓝/灰/黑/金瞳即 fail（原文一处"蔚蓝眼眸"为用词漂移，不采）。
4. [硬] 宴会装本体：立领、高腰、羊腿袖的浅白色华丽长裙，上身紧束、腰肢极细，多层次蛋糕剪裁由鲸骨裙撑撑起、廓形宽大圆润，裙缘缀蕾丝与荷叶边；主色画成深色/浓艳色、无裙撑廓形或画成现代礼服即 fail。
5. [硬] 珠宝手套与舞鞋：耳坠、项链、戒指与发饰闪着细碎珠宝微光，右手笼白纱手套；脚穿白色舞鞋，鞋面缀着玫瑰花瓣形状的小颗钻石装饰，舞鞋在裙摆前缘下方完整可见、无遮没无裁切；舞鞋缺失或被裙撑完全遮住即 fail，鞋面钻石装饰细节与描述有出入仅计 partial、不作否决（维持）。
6. [硬] 姿态：右手虚提裙摆、微微屈膝、上身端正微俯的贵族屈膝礼，目光沉静、神态矜持，为一帧静态定格；无匕首、佩剑、手杖等任何兵器入画，无走动、裙摆飘飞等动态。
7. [硬] 场景要素：贵族宴会厅一隅——高大落地窗帘幕与浅影、深色木质护墙板与厚重帷幔、柔和均匀的暖色光线笼罩人物、光洁地面映浅暖影，头顶与四壁都看不到任何灯具、烛台与光源；无宴会厅空间感即 fail；远处人群只允许虚化为朦胧暖色剪影，出现其他清晰人物面孔或身形即 fail。
8. [硬] 全局负面纪律：画面任何位置无文字、题字、请柬铭牌、印章与徽记纹章；出现任何灯具、烛台、吊灯、火苗（火焰、明火、烛火、燃烧粒子、火星）即 fail，厅内光线只以柔和暖晕与清亮微光呈现、不露出光源；无银白面具、红宝石项链、黑色薄纱长手套、钻石领针、斗篷、黑色骑手服等后期形态元素；无犬只或其他动物；无龙鳞、金色竖瞳、蒙眼丝巾等异变元素。
9. [硬] 构图完整（规则式）：人物全身完整入画，头顶与双脚都清晰可见，双脚不触画面底缘，脚下地板留白；鲸骨裙撑宽廓形已预留充分横向空间，白色舞鞋不被裙摆遮没、不被画面下缘裁切。
10. [硬] 色彩纪律：全画以浅白、暖金、暖赭与深褐的沉郁层次为基调，唯一点睛清色为碧绿眼眸与珠宝细碎冷光；出现第二处大面积鲜艳异色亮斑即 fail。
11. [软] 场景陈设自拟项：护墙板样式、帷幔纹样、吊灯形制等宴会厅陈设细节原文零描写，属自拟项，符合西幻维多利亚式贵族宴会厅基调即可；与预期有出入仅作质量提示，不单独否决。
12. [软] FH-040 风格锚：精密细腻的钢笔交错排线、暗调羊皮纸底色、暖赭统调与做旧纸感，如一页贝克兰德贵族夜宴古卷里的整幅插图；呈现为厚涂油画、赛璐璐动画或照片写实即计 fail（软性风格提示）；画面不得残留牛角铠甲骑士等风格参考意象，不得混入东方古风水墨写意笔触。
