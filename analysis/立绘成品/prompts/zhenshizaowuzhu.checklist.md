# 真实造物主 · 半毁神庙倒吊神像（漆黑十字架与倒吊剪影）· 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 画面主体判定：画面主体为漆黑巨大十字架＋倒吊人形剪影，二者位于画面中央、占主要视觉比重；画成空神殿风景、或以其他人物/物件为主体即 fail。
2. [硬] 十字架形态：仅一座漆黑巨大十字架，竖直矗立于裂痕圣坛上，体量明显大于人形剪影（约四五倍）；十字架画成金色/华丽装饰风、明显小型化，或出现第二座十字架即 fail。
3. [硬] 倒吊姿态：人形剪影头朝下静静悬于十字架前，身影如墨色剪影；画成头在上正挂、站立人形、无十字架的悬浮人形，或姿态扭曲挣扎即 fail。
4. [硬] 面容降格：剪影看不清面容细节，仅眼睛位置透出两点微光；画出清晰五官、表情，或误用地下祭坛睁眼变体（血色眼白＋黑色眸子直视观者）即 fail。
5. [硬] 无血腥恐怖元素：画面任何位置无血迹、血污、伤口、锈钉、穿刺、虫豸、腐肉等元素，剪影边缘干净完整；出现任何红色血腥细节即 fail。
6. [硬] 场景要素：西幻半毁神殿主厅——高大石柱、裂痕圣坛、残破穹顶、远处兽皮灯笼昏黄烛光（以光晕呈现，非火苗特写）；场景画成中式庙宇、现代空间或明亮白昼即 fail。
7. [硬] 静态庄严氛围：画面为静态庄严的圣像式构图，无动态冲突、无惊吓构图、无恐怖压迫式大特写；整体偏暗但十字架与剪影主体清晰可辨。
8. [硬] 全局负面：画面无文字、符文、题字、印章、徽记符号；无提灯探索者等额外人物；提示词全局负面行要求的元素（无血污、无锈钉、无第二座十字架等）全部落实。
9. [软] 风格锚（FH-040）：中世纪暗黑奇幻墨线插画——钢笔交错排线、暗调羊皮纸暖赭色调、纸纹质感与留白；呈现日式动漫赛璐璐感/厚涂油画感/照片写实即计 fail（软性风格提示）。
10. [软] 构图完整：巨大黑色十字架与倒吊剪影完整入画、无明显裁切，四周留出幽暗呼吸空间，画面重心稳定、具庄重对称感。
