# 伊丽莎白 · 水仙花街门口的报喜少女（★定妆·廷根公学期/#143 报喜拜访）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 容貌与年龄（第一识别点）：十六七岁公学少女，三要素齐全——天然卷的褐色长发（卷曲蓬松、垂落肩侧）＋可爱婴儿肥的圆脸蛋（脸颊圆润饱满）＋青涩漂亮的浅蓝色眼眸；画成直发/黑发/金发、清瘦尖削脸型、深褐或黑色瞳即 fail；画成成年女性或沾染贵族华贵、非凡神秘气质即 fail（档案红线：她恒为普通人类少女，无异变无序列）。
2. [硬] 蓝色蕾丝长裙：一袭镶嵌漂亮蕾丝的蓝色长裙，领口/前胸蕾丝镶嵌清晰、袖口与裙摆有蕾丝缘饰，裙摆垂顺及地，十九世纪维多利亚风格西幻设定；主色画成白/红/紫/绿等非蓝色系即 fail（蓝色即她的身份色，全出场恒定蓝色系）；改画中世纪袍服、宫廷裙撑或东方长袍即 fail。
3. [硬] 薄纱软帽：一顶与长裙同色、垂下细格薄纱的软帽，头戴或手捧均可 pass（档案原口径「手拿或头戴」两可，不必摘帽），薄纱柔顺垂软；帽子整体缺失即 fail；画成硬挺宽檐女帽、羽毛高帽、草帽即 fail。
4. [硬] 招牌神态：抿唇含笑、眉眼弯弯的矜持笑容，不露齿，欢喜自眼底透出，仪态端正有淑女教养；画成面无表情、忧郁低落、惊惶不安即 fail；露齿大笑、张狂失态亦 fail。
5. [硬] 场景要素：清晨阳光下的空无一人的住宅街——砖石联排住宅的蒸汽时代街景、晨光自街口斜洒铺满人行道，宅邸门前黑漆铸铁栅栏与石砌台阶，街道空旷安静、远景唯有街角建筑轮廓在薄雾中虚化；场景画成室内、教堂、俱乐部、墓园即 fail。
6. [硬] 无黑甲骑士与盔甲：画面任何位置不出现黑甲骑士、任何盔甲、头盔、甲胄与金属护具意象（黑甲骑士为噩梦怨魂、非她的形态，惊悚元素禁入）；出现任何铠甲残留即整图 reject。
7. [硬] 无惊悚阴影：画面不出现魔镜与镜面物件、阴森投影、诡异暗影、怪物轮廓等任何惊悚元素；画面整体通透明亮、治愈安宁，出现阴郁压抑或恐怖氛围渲染即 fail。
8. [硬] 全局负面：画面任何位置不出现文字、匾额题字、招牌字迹、印章、徽记符号（伪文字即 reject）；不出现火焰、明火与任何燃烧元素，街道上不出现任何点亮或透光的光源器物（r3/r4 教训：街灯元素已整体删除，画面出现点亮光源器物即 fail），全部光效为清晨天光与柔和反光；街道上空无一物，不出现任何车辆、牲畜与货物（r1-r4 教训：马车四轮连召，车辆元素已整体删除，出现即 fail）；不出现枪械、手杖、雨伞、长杆类物品与神秘学法术特效；不出现骑士、牛角铠甲、古老石阶遗迹等 FH-040 参考残留意象。
9. [硬] 独处红线（无他人同框）：清晨的水仙花街空无一人，画面除伊丽莎白外不出现任何其他人物或人影——无路人、无门内迎候人影；任何清晰或半清晰行人剪影即 fail（r2 教训）。
10. [硬] 构图完整与静态：镜头拉远至全身完整入画，头顶与双脚清晰可见，蓝色裙摆下露出小腿与一双深色小皮鞋，双脚完整踩在人行道上、脚前留出街道留白；双脚不可见、裙摆触画面底缘即 fail，头顶被裁切亦 fail；人物为画面绝对主体、背景虚化衬托，背景抢夺视线计 partial；全画为静态定格，无奔跑、转身、裙摆剧烈飘动等动态混乱。
11. [软] FH-040 风格锚：精密细腻的钢笔交错排线、暗调羊皮纸暖赭底色、做旧纸纹与颜料肌理，如一页古老典籍中的整幅明快插图；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail；不得混入东方古风水墨写意笔触（软性风格提示）。
12. [软] 青春治愈气质：整体明快温润、青春元气，蓝色系长裙为绝对主色、晨光暖金与蕾丝湛蓝为唯一点睛亮色；画面沉郁暗黑化、亮色杂多仅作提示、不计 fail。
