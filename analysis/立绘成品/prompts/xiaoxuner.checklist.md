# 萧薰儿 · 雪夜重逢（成年归来）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄感与身形：成年薰儿形象，身高七头身、身姿高挑颀长，面容为成年女子的清丽舒展；出现幼态稚龄、大头短身、儿童体态即 fail。
2. [硬] 黑发：乌黑长发半挽半垂、余发披散肩后如墨瀑；发色画成棕/银/白即 fail（半挽发式与素金步摇为自拟软项，细节出入仅记 partial）。
3. [硬] 回眸温柔：少女侧身立于雪中回眸，眸中带一缕温柔、唇边有极淡笑意；眼神画成冷漠疏离/惊惶，或改成正面直视站立即 fail。
4. [硬] 中层青衫与内层白裙：淡青色广袖长衫（呼应原文青衣意象）与素白中衣长裙为服装主体，领缘滚一道极细淡金边；整体主色画成大红/明黄等浓艳配色即 fail。
5. [硬] 外层狐裘大氅：肩披银白色狐裘大氅，领口一圈白狐毛，氅面有暗金色云雷纹；缺氅或缺狐毛领即 fail（云雷纹细节模糊仅记 partial）。
6. [软] 腰饰与内衬：腰束淡金丝绦、垂青白玉佩，氅衣内衬自领口露出一抹浅紫（均为自拟软项，缺失仅计 partial 不否决）。
7. [硬] 雪夜场景：夜色庭院积雪覆地、檐上堆雪、细雪正在飘落、有白梅数枝；无雪景或改成白日即 fail。
8. [硬] 静态与单人：画面为静态站姿，衣袂氅衣自然垂坠、无风吹飞舞；画面中仅薰儿一人，萧炎或任何其他人物不得入画。
9. [硬] 无兵器：通身不佩刀剑等任何兵器；出现兵器即 fail。
10. [硬] 全身完整：头顶到双脚完整入画、无裁切，全身约占画面三分之二，脚下留有一身位空白。
11. [硬] 无文字与无灯火：画面任何位置不出现文字、题字、印章、徽记符号；不出现火焰、灯火、灯笼等燃烧发光元素。
12. [软] 水墨风格：潇洒写意笔触、大面积留白（雪夜天色以宣纸留白与淡墨晕染）、透明叠染、仅金色与浅紫点睛；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
