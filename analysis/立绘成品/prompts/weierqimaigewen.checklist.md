# 韦尔奇·麦格文 · 客厅笔记解读之夜（★生前定妆·单人变体）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 体型面容（第一识别点）：身材圆滚滚的富态青年、皮肤白皙、面颊饱满带红润气色、二十岁上下大学毕业生年纪；画成清瘦挺拔的书卷青年、憔悴苍白，或画成中年发福大叔即 fail（档案红线：圆滚富态＋白皙为全书唯一直接外貌描写，勿套用克莱恩清瘦模板）。
2. [硬] 无眼镜：面部任何位置不出现眼镜、单片镜、夹鼻镜及其挂链——金边/单片眼镜为克莱恩系配饰锚点，原文未提韦尔奇戴镜，出现任何眼镜即整图 reject。
3. [硬] 服装体系（推定自拟）：深色西装马甲＋挺括白衬衣＋深色小领结＋深色长裤＋黑色皮鞋的维多利亚大学生居家便装，剪裁按富态身形放宽放量；改画黑袍（海纳斯锚点，勿移给韦尔奇）、中世纪袍服铠甲、东方长袍或居家睡袍即 fail。
4. [软] 服装颜色（自拟推定项）：马甲与长裤的深色具体色相（炭灰/深褐等）为推定自拟，原文零描写；画成其他深色系仅作提示、不计 fail；主调画成白/红等亮色则升格计 fail。
5. [硬] 豪爽生动神态：坐在主位沙发前沿、身体微前倾，笑容爽朗、眉飞色舞、正开口说话，右手抬在胸前五指张开作讲解手势、左手搭沙发扶手；画成阴郁沉思、正襟危坐无手势、局促含羞或忧郁深沉脸即 fail（豪爽爱交友为档案气质锚点）。
6. [硬] 场景要素：夜晚豪华客厅——深棕色皮制一主二副沙发组合（他坐主位）、光洁大理石茶几、茶几正中一册合拢的深黑色封面古籍（封面素净）、厚重织花地毯、木质护墙板、深色窗帘、无源式暖黄光晕；场景画成墓园、街头、书房、宴会厅即 fail。
7. [硬] 无火焰灯体：光效一律为高处漫洒的无源式暖黄光晕，画面不出现吊灯、灯罩、灯体、烛台、火苗、火光等任何灯具或燃烧元素——出现任何灯具本体或火焰即 fail（防伪火焰复发，档案吊灯不作实体呈现）。
8. [硬] 生前定妆红线（特殊负面）：画面任何位置无血迹、无血污、无伤口、无淤痕、无绷带、无尸骸、无墓碑、无墓园、无灵堂遗像、无枪械（其左轮手枪为遗物锚点，禁入）；人物完好无损、红润鲜活，出现任何死亡/凶案元素即整图 reject。
9. [硬] 独处红线（无第二人）：画面除韦尔奇外无任何其他人物或人影——无黑发褐瞳书卷气青年（克莱恩/原主）、无戴薄纱手套的娇美女士（娜娅）、无褐发直立的黑袍中年男子（海纳斯）、无灰蓝眼半百老头（西里斯），副沙发与全部座位空置；出现任何清晰或半清晰第二人影即 fail。
10. [硬] 无伪文字：画面不出现任何文字、题字、匾额、印章、徽记符号；深黑色古籍封面素净无可辨文字纹章，墙面挂画虚化为模糊色块；出现任何可辨文字即 fail。
11. [硬] 构图完整与静态：人物全身完整入画，头顶与双脚清晰可见，双脚踩在脚前地毯上、不触画面底缘，头顶或双脚被裁切即 fail；全画为静态定格，无起身、手势挥舞过猛、衣饰剧烈飘动等动态混乱。
12. [软] FH-040 风格锚＋富家子气质：精密细腻的钢笔交错排线、暗调羊皮纸暖赭底色、做旧纸纹质感，如一页古老典籍中的整幅插图（厚涂油画感/赛璐璐动画感/照片写实计 fail，不混东方水墨写意笔触）；整体透出出手阔绰、养尊处优、爱交朋友的豪爽富家子弟气息，用料考究而不张扬（软性风格与气质提示）。
