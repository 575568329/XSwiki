# 格蕾嘉莉 · 灵界深渊不死鸟降临（黑暗祭坛·本体版）· 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 画面主体判定：画面主体为山岳般庞大的不死鸟形古神巨鸟，双翼完全收拢贴伏于体侧、悬浮于灵界幽暗深渊中央的黑暗祭坛上方，位于画面中央、占主要视觉比重（整体约占画面高度五分之三，祭坛与深渊仅作底座背景）；画成空深渊风景、以祭坛或黄金饰品为主体、或巨鸟缩于一角即 fail。
2. [硬] 不死鸟巨鸟形态：体态修长的神鸟骨架——鸟首、利喙、修颈、完全收拢贴体的双翼、尾羽齐全，巨大而不臃肿，远景如山岳横亘；画成臃肿圆团、普通鹰鸦类小体量、龙形或其他神兽即 fail。
3. [硬] 苍白火焰羽毛与羽翼：羽毛呈现苍白火焰的白金色冷光并与神秘暗色花纹交织，双翼由层层叠叠的苍白火色羽片构成；火焰色羽是羽色特征不是燃烧火效——出现真火苗跳动、烟雾、火星飞散、羽毛焚毁碳化效果即 fail。
4. [硬] 闭眼青铜眼睑：巨鸟双目阖闭，眼睑为青铜铸造的哑光质感，带金属氧化的青绿锈色与铸纹，安详如上古石像，阖闭处无发光、无高光点、无苍白火焰；双目阖闭青铜哑光眼睑为 pass；睁眼且发光金黄、呈抛光金球/琥珀金球感、或无青铜氧化铸感即 fail（r1-r3 三轮教训：神鸟发光眼为图像学级先验，词语战不可对抗，故改闭眼方案）。
5. [硬] 无实体门洞与龛：巨鸟周身（尤其胸口正中）不得出现任何实体门框、可通行门洞、金属龛、拱券递进或廊道结构，胸前羽毛致密整齐、与周身羽色一致、为完整连续羽面；若双眼微睁，瞳内可隐约浮现层叠门影（仅眸中虚像，可选弱细节）；胸口出现实体门洞/金属龛即 fail（r3 教训：门影被错置于胸口龛中），躯干或翼面任何位置画入实体门洞亦 fail。
6. [硬] 灵界深渊场景：无边黑暗的灵界幽暗深渊＋底部古老石质祭坛沉默轮廓，苍白火色羽光为画面唯一亮色光源（青铜眼睑呈哑光锈色、不发光），远景没入阴影；画成明亮白昼、神殿室内，或出现灯笼/烛台/火盆等火焰灯体即 fail。
7. [硬] 无残躯腐烂态：巨鸟为完整圣洁的全盛形态，羽毛丰满齐整；出现腐烂、腐皮、淡黄脓液、创口、羽毛消融残破等任何细节即 fail。
8. [硬] 无人形与无月亮女神元素：画面任何位置（含胸口、祭坛上、深渊中，若瞳内有门影则门影内亦不得有人影）无任何人形、人脸、Human-face、人形剪影、人格化面孔，亦无月亮、月轮、月光、女神或女性化元素；出现任一即 fail。
9. [硬] 无伪文字：画面无文字、符文、题字、印章、徽记符号，羽上暗纹仅为抽象织纹而非可读符号；出现即 fail。
10. [硬] 构图完整：巨鸟整体完整入画、约占画面高度五分之三，双翼完全收拢贴伏于体侧、翼尖收于尾羽附近不向外展开、不呈展翼状、不触及画面左右边缘、无明显裁切，四周留出幽暗呼吸空间，静态庄严圣像式构图、重心沉稳；双翼收拢贴体为 pass；展翼且翼尖触缘裁切即 fail（r2/r4 两轮教训：半展翼不可控，须完全收拢贴体）；出现动态冲突、惊吓式大特写或重心失衡即 fail。
11. [软] 风格锚（FH-040）：中世纪暗黑奇幻墨线插画——精密钢笔交错排线、暗调羊皮纸暖赭色调、纸纹质感与留白；呈现日式动漫赛璐璐感/厚涂油画感/照片写实即计 fail（软性风格提示）。
12. [软] 冥界威严感：古神死寂、宏大、压迫的庄严气质，无表情、无人格化神态，安静肃穆如古老壁画；气质轻佻、萌化或装饰细节喧宾夺主即提示（软性）。
