# 科林·伊利亚特 · 圆塔首席书房定妆（★便装定型·白银城首席/百岁老猎魔者）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 花白乱发（第一识别点）：花白头发凌乱疏于打理、蓬乱覆顶；画成乌黑/金黄/银亮整齐发型、梳理服帖或中青年发量浓密即 fail（档案红线：全书恒定花白乱发，登场即百岁，不可美化）。
2. [硬] 法令纹与陈旧伤疤：法令纹很重、深刻清晰，其余部位少有皱纹；左脸颊有两道交叉的陈旧刀疤，疤痕泛白、边缘清晰；画成无疤光洁嫩脸即 fail；画成满脸细密皱纹的干瘪老朽亦 fail（档案明文"法令纹重而其余少纹"）。降级条款：疤位细节连续两轮盲审不达即降为软性提示、不再否决（r1 教训：疤位模糊，P1 不烧轮次）。
3. [硬] 浅蓝深邃眼眸：浅蓝色眼眸、深邃沧桑仿佛写满故事；瞳色画成深褐/黑/金/红即 fail；眼中浮现墨绿符号或任何发光符文光效亦 fail（静态定妆像非能力发动状态）。
4. [硬] 无须：下巴、两颊与唇周完全光洁，一根胡须都没有的干净脸，只以法令纹与皱纹标记年岁；出现任何灰白胡须/髭须/络腮胡即 fail（r1 教训：老年先验；胡须全书零描写，立绘按无须定型）。
5. [硬] 便装体系：亚麻色衬衣＋棕色外套＋腰间镶满暗格的宽皮带（暗格中收纳几只小金属瓶），下身深色长裤与旧皮靴（裤靴为档案推定补全，画成其他深色素款仅计提示）；改画银色盔甲、黑色紧身衣、祭袍法衣即 fail。
6. [硬] 去剑化（r1-r3 三连败，去剑化终局）：他本人身上/手中出现任何剑即 fail——身无背负刀剑、手无持剑、腰无佩剑，双手空无一物自然垂落；双剑只作为背景墙面连鞘陈设存在，背景墙面挂剑允许连鞘剪影，出鞘裸刃或身上任何形式的带剑均 fail。
7. [硬] 书房场景：白银城圆塔首席书房——厚重木质书桌（纸页典籍素净无字）、沉厚石砌墙面（交叉悬挂两把连鞘直剑为书房陈设）、高大窗户、窗外深灰雷暴云层下白银城银白石塔远景；场景画成战场、宫殿大殿、图书馆大厅、荒野营地即 fail。
8. [硬] 禁配硬项（任一出现即整图 reject）：头部竖直独眼或任何额面异眼（全书未实装，出现即 fail）；巨人王冠冕、王冠或任何头饰（冠冕为白银城神级封印物，非个人饰物）；兽皮灯笼（属队员持物）；黑色紧身衣（白银城子弟作战服，科林无此描写）；银色盔甲、巨人化体型、流动水银液体等半神神话战形元素（人物恒为人类老者形态）。
9. [硬] 无伪文字与无火焰闪电：画面任何位置无文字、题字、印章、徽记（书页与书脊亦无可辨文字）；无火焰、明火、烛火、火光与任何灯体灯具，室内光效一律为窗外云层透下的清冷天光；窗外雷暴只作深灰云层明暗微光，出现闪电枝杈、雷光即 fail。
10. [硬] 构图完整与静态独处：人物全身完整入画，头顶与双脚清晰可见，双脚不触画面底缘、脚下石质地面留白，头顶或双脚被裁切即 fail；全画为静态定格标准像，无动态混乱；除他本人外不出现任何第二人影（无队员、无来访者、无戴里克同框）。
11. [软] FH-040 风格锚：精密细腻的钢笔交错排线、暗调羊皮纸暖赭底色、做旧纸纹质感，如一页古老典籍中的整幅插图；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail；不得混入东方古风水墨写意笔触（软性风格提示）。
12. [软] 沧桑守护者气质：沉稳、温和、寡言的守护者长者气场，老而弥坚、肩背宽厚腰背挺直；画成暴戾凶相、佝偻衰朽、阴郁反派相或青年化即计提示（软性提示）。
