# 李绛迁 · 金簪化枪 立绘盲审清单

> 对应提示词：`prompts/lijiangqian.prompt.txt`；评审只依据图面逐项判 pass / fail / partial 并给证据，全部 [硬] 通过才可 accept。

1. [硬] 长枪只有一端有金属矛头且只垂一束枪缨，另一端为平钝收口；出现第二枚矛头/第二束缨即 fail
2. [硬] 整支长枪完整入画，枪杆通直无断裂、无裁切，握把尾端点地
3. [硬] 人物为成年青年（20 岁以上观感），身形偏高瘦；出现少年/孩童感即 fail
4. [硬] 双瞳为金色，眼形偏狭长；瞳色呈棕/黑/蓝等非金色即 fail
5. [硬] 着装主体为一袭绛色（暗红）长袍，通身以绛红为主色；出现第二件主色外袍或现代服饰元素即 fail
6. [硬] 浓密墨发高束成髻，画面定格为金黄长钗已拔离发髻化枪的状态；发髻上再出现任何簪钗即 fail
7. [硬] 场景为大漠阵前，天际有杏黄色离火光晕笼罩，人物自火光中显现
8. [硬] 黑发间燃有微微发光的杏黄色火焰
9. [硬] 构图：人物头顶到双脚完整入画，全身约占画面三分之二，脚下留出一身位空白；头顶或双脚被裁即 fail
10. [硬] 画面中不出现任何文字、匾额题字、印章符号
11. [软] 水墨古风笔触：可见手绘笔压与轻微不齐整的轮廓节奏、大面积留白与纸纹质感，而非光滑厚涂或赛璐璐描线
12. [软] 色彩基调以绛红、金黄、墨黑与杏黄火光为主；气质为唇角含笑而目光锐利阴冷
