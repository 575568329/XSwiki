# 杰森·贝利亚 · 雾夜甲板上的逃亡者（★定型·真身行动期/银镜逃亡装束）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 真身容貌定妆（第一识别点）：中等身材、外表三十来岁；深褐色短发自然微卷、几缕发卷自帽檐边缘露出（发卷程度为档案推定）；深棕色（咖啡色）眼眸、目光冰冷内敛。发色画成金/银/纯黑直发、瞳色画成蓝/绿/灰即 fail；眼中泛火红/熔岩般红光即 fail（红瞳为恶魔显形专属，#434）；画成颧骨高耸、蓝眼带灰、头发整齐后梳的"帕特里克·杰森"人皮中年脸即 fail（人皮形态非本图对象，勿与真身混同）。
2. [硬] 鸭舌帽与按帽动作：头戴鸭舌帽（软质扁平帽檐），右手按在帽顶、帽檐压得极低并在眉眼上投下浓重阴影（#431「按着鸭舌帽」）；帽画成高筒大礼帽、圆顶硬礼帽、宽檐帽即 fail；帽檐高高掀起露出完整眉眼、无按帽动作即 fail；双手均无朝向帽子的动作亦 fail。
3. [硬] 竖领深色大衣：深色及膝长大衣、领口高高竖起掩住颈侧与半边下颌，大衣之下内里衣物深黯不作细辨，全身衣色统一深黯收敛（#433 深色大衣＋#431「竖起大衣领口」）；大衣缺失、领口翻下敞露颈胸即 fail；衣色画成白/亮色或改画中世纪袍服铠甲即 fail。
4. [硬] 内河船甲板场景：深色木质甲板＋船舷木栏杆（人物独立于栏杆旁）＋桅杆帆影/缆绳/货箱的暗色剪影＋栏杆外薄雾河面与远处码头雾影（#431 银镜逃亡场景的甲板静态变体）；场景画成码头岸地、街道、阁楼、船舱内部即 fail；栏杆或甲板缺失即 fail。
5. [硬] 夜航光效（无火焰灯体）：全船光效一律为雾后月晕的清冷白光与雾隙天光，无一点暖黄灯火；出现灯笼、桅灯、烛火、明火、火光等任一燃烧元素即 fail（月晕式写法为本图硬纪律，火焰元素同时是恶魔显形态红线，双重禁入）。
6. [硬] 含蓄阴沉气质：唇线平直轻抿、下颌内收、目光低敛投向雾色深处、帽檐阴影遮眼，整体呈高度戒备、刻意低调的压抑藏匿感；嘴角勾起愉悦笑意或狞笑、神情张狂外露、直视镜头的嚣张气场即 fail（愉悦笑意为阁楼/显形态锚点 #433/#434，勿混入逃亡态）。
7. [硬] 无恶魔显形态：通体为正常人类血肉的静态立姿——无黑色粘液覆盖、无蝙蝠翅膀、无淡蓝火舌、无硫磺火球、无影化黑影/纸薄黑影、无身形膨胀异形、眼中无火红光；任一出现即整图 reject（显形/影化为另一形态链 #434/#435，严禁混入本图）。
8. [硬] 独处与无动物红线：画面除杰森外无任何第二人——无艳丽女子同伙、无船员、无旅客、无码头人影；无任何动物——无黑狗、无恶魔犬、无飞鸟鼠类；出现任何清晰或半清晰第二人影或动物即 fail（女子同伙与恶魔犬为附录/伴生元素，禁入本图）。
9. [硬] 全局负面（无伪文字/徽记/道具）：画面任何位置不出现文字、船名牌、匾额、印章、徽记符号，帆面、货箱与船舱木壁无可辨字迹，尤其无五芒星与羊角纹样的贝利亚家族徽记（#436）；不出现枪械、匕首、手杖、长杆、卡牌类道具（「深渊」亵渎之牌禁入）与神秘学法术特效；不出现银镜、镜框或任何框景边框（甲板变体弃用镜框景）；不出现骑士、牛角铠甲、石阶遗迹等 FH-040 参考残留意象。
10. [硬] 构图完整与静态：人物全身完整入画、立于画面中央偏侧占画幅主体高度，甲板栏杆横贯画面下三分之一，头顶雾空与河面雾影收束上部；头顶与双脚清晰可见，双脚不触画面底缘、脚下甲板木板留白，头顶或双脚被裁切即 fail；全画为静态定格，无奔跑、回望、衣摆剧烈翻飞等动态混乱。
11. [软] 伪装逃亡者阴郁氛围：整体悬疑压抑、雾夜河面的空寂感，"藏头露尾生怕被认出"的逃亡叙事感；画成阳光明朗、英雄气场或张扬反派海报感仅作提示、不计 fail。
12. [软] FH-040 风格锚：精密细腻的钢笔交错排线、暗调羊皮纸暖赭底色、做旧纸纹质感，如一页古老典籍中的整幅插图；厚涂油画感/赛璐璐动画感/照片写实计 fail，混入东方古风水墨写意笔触作提示；全画唯一点睛亮色为月晕清冷白光与帽檐阴影下一线苍白肤色，出现其他鲜艳亮色块作提示。
