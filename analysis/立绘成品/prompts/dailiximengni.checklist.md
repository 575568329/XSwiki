# 戴莉·西蒙妮 · 皮沙发旁的通灵者（★定型·生前廷根通灵者造型/零灯具变体）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 蓝色眼影与蓝色腮红（第一识别物）：眼睑涂幽蓝的蓝色眼影、双颊扫蓝色腮红，两处蓝妆清晰可辨、位于面容视觉焦点，在微光下可带一层诡异光泽；缺妆、褪成普通红色腮红或灰黑烟熏妆即 fail（档案红线：全书十余次从无更改的第一识别物，无蓝妆即非戴莉）。
2. [硬] 碧绿眼眸：双眼为晶莹的碧绿色、如绿宝石；画成蓝/棕/黑/金/红等其他瞳色即 fail；眼神空灵飘渺、静态望向画外。
3. [硬] 兜帽黑袍（通灵者长袍）：一身黑色带兜帽长袍，厚重垂顺、下摆收在脚踝上方，衣褶层叠，兜帽清晰入画（垂搭于脑后肩背、帽缘轮廓可见），十九世纪维多利亚风格西幻设定，通体素净无纹饰；长袍缺失、改画女警制服或其他服饰、兜帽消失或画成东方道袍即 fail（她全书唯一常服，黑袍为底）。
4. [硬] 盘发：深色头发（发色为档案推定自拟）在脑后盘成整齐发髻、一丝不乱；披发散发即 fail；发丝崩解四散（死亡段形态）即 fail；金发即 fail。
5. [硬] 银链白水晶：一侧外露手腕缠绕数匝细银链，链端垂一枚莹润的白色水晶吊坠、凝清亮微光；整体缺失即 fail；水晶画成红色/紫色等其他宝石即 fail；以戒指、手镯等其他首饰替代即 fail（不佩戴任何戒指类饰物）。
6. [硬] 客厅场景：昏暗的维多利亚宅邸客厅——她静立于皮制沙发旁（深褐皮革、坐压褶皱），配大理石茶几——几面完全空置、没有任何器物，茶几面出现任何器物（含茶杯）即 fail（r2 教训：一只倒扣茶杯曾生出两只正立茶杯，茶几彻底清零）；深色木质家具、帷幔退为暗部背景，四壁为素净壁纸与木饰板；画成街头、教堂、墓园、停尸房、飞空艇休息室或灰雾长桌即 fail。
7. [硬] 无冥界元素（生前定型期红线）：不出现漆黑蛇鳞与白色绒毛等身体异变（失控态禁入）；不出现布满符号的青铜之门或任何门形异象、血臂触手藤蔓；不出现无脸长舌的怪异信使生物或任何灵界生物；不出现骷髅、亡灵、幽影鬼魂、灰雾投影等冥界元素——出现任一即 fail（按生前人形建档，异变态与身后态全部禁入）。
8. [硬] 全局负面（无伪文字/无火焰灯体）：画面任何位置不出现文字、符文、题字、印章、徽记，长袍器物墙面均素净无可辨铭刻；不出现任何烛台、灯具、灯体轮廓、油灯、煤气灯、吊灯、火苗、火光等燃烧或发光器物，室内照明一律为幽蓝与暖赭交织的无源微光（出现任何灯具火苗即 fail）；四壁不安装任何壁灯、烛台、搁板或支架类器物，出现壁装支架轮廓即 fail（r2 教训：暗部轮廓也算）；不出现药瓶、法杖、魔杖、武器（她全程徒手）；不出现骑士、牛角铠甲、石阶遗迹等 FH-040 参考残留意象。
9. [硬] 独处红线（无他人）：画面除戴莉本人外不出现任何其他人物或人影——无克莱恩、无邓恩、无伦纳德、无信使脸孔贴墙；出现任何清晰或半清晰第二人影即 fail。
10. [硬] 构图完整与静态：人物全身完整入画，头顶与双脚清晰可见，双脚不触画面底缘、脚下地面留白，头顶或双脚被裁切、双脚不可见或袍摆延伸出画面底缘即 fail（长袍下摆收在脚踝上方，露出脚面与深色低跟鞋，双脚完整踩在地板上）；全画为静态定格，无风吹袍动、灵界特效、风影重影等动态混乱；她立于画面中央偏前、环境收束为四围暗色衬托，人物占比为主体。
11. [软] FH-040 风格锚：精密细腻的钢笔交错排线、暗调羊皮纸暖赭底色、做旧纸纹质感，如一页古老典籍中的整幅插图；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail；不得混入东方古风水墨写意笔触（软性风格提示）。
12. [软] 妖异冷艳气质：观感三十出头、妆容刻意画得老气而艳丽，苍白肤色＋妖异美感＋成熟气质，"像一位真正的通灵者"；嘴角噙若有似无的浅笑；画成明快甜美的少女感即提示（素颜清丽少女态属卸妆特殊剧情态，勿混），画成恐怖惊悚鬼气亦提示；均不计 fail。
