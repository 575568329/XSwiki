# 元景帝 · 八卦台观斗法（道袍俯瞰）立绘 · 盲审清单（二轮修订：年长锚点强化）

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄长相（双硬信号）：年过五旬老者——①颔下一部长须垂至胸前（灰白/白色，明显非黑色短须或无须）；②两鬓与长发半白。长须与半白发缺一即 fail；面容清俊、气色红润如盛年为正向要求，画成二十余岁青年即 fail，枯槁龙钟衰朽亦 fail。
2. [硬] 木簪束发：半白长发用一根素木发簪高高束起、绾成道髻，木簪形制朴素可辨；无金冠、冕冠、玉冠等任何冠饰；无木簪即 fail。
3. [硬] 双臂垂侧：双臂自然垂于身体两侧，双手不持物、不扶腰带、不拢袖、不负手；出现握袍带、拢袖或抬手势即 fail。
4. [硬] 道袍形态：素色宽大道袍，宽袍大袖、双袖飘飘，袍身朴素无绣纹、无金线镶边、无兽纹章纹；画成窄袖武服、锦缎华服或帝王礼服即 fail。（月白/灰白色相为自拟软设定——原文仅「朴素道袍」，只审素色无纹，偏白偏灰不作否决。）
5. [硬] 无帝王礼服元素：全画无明黄衮服、龙袍、龙纹蟒纹、十二章纹、冕冠、平天冠、玉圭；「像道士而非皇帝」的道袍反差即锚点，出现任何龙袍类元素即 fail。
6. [硬] 气质定妆：仙风道骨、淡泊沉静、不怒不喜，垂眸俯瞰，眼底至多一缕深藏锐意；不得画成暴怒、疯魔、悲恸、癫狂或狼狈失态。
7. [硬] 场景要素：司天监观星楼八角形高台（八卦台）高处，人物立于台缘俯瞰，台下皇宫广场人山人海、以淡墨虚化呈现；无高台、无俯瞰关系或台下无人海即 fail。
8. [硬] 无兵器：画面任何位置无剑、无刀兵、无仪仗兵器（含手中、身侧与台下人海中；不出现黄铜剑）。
9. [硬] 无文字与卦符：台身台面、栏板、衣饰、背景均无文字、匾额题字、印章、徽记符号；八卦台不刻画卦象符号，以素面八角造型与云纹表现。
10. [硬] 无燃烧元素：无火焰、明火、火光、烛火、燃烧粒子与烟焰特效；台下不画斗法光效与火光，光效仅限清亮天光与淡金流光。
11. [硬] 全身完整：人物头顶到双脚完整入画、无裁切。
12. [软] 构图占比：远景构图，人物全身约占画面三分之二，脚下台面留一身位空白；占比明显过大（如近八成）或过小仅作质量提示，不单独否决。
13. [软] 监正随坐：人物身侧可有白衣白须老监正席坐执盏；缺席不否决，出现时体量须明显小于主体、不喧宾夺主。
14. [软] 水墨风格：笔触潇洒写意、有大面积留白与宣纸纸纹质感、透明叠染色调；呈现厚涂油画感/赛璐璐动画感/照片写实即提示 fail（软性风格提示）。
