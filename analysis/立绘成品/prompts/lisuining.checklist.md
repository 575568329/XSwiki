# 李遂宁 · 雪岸独立（幻醒重审）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄感：人物为二十余岁的成年青年男子，眉宇冷峻、含忧郁思虑之神，神情出神而迷茫；不得画成半大少年的稚气脸，也不得出现胡须、皱纹等中年以上特征。
2. [硬] 银眸与眉：双眸沉静内敛，眼中隐约泛着淡淡的银白色辉光；眉形凌厉上挑。眼睛不得画成实心发白的发光眼，也不得画成红瞳、金瞳、蓝瞳等异色瞳。
3. [硬] 眉心银印：眉心正中有一点竖直的银色菱形光印，如一枚小小的额饰珠宝嵌在肤上、微微发亮；无光印、画成纹身图案，或画成刺眼爆发强光即 fail。
4. [软] 发式发饰（自拟项，非原文依据）：黑发全部束起成髻，以素色发带或素木簪固定；"束发起髻"为主判点，发带／木簪的具体样式不苛求，全披散发即计 fail（软性提示）。
5. [硬] 外层厚氅：身披一件深玄青色（近墨的深青黑）厚重长大氅，氅衣厚实垂坠、有挡风雪的重量感，自肩背覆至足踝上方；画成单薄披巾、短斗篷，或换成银袍／白袍即 fail。
6. [硬] 内衬素白长袍：氅襟敞开处露出素白色交领长袍的领缘与前襟，下身露素白袍摆；内袍不得画成彩色织锦或绣纹华服。
7. [硬] 腰间束带与悬挂物：腰间以素白色腰带束氅，腰侧仅一枚素色玉佩；出现任何旗类、幡类悬挂物，或腰带玉佩上出现文字、符文式笔画符号即 fail。
8. [硬] 场景要素：画面为冰封湖岸，四项齐备——湖水凝冻的冰白湖面、鹅毛大雪漫天飘落、天地阴沉灰白、岸边空无一人的长道；人物为画面唯一人物，不得出现第二人、屋舍人烟或战斗痕迹。
9. [硬] 光效收敛：静谧雪景，画面无雷电、闪电、雷云翻墨、阵法光柱、金光爆发等任何动态光效；眉心银印、眸中银光的光一律为柔和静谧的清亮辉光，出现任何爆发式光效即 fail。
10. [硬] 全身完整：人物头顶到双脚完整入画，靴底以下雪地留白清晰可见，靴筒下半截被积雪埋住；[软] 构图占比：全身占画面约三分之二为佳，占比较高但上述三要素齐全不否决（先例：萧初庭／空衡以 notes 收货）。
11. [硬] 无文字：画面任何位置（含旗面、衣饰、发带、背景天空湖面）不出现文字、题字、印章、徽记符号。
12. [软] 水墨风格：笔触潇洒写意、有大面积留白与宣纸纸纹质感、透明叠染色调；呈现厚涂油画感／赛璐璐动画感／照片写实即计 fail（软性风格提示）。
