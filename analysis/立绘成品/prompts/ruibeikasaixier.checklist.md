# 瑞贝卡·塞西尔 · 开国典礼（掌心火球）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄与气质：人物为十六七岁的活力少女，眼睛很大、深褐色长发、几缕碎发翘起，笑容灿烂、两眼放光；画成幼态孩童（大头身、稚气脸）或成熟成年女性（风韵、御姐相）均 fail。
2. [硬] 宫廷长裙：身穿藏青蓝底、金线滚边与暗纹刺绣的曳地宫廷礼裙，泡泡短袖、腰束缎带、裙摆层叠；画成研究员外袍、白色短袍、短法师袍或日常常服即 fail（裙色为自定推测，形制必须为宫廷长裙）。
3. [硬] 铁法杖形制与持态：一手在身侧轻轻拎着一根深色木质长法杖，顶端嵌一枚哑光金属环，杖身竖直、静止；杖头发光、杖上缠绕符文光纹、挥动施法姿态或整杖缺失均 fail。
4. [硬] 火球形态：另一手掌心上方悬浮一枚拳头大小的稳定火球，浑圆收敛、边缘安静、无拖尾；画成爆炸、烟花式炸开、飞溅火星、巨大火球或贴附掌心的火团即 fail。
5. [硬] 唯一火源：除掌心火球外，画面任何位置无火焰、明火、火把、烟花、燃烧粒子与烟雾；台侧光学水晶装置只反光不燃火，出现第二处火源即 fail。
6. [硬] 场景要素：洁白石砌观礼台与简洁石栏、台侧光学水晶装置反光、台下远景列队士兵方阵与欢呼人群剪影、远处白银堡尖塔与城垛轮廓；缺任一主体场景要素即 fail。
7. [硬] 场景静态：全画为静态定格，无爆炸、无动势冲突、无挥动残影；无第二位可辨识近景人物，背景人群仅为远景剪影，出现清晰近景第二人即 fail。
8. [硬] 构图完整：人物头顶到双脚完整入画、无裁切，全身约占画面三分之二，脚下留出一身位空白。
9. [硬] 无文字：画面任何位置（旗帜、石栏、服饰、水晶装置、背景）不出现文字、题字、印章、纹章徽记与可辨识符号。
10. [软] 风格锚：中世纪暗黑奇幻墨线插画——精密钢笔交错排线、羊皮纸暖赭底色、纸面颗粒质感、暖橙火光为唯一点睛色；呈现宣纸水墨晕染、厚涂油画感、赛璐璐动画感或照片写实计 fail（软性风格提示）。
11. [软] 自定推测项：瞳色（琥珀褐）、宫廷长裙配色（藏青蓝＋金线）、光学水晶装置形制均为着装档案未明写之自定项，仅作跨图一致性核对，不作否决依据。
