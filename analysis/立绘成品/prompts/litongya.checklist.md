# 李通崖 · 寒云峰一剑断道 · 盲审清单

- [硬] 年龄与发色：人物为十六七岁黑发少年，发色为纯黑色；出现白发、灰白发或老年皱纹面容即 fail。
- [硬] 眸色：双眼为灰色的眸子；出现金瞳、红瞳等即 fail。
- [硬] 眉眼体貌：眉形细长舒缓（长眉），脸颊清瘦，两肩宽大，身形挺拔。
- [硬] 着装主体：所穿衣袍主体为灰色；主色为白袍、黑袍或其他色即 fail。
- [硬] 着装饰纹：灰衣上有清晰可辨的白色纹样（白色缘边或暗纹沿衣襟/袖缘/下摆出现）。
- [硬] 袖式与佩剑：双袖为宽大飘逸的云袖；另有一柄连鞘长剑负于背后，背上可见剑鞘或露出的剑柄。
- [硬] 兵器形制：手中之剑为通直、双面开刃的直身剑，有剑格与缠绳剑柄；出现"长杆+顶端矛头"的枪形、单侧弯刃的刀形，或剑身两端都带刃即 fail。
- [硬] 场景要素一：背景为寒云峰山巅环境，有云雾/低垂浓云，天色偏昏沉（可带细雨）。
- [硬] 场景要素二：画面可见山道，山道被一剑斩出清晰断痕/裂口，并有青白色剑光；无断痕或无剑光即 fail。
- [硬] 构图：人物头顶到双脚完整入画，全身可见，约占画面三分之二，脚下留出一身位空白；头顶或脚部被裁切即 fail。
- [硬] 无文字：画面任何位置（角落、衣物、山石、云间）不出现文字、匾额题字、印章或符号字样。
- [软] 风格笔触：整体为水墨古风人物画——潇洒写意笔触、大面积留白、透明叠染与柔软边缘、可见纸纹与手绘笔压感（FE-013 特征整体成立）。
