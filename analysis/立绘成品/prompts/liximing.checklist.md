# 李曦明 · 谒天门证紫府 · 盲审清单

- [硬] 全身完整入画：人物头顶到双脚全部在画面内，双脚可见且脚下留有空白，无裁切
- [硬] 年龄感：三十岁上下的青年男性，非少年非老者
- [硬] 眉心天光印：眉心正中有一枚清晰明亮的发光印记，光晕明显（弱到几乎不可见即 partial）
- [硬] 瞳色：淡金色眸子（非黑非棕）
- [硬] 着装主体：白金双色宽大道袍——月白底色 + 衣襟/领缘/袖缘淡金色缘边 + 暗金流云纹，腰束金色丝绦；不得出现紫色袍服
- [硬] 发式：黑发束道髻 + 素色玉簪，不得披头散发
- [硬] 场景：开阔湖面 + 身后高空彩云中一座亮白色天门，门内有天光洒下
- [软] 仪仗虚影：天门两侧云间有旗幡/仪仗的层叠虚影（有则 pass，弱或无则 partial）
- [硬] 风格：水墨古风人物画——可见手绘笔触、大面积留白、宣纸纸纹/透明晕染；不得是照片质感或厚涂油画
- [硬] 无文字：画面任何位置（含天门匾额处）不出现文字、题字、印章符号
- [软] 氛围：庄严圣洁，天光为暖亮色调、画面整体通透明亮
