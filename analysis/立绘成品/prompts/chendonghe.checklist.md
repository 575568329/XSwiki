# 陈冬河 · 阵前老卒（#1083 暮年守阵）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄与发须：人物为八九十岁的老年男性，满头白发（以白为主、至多夹杂少量灰白）并有白须；画成中年/青年，或黑发、深色须发即 fail。
2. [硬] 素袍主调：身穿素白色宽袖长袍，全身衣装主色为素白；主色画成黑/红/金等深色华服、锦缎礼服或武人劲装即 fail。
3. [软] 玉甲：胸前覆一件素白色片甲质感的胸甲，甲片如白玉层层相叠、温润素净；甲形制式与描述有出入仅作提示，不否决（原文仅"一身玉甲"三字，形制为推定）。
4. [硬] 背后负剑：一把长剑连鞘斜负于背后，剑柄自肩后露出、剑身整体收于鞘内；出现拔剑出鞘、露出剑身或剑刃、手握剑柄拔剑、持剑在手的任何姿态即 fail。
5. [硬] 姿态：盘膝端坐于阵前地面，双手在身前结出法印（结印手式形式不限，须为双手静定结印），腰背挺直；画成站立、箕踞散坐、弯腰驼背，或双手持物、撑地即 fail。
6. [硬] 神态：面容沉静肃穆、如老僧入定，双目微阖、垂帘或平静下视均可；画成怒目、开口呼喊、大笑、悲泣扭曲等激烈表情即 fail。
7. [硬] 场景要素与单人：画面中有一座古朴厚重的巨大石门，石门前地面有金色纹路线条勾画的阵法，阵上氤氲淡紫色清亮光华，人物坐于石门之前的阵前，且画面中仅此一位人物；缺石门、缺金纹阵法、缺淡紫辉光任一，或出现任何其他人物（含白羽长袍少年剑仙）即 fail。
8. [硬] 无文字：画面任何位置（石门、阵纹、衣饰、甲片、背景）不出现文字、题字、印章、徽记符号；阵纹只可为抽象线条花纹，描出文字或字符字形即 fail。
9. [硬] 无燃烧元素：画面任何位置无火焰、明火、火光、烛火、紫火、燃烧粒子或火星；阵法与场景光效只允许清亮辉光/流光（淡紫或淡金光华），出现任何火苗形态即 fail。
10. [硬] 全身完整：人物头顶到双脚完整入画、无裁切（含肩后露出的剑柄与盘坐双脚），盘坐全身居于画面主位，四周留白。
11. [软] 发髻：白发向后梳拢束成一枚素髻；披发、散发或髻形有出入仅作提示，不否决（发式为推定，原文无据）。
12. [软] 水墨风格：笔触潇洒写意、有大面积留白与宣纸纸纹质感、透明叠染色调；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
