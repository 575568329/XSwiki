# 李周巍 · 立天门（负伤驰援）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄感：人物为成年壮年男性，无少年稚气、无老年衰老特征，面容雄伟威武阳刚。
2. [硬] 暗金瞳：双眼瞳孔为暗金色（深沉金属金），不得画成黑/棕/蓝/绿/红瞳，且面部无鳞片状纹路覆盖。
3. [硬] 甲衣本体：身穿以墨黑为底色的重型甲衣，主色为黑，甲面布满暗金色玄纹；主色画成红/白/蓝或画成普通布袍即 fail。
4. [硬] 护臂纹饰主题：两臂护臂上有金色麒麟扑跃纹样；纹样画成龙纹/凤纹/其他兽纹替代麒麟即 fail。
5. [硬] 外层王氅：肩背披一件羽毛大氅，羽毛一片片分明可辨，羽毛末端带浅紫色，氅面有细密暗金色纹路。
6. [硬] 发冠：黑发束起成髻，头上戴有金色王冠/发冠；披发或无冠即 fail。
7. [硬] 金血：人物指尖或手上可见一抹金灿灿的金色血痕（血为金色，不得画成红色血液）。
8. [硬] 场景要素：画面中有一座巍峨高耸、通体发光的天门（门楼/光门形态），人物立于天门顶端，天门下方为云海。
9. [硬] 无燃烧元素：画面任何位置无火焰、明火、火光、烛火、紫火、燃烧粒子或火星；天门与氅面的光效只允许清亮辉光/流光（白亮或淡金光华），出现任何火苗形态即 fail。
10. [硬] 全身完整：人物头顶到双脚完整入画、无裁切，全身约占画面三分之二，脚下留有一身位空白。
11. [硬] 无文字：画面任何位置（含匾额、衣饰、甲片、背景）不出现文字、题字、印章、徽记符号。
12. [软] 水墨风格：笔触潇洒写意、有大面积留白与纸纹质感、透明叠染色调；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
