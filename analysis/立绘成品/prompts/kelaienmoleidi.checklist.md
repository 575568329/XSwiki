# 克莱恩·莫雷蒂 · 酒吧门口的可怕绅士（海上格尔曼·斯帕罗定型）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄气质：人物为二十多岁的年轻男性，脸庞消瘦、棱角分明、嘴边无须，神情冷峻沉静、目光淡漠，年轻中带着沉稳阅历，体形单薄清瘦；画成少年稚气、魁梧壮汉、中年发福或衰老即 fail；出现浓密胡须即 fail（浓须为另一马甲的锚点，此形态无须）。
2. [硬] 发瞳：黑发整齐斜梳；双眼为深棕色（褐色）瞳孔；发色画成金/银/白/棕红或瞳色画成蓝/绿/金/红等异色即 fail。
3. [硬] 礼帽：头戴一顶半高的黑色丝绸礼帽，帽筒只比帽檐略高一点，绸面柔和反光；无帽、手持帽子、鸭舌帽/软帽即 fail；帽筒高耸、高逾约两倍帽径（高筒大礼帽形态）即 fail。
4. [硬] 大衣体系：身穿黑色双排扣呢制长大衣，厚重垂顺、下摆长过膝弯，主色为黑；主色画成红/白/蓝/棕、改画短夹克或东方长袍宽袖即 fail。
5. [硬] 手部姿态与右手裸手：左手插在大衣口袋里，右手不戴任何手套、五指裸露、自然垂于身侧——右手无手套裸露为硬项，右手出现任何手套（含薄手套）即 fail；右手持物或插袋亦 fail。
6. [硬] 无枪械与杆状物：画面中不出现任何枪械、手杖、文明棍、雨伞、长杆类物品（手持、拄地、倚靠、背负均算）；出现任何枪械或长杆类物品即 fail。
7. [硬] 无单片眼镜：鼻梁佩戴细金边框架眼镜（双侧镜片、配有镜腿）；任一只眼出现单片眼镜、无框夹鼻镜片、挂绳或链条即 fail（单片眼镜为阿蒙专属锚点，出现即整图 reject）。
8. [硬] 场景要素：背景为深夜的纯色渐变夜空，上方一轮绯红圆月悬于薄云之间，下方渐变为深邃墨黑色；出现任何建筑、灯柱、船只、桅杆、人形、地面细节（含码头/栈道/街道/石板）即 fail；缺绯红圆月即 fail；画面出现清晰可辨的其他人物亦 fail。
9. [硬] 全局负面：画面任何位置（含背景渐变夜空处）不出现文字、题字、招牌、匾额、印章、徽记符号；不出现火焰、明火、火光、烛火、枪口焰、硝烟等燃烧与发射元素；全画唯一点睛色为绯红圆月的暗红，其余为墨线与暖赭、深褐层次，出现第二处鲜艳亮色即 fail。
10. [硬] 构图完整与静态：人物全身完整入画，头顶与双脚都清晰可见，画面底缘为深黑渐变夜色的一部分，双脚完整可见、不触底缘，头顶或双脚被裁切、脚部完全不可见即 fail；全画为静态定格，无奔跑、打斗、衣帽剧烈飘动等动态混乱。
11. [软] FH-040 风格锚：精密细腻的钢笔交错排线、暗调羊皮纸底色、暖赭统调与做旧纸感，如一页古老航海志插图；呈现为厚涂油画、赛璐璐动画或照片写实即计 fail（软性风格提示）；画面不得残留牛角铠甲骑士、石阶遗迹等风格参考意象，不得混入东方古风衣饰或写意水墨笔触。
12. [软] 占比与留白：人物全身约占画面三分之二、脚下留有一身位空白感；占比失当（半身特写化或远景过小化）仅作质量提示，不单独否决。
