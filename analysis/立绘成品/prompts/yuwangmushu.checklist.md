# 欲望母树 · 虚幻红月·万物滋长（绯色圆月与滋长剪影）· 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 画面主体判定：画面主体为一轮饱满的绯色圆月，浑圆完整、通体绯红、月色比血月更浓郁，位于画面中央偏上、占主要视觉比重；月亮画成灰白月亮、月牙或缺月，月色寡淡如寻常红晕，或出现第二个月亮即 fail。
2. [硬] 滋长剪影群像：月光所及处铺展草木疯长、蘑菇破土、藤蔓攀卷的植物剪影，草叶向上伸展、蘑菇伞盖错落、卷须舒展，呈现鲜嫩新生、蓬勃滋长之势；植物画成枯草干花、稀疏萎缩（沦为堕落母神式枯月意象），或剪影群整体缺失即 fail。
3. [硬] 夜空场景：背景为漆黑夜空与疏落冷白星点，照明仅为绯红月光与星点冷辉；出现室内屋顶、房屋墙壁、地平线建筑轮廓，或火把、灯笼、烛火等任何火焰灯体光源即 fail。
4. [硬] 无怪树本体：画面无怪树、血肉之树、褐绿树瘤、食人巨花、白皙巨躯等本体元素；出现即 fail。
5. [硬] 无人形无面孔：植物均为纯墨色剪影，无任何人形、恩赐小人、人体部位嵌入或缠绕植物，无面孔、五官与器官细节；出现即 fail。
6. [硬] 无信徒房屋：画面无信徒与任何人物，无房屋、室内、墙壁、祭坛等任何建筑元素；出现即 fail。
7. [硬] 无玫瑰荆棘：藤蔓剪影上无玫瑰花朵与尖刺荆棘（异种王系意象禁配）；出现即 fail。
8. [硬] 无伪文字：画面任何位置无文字、符文、题字、印章、徽记符号；出现即 fail。
9. [硬] 构图完整：绯色圆月完整入画、无明显裁切，植物剪影铺陈于画面下方三分之一与两侧边缘、克制不遮挡月轮，四周留出夜空呼吸空间，画面重心沉稳庄重。
10. [软] 风格锚（FH-040）：中世纪暗黑奇幻墨线插画——钢笔交错排线、暗调羊皮纸暖赭色调、纸纹质感与留白；呈现日式动漫赛璐璐感/厚涂油画感/照片写实即计 fail（软性风格提示）。
11. [软] 诡异唯美滋长感：静态古老异象式构图，庄严静谧、暗藏万物滋长的欢愉，诡异来自饱和绯红月色与静谧疯长的生命力而非血腥惊吓；画面轻快明丽、失去异象庄严感，或偏向血腥恐怖惊吓感即计 partial（软性提示）。
