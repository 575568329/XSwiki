# 陆江仙 · 月夜玄池（白发显真容）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄感与仪态：人物为成年人（不低于二十余岁观感），无少年稚气、无老年衰老特征；姿态为静立、微微低眉、两手笼于宽袖、神态沉静的静态站姿，无战斗、施法或形变中的动作。[软] 成熟度加分：面容呈三四十岁样貌、眼角有细纹、两鬓霜白（达到记 pass，偏青年不否决）。
2. [硬] 白发披散：全头白发，长发披散、不束冠不束髻，垂至腰际以下；画成黑发/灰杂发或加束发冠即 fail。
3. [软] 面部锚点加分：眼窝深邃，一侧脸颊有一道浅浅的细疤（原著方位为左颊，左右不究）；疤痕可辨记 pass，无疤或不可辨不否决整图。
4. [硬] 着装主色与纹样：身穿月白/乳白色交领广袖长袍，袖口与领边绣有银白月牙纹路，月牙形状清晰可辨；主色画成黑/红/青/紫等深色或普通布衣短打即 fail（宽容度：交领为最小设定，圆领亦可接受；腰束月白丝绦、下摆及踝为同色系最小设定；鞋履原文未见，赤足或素色履均 pass）。
5. [硬] 瞳色（最小设定）：眸色为浅淡沉静色系（月灰/银灰/浅褐/近黑均可），不得出现浓艳异色瞳（亮红/紫/金/绿等）；此项为原文未见的同色系最小设定，宽容度大，仅浓艳亮色瞳判 fail。
6. [硬] 无镜类物件：画面中不出现任何镜类物件——铜镜、古镜、立镜、穿衣镜、镜面、镜框与镜中映像一概不得出现（人物身侧、手中、背景、水中倒影均不得出现镜状物）；出现任何镜状物或镜面反光物件即 fail。
7. [硬] 场景要素与单人像：月夜湖面，湖心一方幽深的玄色水池，人物立于水面之上，头顶高悬一轮明月，乳白月华雾气漫铺水面；无湖池、无明月或人物悬空无水面依托即 fail；画面为单人像，四野空阔，其余人物不得入画。
8. [硬] 无文字：画面任何位置（含衣饰、背景、月面）不出现可读文字、题字、印章、徽记符号（袍服月牙纹为图形不算文字）。
9. [硬] 无燃烧元素：画面任何位置无火焰、明火、火光、烛火、紫火、燃烧粒子或火星；月华光效只允许清冷辉光与流光（乳白/淡白），出现任何火苗形态即 fail。
10. [硬] 全身完整与构图：人物头顶到双脚完整入画、无裁切，人物全身约占画面（画高）三分之二（允差约六至七成，达到约四分之三或以上即 fail），脚下湖面完整可见，脚下留出一身位空白（空白可为月色水面涟漪）；人物占比过大、脚下留白不足或足部没入水中被遮即 fail。
11. [软] 水墨风格：笔触潇洒写意、有大面积留白与宣纸纸纹质感、透明叠染色调；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示，不否决整图）。
