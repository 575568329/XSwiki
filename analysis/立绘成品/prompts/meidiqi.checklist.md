# 梅迪奇 · 班西山巅的红天使（★定型·染血黑甲真身/恶灵态收束）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年轻英俊与苍白脸（第一识别点）：面容年轻英俊、轮廓锋利、无胡须，脸色苍白、欠缺血色；画成苍老、留须、红润健康或肤色偏棕即 fail（四处定妆一致"年轻英俊"；肤色偏棕属"看门人"容器面孔，勿混）。
2. [硬] 火红战士发髻：火红色头发在头顶偏后绾成一个紧凑的战士发髻，髻形硬朗、黑色皮绳缠紧，只余鬓角两侧各一缕火红短发垂在颊侧，发髻与鬓发长度不过颈背；发髻为 pass 锚，披散且过肩即 fail（r1/r2/r3 三轮教训注记：披发红发先验极强，"及肩/束马尾"词战全败，r4 换最强形状锚"发髻"；若 r4 仍披散，r5 前按规则 12 将本条款降为软项，以"火红发色＋总体造型"为判定锚收货）；发色画成黑/金/棕/银即 fail；出现头盔、兜帽、头巾等任何头部遮蔽致红发不可见即 fail（无头盔记载，红发为最强识别锚点，须外露）。
3. [硬] 眉心旌旗状血色印记：眉心正中一枚旌旗（战旗）状血色印记，为暗红旗帜剪影、旗面素净；印记缺失或移位他处即 fail（r4 教训：r3 有 r4 消失，属振荡型败点，须钉死）；旗面出现可辨文字、纹章图样即 fail（四处复现锚点，战争神格可见标识，务必保留）。
4. [硬] 黑色染血盔甲：一身哑光黑色盔甲覆盖躯干四肢，甲面泼溅暗红色陈血斑痕、色沉如干涸泼墨；改着布衣、长袍或皮甲即 fail；血渍画成鲜红亮色、观感如新泼油漆即 fail；甲面出现金色纹饰、兽首浮雕、牛角装饰即 fail（甲胄形制为档案推定自拟，"泼血般暗红非鲜红"为档案红线）。
5. [硬] 双臂抱胸嚣张站姿：双臂环抱胸前、身姿挺拔静立，下巴微抬、嘴角讥诮（"双脚搁上会议桌"式的统帅嚣张凝为站姿）；双手垂落立正、叉腰或持械挥砍等替代动作即 fail。
6. [硬] 山巅余烬场景：坍塌海边山峰之巅，人物立于碎石巨岩之上，四周巨石碎岩散落，身后天际残留暗红橘赭余烬色调微光；场景画成室内、地下宫殿、教堂、港口街道即 fail；天际余烬画成整片燃烧火海或云上飞焰即 fail（应为天光残温式沉沉晕染）。
7. [硬] 腐烂痕迹仅隐约：面颊眼下暗色斑痕浅淡克制、隐约可辨；画成明显腐烂、见骨、溃烂疮面即 fail（恐怖元素克制红线）；通体完全无痕、过于干净计 partial（档案建议至少隐约呈现"死过一次"感）。
8. [硬] 无附身态元素（形态甄别红线）：不出现黑底红纹长袍、兜帽、任何袍服斗篷；不出现两颊裂开的血嘴或面部裂口缝合痕；不出现眼眶血红火焰或眼中发光；不出现翅膀、光环（"红天使"仅为称号，绝非有翼形象）；不出现单片眼镜（阿蒙专属锚点，出现即失真）——出现任一即整图 reject（防串附身容器态、防"天使"套版加翼）。
9. [硬] 全局负面：画面任何位置无文字、题字、印章、徽记、纹章图样，眉心印记与甲面皆为无字剪影，出现任何可辨字符即 fail；人影凝实，身上与周身无任何火焰、火苗、火星或火焰聚形成形（出现身上着火或火焰组成人形即 fail），光效一律为天际余烬残光；除他本人外无任何第二人影——无军团骑士、无乌鸦、无魔女天使（出现即 fail）；无卷烟、皇冠、卡牌等手持物；无牛角铠甲、石阶遗迹等 FH-040 残留意象；全画唯一点睛亮色为火红头发与天际余烬的暗橘呼应，出现其他鲜艳色块即 fail。
10. [硬] 构图完整与静态：人物全身完整入画，头顶与双脚清晰可见，双脚不触画面底缘、脚下碎石留白，头顶或双脚任一被裁切即 fail；全画为静态定格，无衣甲飘飞、发丝狂舞、火光乱舞等动态混乱。
11. [软] FH-040 风格锚：精密细腻钢笔交错排线、暗调羊皮纸暖赭底色、做旧纸纹质感，如一页古老典籍中的整幅插图；呈现厚涂油画感、赛璐璐动画感或照片写实计 fail，混入东方水墨写意笔触计 fail。
12. [软] 气质锚：铁与血的战争统帅之傲——嚣张张扬、战意灼然而不阴森，压迫感来自位格与气场而非恐怖血腥；画成阴郁怨毒、疯癫失控仅作提示、不计否决。
