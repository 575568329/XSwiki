# 李木田 · 守镜小屋香畔打盹（暮年定型）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄感：年逾七旬的古稀老农——须发皆白、满脸皱纹深重、身形枯瘦、脊背微见佝偻；画成中年/壮年/少年，或面色红润、体格壮实富态即 fail。
2. [硬] 凡人身份：画面主体为凡人老农守夜，不得出现任何修士元素——道袍、道冠/法冠、拂尘、佩剑、手持法器、掐诀、灵光法阵、符箓纸、仙气特效，出现任一即 fail。
3. [硬] 拐杖：画面中有一根磨得发亮的旧木拐杖（双手搭杖头坐姿拄杖，或斜倚身侧凳旁），素木本色；全画无拐杖即 fail，拐杖镶玉嵌宝或雕成龙头杖即 fail。
4. [硬] 姿态：老人坐在旧木凳上、垂首阖眼、对镜安然打盹（坐姿）；站立、行走或睁目端坐即 fail。
5. [硬] 场景要素：后院守镜小屋夜内景四要素齐备——屋脊天窗漏下的一柱月光、屋子正中的青石石台、石台上的青灰铜镜、石台旁一线笔直上升的香烟白烟；缺任一即 fail。
6. [硬] 铜镜形态：铜镜为青灰古朴的旧铜镜，静置台上、镜面无光不显影；画成发光宝镜、镜面显影/显像/显字或镜身环绕光晕即 fail。
7. [硬] 全身完整：老人头顶到双脚完整入画、无裁切，双脚与旧布鞋踏实入画可见；坐姿半身裁切、脚部或膝以下出画即 fail。
8. [硬] 无文字：画面任何位置（含镜面、香炷、器物、墙面、衣饰）不出现文字、题字、印章、符纸符号。
9. [硬] 香烟不成火：石台旁只有一炷细香与一线白烟；画面出现火焰、烛火、油灯灯苗、火盆、火星等任何明火即 fail（月光是全画唯一光源，只允许清亮月光）。
10. [硬] 静态独像：画面只有老人一人，无他人、无猫狗飞鸟等任何动物、无飘飞衣袂或动态特效；多人或多物入画即 fail。
11. [软] 服装与发式（推断项，非原文）：洗得发白的本色粗布短褐/素色棉麻衣裤、旧布鞋，白发松挽小髻，旧而整洁、通身无饰物；颜色深浅与新旧程度不作硬性判定，唯呈现绸缎光泽、锦缎纹样、官服华服时作为质量提示标出。
12. [软] 水墨风格：笔触潇洒写意、有大面积留白与宣纸纸纹/颜料肌理、透明叠染色调、以墨色浓淡为基调；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
