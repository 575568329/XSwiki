# 潘娜蒂亚 · 雾锁小镇的白袍圣女（★定型·迷雾小镇囚徒期收束/#859 初登场定妆）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 纯白朴素长袍（唯一贯穿装）：一身纯白、无任何花纹装饰、宽松素净、平整洁净不染尘埃的长袍，自肩头垂顺而下、下摆收在脚踝上方（不曳地）；袍面出现花纹刺绣、污渍、破损撕裂即 fail；主色画成米黄、灰蓝、绯红等其他色即 fail（档案红线：纯白长袍为全书恒定识别装，破损态属雾镇囚徒限定、本图禁入）。
2. [硬] 明艳容貌与黑发挽髻（第一识别点）：面容明艳灿烂、秀美亮丽、让人眼前一亮；黑色长发松垮挽成慵懒发髻、鬓角有自然滑落的碎发；发色画成金/银/棕红即 fail；发型画成披散疯长、夸张编网或利落短发即 fail；容貌画成清秀平淡、年老憔悴或带男性化特征即 fail（档案红线：恒按明艳女性处理，勿绘男性化特征）。
3. [硬] 宛若宝石的眼眸：眼眸呈宝石般的莹润质感、澄澈沉静；质感画成浑浊呆滞、或眼中藏镜片碎光即 fail；瞳色按深色系档案推定处理，画成血色、红色即 fail（血瞳属饥饿半疯态，本图禁入）。
4. [硬] 雾镇巷口场景：迷雾笼罩、色调阴暗的西幻小镇巷口——老旧砖石房屋深褐朦胧轮廓、湿冷石板路面、浓雾自巷道深处漫涌，远景可有风车与教堂尖顶的灰白虚化剪影；场景画成贝克兰德街道、教堂内部、古老宫殿即 fail；无雾、明亮清晰的白天街景即 fail。
5. [硬] 红月远景：上方远天悬一轮被雾晕染的绯红之月，只作远景天空的一团柔和红晕点缀；红月缺失即 fail；红月画得巨大压顶、占据画面主体位置即 fail；把红月画成银白普通满月即 fail（绯红为本图唯一亮色锚）。
6. [硬] 圣洁端庄神态（疯态即 fail）：神情沉静柔和、清柔气质内敛与慵懒糅合、唇角噙浅淡笑意、双手动作克制、双脚稳踏石板静立；画面出现齿缝血色肉丝、锁骨裂口伤口、皮肤异色花纹、黑发疯长结网、脚下蛛网细线、漂浮离地、疯癫戏谑狂笑中任何一项即 fail（#859 疯态锚点全部禁入，本图为克制静态构图）。
7. [硬] 无伪文字：画面任何位置不出现文字、匾额题字、招牌字迹、印章、徽记符号，房屋墙面与月面纹理亦无可辨字符。
8. [硬] 无火焰灯体：不出现火焰、明火、烛火、灯盏灯体及一切发光灯具，窗内亦无透出的暖黄灯光，雾镇光效一律为红月清辉与雾中灰白天光；出现街灯、提灯、烛台火苗即 fail。
9. [硬] 独处红线（无他人）：画面除潘娜蒂亚外不出现任何其他人物或人影——无行人、无路人影、无悬吊尸影、无兜帽女子（"橡皮擦"天使勿混入同框）；出现任何清晰或半清晰第二人影即 fail。
10. [硬] 构图完整与静态：人物全身完整入画，头顶与双脚清晰可见——双脚不可见/袍摆触底即 fail（r1 教训：本项目最高频败点）；白色长袍下摆须收在脚踝上方，露出脚面与一双浅色便鞋，双脚完整踩在巷口石板上、脚前留出留白，袍摆延伸出画面底缘即 fail，头顶被裁切即 fail；脚部画成赤足即 partial 不否决，但优先便鞋；全画为静止定格，无衣袂剧烈翻飞、发丝狂舞、雾气汹涌等动态混乱；人物为画面唯一视觉焦点，背景虚化退后不争焦点，画面主体被场景元素遮挡即 fail。
11. [软] FH-040 风格锚：精密细腻的钢笔交错排线、暗调羊皮纸暖赭底色、做旧纸纹质感，如一页古老典籍中的整幅插图；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail；不得混入东方古风水墨写意笔触，不得残留骑士、牛角铠甲、石阶遗迹等风格参考意象（软性风格提示）。
12. [软] 圣洁与诡秘并存的气质：纯白圣洁的身影与灰暗诡秘的雾镇形成格格不入的强对比——白袍为画面最明亮的浅色块、绯红月为唯一亮色，圣洁之下藏一丝不可言说的诡秘压抑；对比缺失、画面俗艳化或纯恐怖阴间化均作提示。
