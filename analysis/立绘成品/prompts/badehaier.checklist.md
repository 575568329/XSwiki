# 巴德海尔 · 悬崖晨曦（巨人王庭壁画）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 无脸铁律（本图与其他所有角色立绘的根本区别项）：整张脸完全藏于一体成型的无缝头盔之后，头盔之下不画出任何五官、皮肤、发须或人形面孔轮廓；出现露脸、露下半张脸、头盔破损露出皮肤、盔面隐现眉眼口鼻即 fail——巴德海尔任何形态从不露脸，露脸即整图 reject。
2. [硬] 头盔无缝无开孔无发光（一体成型三重锁定）：头部被一顶一体成型的无缝头盔完全包裹——像一张完全光滑、没有任何特征的白面具，没有眼缝、没有开孔、没有可开合的结构；头盔出现任何眼缝、开缝、开孔、发光、橘红光团、双眼分立光点或眼形亮斑即 fail（眼缝光两次画成双眼、开缝四轮复发，此元素已整体删除并三重锁定），出现可开合面甲/面罩结构亦 fail；头盔之下不得画出眼球、独眼或瞳孔（巨人血脉独眼为其母/弟与途径半神特征，本尊眼部从未显露）。
3. [硬] 银白盔甲与无发外露：全身银白色金属铠甲包裹全身，整套盔甲为哑光的银白色、造型简洁的素面铠甲；头部为全覆式盔顶与面甲，盔甲包裹整个头部、无任何头发外露，盔缘出现一缕黑发或任何发丝即 fail；主色画成黑金、红、蓝等异色，或改画布袍、皮甲、裸身即 fail。
4. [硬] 长剑拄地：双手扶着剑首，一柄巨大的长剑剑尖拄地在身前，剑身宽厚素净——拄地扶剑首为 pass，剑尖指天即 fail；单手斜持、扛肩或任何非拄地姿态亦 fail；剑身出现光斑、火花、缠绕光纹、剑气或染血即 fail；武器画成斧、锤、巨镰、枪戟等其他形态即 fail。
5. [硬] 场景要素：黎明高崖——人物立于崖顶岩石边缘，天际一轮初升朝阳与金橘色晨光，银甲表面有初阳般柔和漫射的暖金光辉；无悬崖、无晨光即 fail；背景出现金黄麦田、麦穗、果实等丰收意象即 fail（丰收女神姊妹壁画专属，属另一角色）；崖下远坡可有数个单膝跪地膜拜的巨人逆光暗剪影，仅限剪影、无面部细节、体量明显小于主体，出现清晰面孔的次要人物或群像争夺视觉中心即 fail。
6. [硬] 体量与气质：人物高大魁伟、肩宽背阔、有神祇的静穆压迫感；画成常人体格或瘦削少年感即 fail；无需画成山岳级超巨体型（尺度收敛为高大即可），但须明显超出普通士兵的体格感。
7. [硬] 全局负面：画面任何位置（含甲面）不出现文字、题字、碑铭、印章、徽记符号与可辨图形；不出现火焰、明火、火光、烛火等燃烧元素及剑气、闪电、能量特效；不出现血迹、骷髅、白骨等恐怖意象；不出现三叉戟、黑镰、繁星长裙、藤蔓与婴儿、太阳金球与白袍等其他神祇标志物；全画唯一点睛亮色为天际初阳的金橘晨光，其余为银白、铁灰、深褐与暖赭的沉郁层次，出现第二处鲜艳异色亮斑即 fail。
8. [硬] 构图完整与静态：人物头顶到双脚完整入画、无裁切，全身约占画面三分之二，脚下崖顶岩石留出一身位空白；全画为一帧静止定格，无战斗、无挥剑动作、无衣甲剧烈飘动等动态混乱。
9. [软] 盔甲形制与甲面素面（自拟推测，纹样按轮次校准降软）：甲片形制等细节原文无载，按哑光素面、简洁流畅的铠甲处理即可；甲面素面为佳；出现涡卷/十字/徽记状纹样计 partial 提示，不再单独否决整图，但出现文字/可辨图形仍 fail（按第 7 条硬项执行）；形制细节与预期有出入仅作质量提示，不单独否决。
10. [软] FH-040 风格锚：精密细腻的钢笔交错排线、暗调羊皮纸底色、暖赭统调与做旧纸感，如一页巨人王庭古史诗抄本插图；呈现为厚涂油画、赛璐璐动画或照片写实即计 fail（软性风格提示）；画面不得残留牛角铠甲骑士、石阶遗迹等风格参考意象，不得混入东方古风水墨写意笔触。
