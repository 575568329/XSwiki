# 南宫婉 · 子峰观天兆（月宫仙子）立绘 · 盲审清单

> 定型注明：★定型取「子母峰白衫宫装少妇期」（#1192-#1221）「雪白宫装如月宫仙子」；未取 #2394 小灵天「月仙子降临」白衣少女形态。场景=#1221 月宫仙子观天兆（该场景无剑，全程不得出现兵刃）。

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄感与定型：少妇期形象，少女绝色容颜与少妇雍容糅合；不得画成七八岁女童、稚气少女，也不得画成中年或老年妇人。
2. [硬] 白衣宫装：一袭雪白的宫装长裙，广袖、裙裾层叠，主色为纯白、通身无第二种颜色；白衣画成红/蓝/黑/彩裙，或改成战甲、婚服、劲装短打即 fail。
3. [硬] 乌发：发色漆黑如墨，绾成高髻、额前鬓边垂几缕青丝碎发；发色画成棕/栗/银白/灰白，或披发遮面即 fail。
4. [硬] 容颜五官：肌肤白腻胜雪，略尖的下巴、秀气的鼻子、清澈醉人的明眸；面部出现蒙面、面纱、斗篷遮面，或画成 #361 易容假面即 fail。
5. [硬] 清冷气质：神情清冷出尘如月宫仙子，黛眉微皱、仰望天际灵云；画成大笑、娇媚抛眼、羞怯脸红等对外妩媚态即 fail（本场景取清冷面）。
6. [硬] 朱雀环：腕间悬一枚火红色的圆环玉环，素面静态饰品、全画唯一浓烈撞色；环缺失、画成多只手镯，或改成腰间以外不明悬挂物即 fail。
7. [硬] 无燃烧元素：画面任何位置无火焰、明火、火光、燃烧粒子或火星；朱雀环上出现火苗、光焰特效即 fail（环只是素润圆环）。
8. [硬] 场景要素：人物独立于子峰之顶崖石玉台，远处母峰上空有一团五彩斑斓缓缓旋转的巨大灵云（淡彩晕染），群山云海远景，数步外一名灰袍弟子淡墨写意肃立且身形远小于主体；灵云缺失、场景变成室内/战斗即 fail。
9. [硬] 全身完整：人物头顶到双脚完整入画、无裁切，远景大山川构图，脚下崖石留一身位空白，天空大面积留白。
10. [硬] 无文字与兵刃：画面任何位置（衣饰、山石、背景）不出现文字、题字、印章、符箓文字；画面不出现剑或任何兵刃、不出鞘不抚鞘（本场景无剑）。
11. [软] 水墨风格：笔触潇洒写意、有大面积留白与宣纸纸纹质感、透明叠染色调；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
