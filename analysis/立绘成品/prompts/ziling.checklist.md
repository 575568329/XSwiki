# 紫灵 · 仙子落谷（红光敛去 #825）立绘 · 盲审清单

> 形态注明：取★定型「坠魔谷白裙仙子期」真容绝色态（#749/#825「仿若天上仙子」），非魔界紫衣期、非遮面清秀伪装态。

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 真容形态·无遮面：人物为真容绝色态，面容完整清晰可见；画面不得出现面纱、纱幕、轻纱、法术遮面等任何遮面元素，也不得画成清秀伪装态的小家碧玉面容。
2. [硬] 绝色艳容与明眸：容貌明艳照人、艳丽无双，嫣然浅笑、妩媚而不妖；一双明眸大而清澈、眸光清亮含笑；不得画成平庸面目、老相、过度脂粉浓艳，或细长眼/眯眼/眼神呆滞。
3. [硬] 白玉肤色：面部与手部肤色白玉般洁白细腻；画成暗黄、古铜、灰败即 fail。
4. [硬] 乌黑亮发：长发乌黑发亮、浓密如乌云，部分松挽成髻、余发披垂腰际；发色画成棕/褐/灰/白即 fail（髻式与白玉簪形制为自拟推测项，不作硬性判定，仅提示与仙子气质协调）。
5. [硬] 白裙：身穿一袭素白曳地长裙仙裾，主色为白，广袖飘逸、裙裾层叠；主色画成紫/黄/红/其他颜色即 fail，画成铠甲、短打或现代裙装亦 fail。
6. [硬] 身材修长：身形修长婀娜、体态优雅，头身比例协调；画成矮壮、臃肿或比例失调即 fail。
7. [硬] 场景要素：画面为幽暗密林空地，四周参天巨树环伺，林间有天光洒落；人物身后上空悬一道细线状红色惊虹流光光带，呈自天斜垂、缓缓敛去之势；密林场景缺失，或红色光带画成火焰、爆炸状大面积红光即 fail。
8. [硬] 禁出元素：画面无任何兵器、刀剑、飞剑、法器；仅此一位人物，不出现韩立或其他人物、妖兽；任何位置（含衣饰、树干、光带内）无文字、题字、印章符号；无火焰、明火、烛火等燃烧元素。
9. [硬] 全身完整与静态：人物头顶到双脚完整入画、无裁切，全身约占画面三分之二，脚下留出一身位空白；人物为静态伫立，无打斗、施法、奔跑等动态。
10. [软] 水墨风格：笔触潇洒写意、大面积留白与宣纸纸纹质感、透明叠染，白裙以留白与淡墨细线呈现尤佳；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
