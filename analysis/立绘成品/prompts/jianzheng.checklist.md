# 监正 · 雪夜片雪不落（八卦台盘坐）立绘 · 盲审清单（二轮修订）

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄与体态：人物为五百岁老者，面部布满褶皱、清瘦而腰背挺拔，盘坐不佝偻；画成中年/青年，或画成驼背衰朽老态即 fail。
2. [硬] 慈眉善目：白眉、眉目慈和、面带温和笑意；画成凶相、怒目或冷酷面容即 fail（锐利只允许藏于眼神深处，不得改变慈和眉目底色）。
3. [硬] 白发白须：满头白发与颔下长长白须，纯白如霜，披散不束冠、不束须；出现黑发、灰发、束发冠或短须即 fail。
4. [硬] 纯白一色：通身雪白的宽袍大袖道袍，两袖飘飘，衣料素白无纹、无绣、无镶边，通身无第二种颜色；衣袍画成灰白脏色、带彩色纹样或主色偏移即 fail。
5. [硬] 白玉酒杯：指间静持一只白玉小酒杯（静态持握于指间）；无酒杯，或画成仰头畅饮、弹酒、泼洒等动作瞬间即 fail。
6. [硬] 片雪不落（第一记忆点·对比判据）：雪花纷纷扬扬落满整座八卦台与台外他处，唯独人物周身三尺之内无一片雪花，发丝、肩头、袍袖、脚边全都干干净净。判据：人物周身三尺内无一片雪花＋台面他处落雪积雪＝pass；任何雪花落在人物发际、肩头、袍袖、脚边或三尺之内，或画面无「他处落雪、独他干净」的对比即 fail。
7. [硬] 场景要素：鹅毛大雪的雪夜，八卦台为厚重素面青石且台面他处积雪，远处京城屋脊在雪幕中隐约绵延；缺雪景、缺高台即 fail。
8. [硬] 石案及器物表面无卦象刻纹：身前为素白石案，案面平整空净；石案、青石台面与一切器物（含酒杯）表面均不得出现八卦卦象、刻纹、图案、符号；任何台面/器物画出卦图、刻纹、纹样即 fail。
9. [硬] 无兵器无法器：画面无刀剑兵刃，无天机盘、罗盘、星盘等带刻度文字的器物，无打神鞭、刻刀等法器；石案案面空净，无酒壶、菜肴等杂物摆设。
10. [硬] 全身完整与单人物：人物头顶到双脚完整入画、无裁切，盘坐全姿约占画面三分之二，四周留出一身位空白；画面仅此一位老者，出现弟子、白衣术士等第二人即 fail。
11. [硬] 无文字：画面任何位置（含器物、台面、衣饰、背景）不出现文字、天干地支、卦象符号、匾额题字、印章徽记。
12. [软] 水墨风格与静态：潇洒写意墨线、大面积留白、宣纸纸纹质感、透明叠染，白雪与白衣以留白表现；全画静态（静坐持杯、落雪无声），无战斗动作瞬间；呈现厚涂油画感/赛璐璐动画感/照片写实，或画成动态打斗即计 fail（软性风格提示）。
