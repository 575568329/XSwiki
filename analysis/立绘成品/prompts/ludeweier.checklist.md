# 路德维尔 · 黑色郁金香号甲板·面具船长（★定型·地狱上将常态）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 夸张三角帽：头戴夸张三角帽，帽身绣白色骷髅纹样＋帽侧插羽饰；骷髅仅限刺绣纹样——画面出现任何实体骷髅头、白骨挂饰或骷髅形帽饰即 fail；帽上骷髅画成文字、字母或徽章图样亦 fail（帽体深色为档案推定自拟，不计色 fail）。
2. [硬] 银白面具与眼洞火焰（第一身份锚点）：覆盖全脸的银白色面具，五官与轮廓皆藏、仅孔洞四周冰冷线条；眼洞内两团苍白如月光色的火焰静静燃烧、像两粒鬼火、冷白偏灰蓝——火焰缺一团、只画一只眼洞、焰色画成血红/阴绿即 fail；眼洞火焰橙黄/琥珀暖调即 fail（r1 教训；r5 终轮：任一复发即 reject 不再整改）；面具露出任何真实五官轮廓、或画成露半脸假面即 fail。
3. [硬] 上身礼服：镶繁复花边的白衬衣＋棕色船长式长外套（船长身份的大衣合规）或短外套均可 pass——长款下摆止于膝弯即可，无花边破损即可（花边缺失计 partial）；外套主色画成黑/红/蓝等非棕色调即 fail；风格画成破烂浪人风或军装风即 fail。
4. [硬] 下身与刺剑：白色紧身裤＋牛皮色腰带固定裤腰＋腰带侧悬细细刺剑（通体铁黑、素面无饰）；缺腰带、缺刺剑即 fail；刺剑画成弯刀、军刀、佩金银饰剑柄即 fail；裤画成宽松长裤或灯笼裤即 fail。
5. [硬] 甲板场景：夜晚的"黑色郁金香号"前甲板——黑沉泛阴绿的巨大帆船、惨白主帆绘漆黑郁金香图案（绘图纹样非文字）、右舷火炮森然列开、舷外海面黑沉如无星之夜；场景画成港口街市、船舱内部、白天晴海或教室王庭即 fail。
6. [硬] 亡灵船员剪影红线：亡灵船员仅以远处模糊暗影剪影存在，无面部、无白骨、无活尸细节；出现任何清晰的骷髅水手、白骨活尸、透明怨魂正脸即 fail；画面出现清晰第二人物（登船来客、水手正脸等）即 fail（单人画面）。
7. [硬] 无摘面具与异变态：面具全程覆脸、无摘面具动作；不出现缺血肉、皮贴骨、透明如水晶的枯脸或头骨；不出现染血黑甲人物、血红火焰眼、爬满血管的眼球、脸颊裂嘴、半身虚幻苍白巨掌、蛇芯状白毛舌头等异变元素——出现任一即 fail。
8. [硬] 无伪文字：画面任何位置不出现文字、题字、字母、数字、印章、徽记符号；帽上骷髅与帆上郁金香须为纯图案纹样，出现可辨识字符即 fail。
9. [硬] 无火焰灯体：画面不出现灯笼、火把、烛火、油灯灯焰等任何燃烧光源，夜色光效一律为月晕式清冷微光＋阴绿幽晕；船楼仅为浓黑剪影、所有舷窗全部熄灭、不透出一丝光——任何窗户/舷窗透光（尤其暖黄窗光）即 fail（r1 教训；r5 终轮：任一复发即 reject 不再整改）；唯一例外＝面具眼洞内两团苍白火焰（面具本体特征）；出现船上吊灯火苗、炮口火光、燃烧炮捻即 fail。
10. [硬] 构图完整与静态（硬性几何规格）：人物全身（帽顶到靴底）只允许占画面垂直高度的三分之二，画面上方三分之一必须是夜空与桅杆剪影，画面下方三分之一必须是空旷甲板木面，帽顶和靴底都不得进入画面边缘 15% 区域；人物立于前景中轴、站在甲板中段的高台木箱旁，双脚与黑色长靴清晰踏在宽厚的甲板木面上、脚前留出大片甲板留白、绝不触画面底缘——占幅超标或头顶/双脚被裁切即 fail（r1/r2/r3 连续复发教训；r5 终轮：任一复发即 reject 不再整改）；全画静态定格，无炮击、跳跃、衣帽剧烈飘动等动态混乱。
11. [软] FH-040 风格锚：精密细腻钢笔交错排线、暗调羊皮纸暖赭底色、深褐墨色分层渲染、做旧纸纹质感，如一页古老典籍中的整幅插图；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail；不得混入东方古风水墨写意笔触（软性风格提示）。
12. [软] 亡灵船长威压感：高傲、死寂深沉、望而生畏的"冷肃送葬者"气质，高大精悍、站姿笔直如侍卫（体型为档案推定）；画成癫狂狞笑、猥琐凶徒、翩翩贵公子或消瘦病鬼即计 fail（威压感不足仅作提示）。
