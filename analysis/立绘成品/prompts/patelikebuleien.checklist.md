# 帕特里克·布雷恩 · 墓园夜色的躬身绅士（★夜间仪式装·黑袍真容定型）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 发瞳脸型与年龄（第一识别点）：黑发、深褐色（棕色）瞳孔、五官轮廓深刻、脸型瘦长偏瘦削、四十五至五十岁的中老年相貌（眼窝微陷、法令纹清晰），身材高挑清瘦；发色画成金/银/棕红、瞳色画成蓝/绿/金/红、画成青年俊朗或体态肥胖即 fail（档案红线：与同名异人"帕特里克·杰森·贝利亚"的高颧蓝眼中年完全不同体系，严禁混淆）。
2. [硬] 黑袍与兜帽不拉起（真容示人）：一袭自肩头垂落脚踝的黑色厚呢长袍，兜帽松翻披在脑后、并未拉起，完整露出真容面庞与黑色头发；兜帽拉起、面目隐没即 fail（兜帽拉起＝麾下信徒与助手的识别键，真容不拉起是本图视觉关键）；长袍主色画成白/红/紫等非黑色、或改画中世纪铠甲袍服即 fail。
3. [硬] 躬身行礼姿态：上身自腰背深深向前躬下、脊背弯成拉到极限的弓，右手在身前笔直下垂、指尖朝向地面，头颅低垂，全画为该姿态的静止定格；站姿笔直无躬身、仅点头欠身的浅弯腰、或改为跪拜/抬手施法/伸手邀客等替代动作即 fail；画成动态模糊或多重残影即 fail。
4. [硬] 墓园夜色场景：郊外墓园的夜晚——几方风化倾斜的浑圆矮石碑、深色草地与浅浅石径、贴地薄雾、高处满月与月晕清辉、远处铁艺栅栏与枯树剪影；场景画成宅邸门厅、教堂、成衣厂房、白天或室内即 fail；石碑出现清晰可辨的碑文刻字或纹章图案即 fail。
5. [硬] 阴冷气质克制呈现：庄重、安静、寒意暗藏、恭敬到近乎夸张的体面绅士，如郊外墓园的夜晚；画成狰狞凶恶、阴森可怖、癫狂扭曲、面露狠光或诡笑即 fail（阴冷≠恐怖脸，克制失守即整图气质崩坏）。
6. [硬] 无恐怖道具堆：画面任何位置不出现棺材（含深黑沉重棺材）、骷髅头骨、人骨兽骨、成堆骸骨、苍白火焰蜡烛、黄金饰品、青铜之门等恐怖道具与仪式器物，出现任一即 fail（此类为死亡仪式场专属道具，本图禁入）。
7. [硬] 无伪文字：画面任何位置不出现文字、碑文、题字、匾额、印章、徽记符号，石碑、栅栏与服饰上均无可辨铭文纹样，出现任何伪文字即 fail。
8. [硬] 无火焰焰状光源：画面不出现火焰、明火、烛火、灯火、焰状光源等任何燃烧发光元素，墓园光效一律为清冷月晕与薄雾辉光；出现烛台火苗、窗内灯火、阴绿鬼火等即 fail。
9. [硬] 无特效叠加与独处红线：不出现灵体簇拥虚影、半透明幽灵身影、阴冷之风与玻璃崩裂特效、黑焰凝成的飞鸟信使等任何灵异特效图层（特效按叠加图层处理，生图一律不画）；画面除主人公外无任何他人或人影——无拉起兜帽的黑袍信徒、无黑底红纹长袍＋兜帽拉起的年轻助手（"死灵导师"）、无安乐椅上鬓角斑白蓝眼的贵绅（克莱恩）、无幽灵车队身影，出现任一即 fail。
10. [硬] 构图完整与静态：人物全身完整入画，头顶与双脚清晰可见，双脚不触画面底缘、脚下地面留白，头顶或双脚被裁切即 fail；全画为静态定格，无奔跑、转身、衣袍剧烈翻飞、雾气涌动等动态混乱。
11. [软] FH-040 风格锚：精密细腻的钢笔交错排线、暗调羊皮纸暖赭底色、做旧纸纹的颜料肌理质感，如一页古老典籍中的整幅插图；呈现厚涂油画感/赛璐璐动画感/照片写实仅计提示，不得混入东方古风水墨写意笔触，不得出现骑士、牛角铠甲、石阶遗迹等风格条目残留意象。
12. [软] 阴冷绅士气质整体拿捏：黑袍体面与墓园夜色阴冷二味的平衡——谦卑恭敬的躬身之下藏一缕非人寒意，"体面"与"阴冷"缺一即提示（画成纯粹仆役式普通恭敬、或阴冷压过体面沦为恐怖片氛围，均计提示不否决）。
