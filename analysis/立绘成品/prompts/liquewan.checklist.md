# 李阙宛 · 雷湖之战（霜虎 · 湖岸慑立）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄与发色：人物为成年青年女性，气质清雅、身姿婀娜，无幼女稚气、无老年衰相；头发为乌黑长发，画成棕发/金发/白发即 fail。
2. [硬] 面部锚点：一双杏眼、红唇、肌肤白皙；眉心一点朱砂，朱砂点两侧各有一道细微花叶状赤色纹路；面部为单一正常人脸，出现第二张覆面重影、汞白面赤瞳异相或面颊青紫花纹即 fail。
3. [硬] 道袍：身穿月白色织锦道袍，衣料垂坠、随风飘摆，衣身有同色暗织月华云纹，领缘/袖缘有窄银线镶边；主色画成大红、乌黑重甲或普通布裙即 fail。
4. [硬] 手姿与掌上古符：两手交叠拢在袖前、身姿挺拔；左手掌心上方悬浮一枚符箓模样的莹白古符，呈铜钱大小的圆环符影，带极浅银色繁花纹路与柔和月白光晕；符面出现文字即 fail。
5. [硬] 霜白巨虎：人物脚边伏踞一头通体霜白的巨虎，虎纹为流动的淡金色，虎形明确，周身有隐约淡黄色光晕，笔触与整幅手绘水墨一致；毛色画成橙黑相间常规虎色即 fail，画成照片写实质感即 fail，画成狼/豹/狮/龙等替代兽即 fail。
6. [硬] 立足场景：人物立于湖岸青黑色石面之上、足边漫有一层朱砂色流光之风，人物悬空离地或石面缺失即 fail；远景为天际浓云低垂、湖面雾气弥漫，画面任何位置出现电弧/闪电/雷光即 fail。
7. [硬] 全身完整：人物头顶到双脚完整入画、无裁切，双脚清晰可辨，脚下湖岸石面完整可见，全身约占画面三分之二，脚下留有一身位空白；巨虎不遮挡人物双脚与躯干主体。
8. [硬] 无兵器：画面中不出现任何兵器（锏/剑/矛/刀/枪等一律不得出现），手中之物仅有掌上古符；出现任何兵器即 fail。
9. [硬] 无文字：画面任何位置（含衣饰、符箓、背景）不出现文字、题字、印章、徽记符号；一切纹样均为抽象纹路。
10. [软] 眸光银意：杏眼眸底可带一缕银光，神色清亮沉静；未画出银光不否决。
11. [软] 水墨风格：笔触潇洒写意、有大面积留白与宣纸纸纹质感、透明叠染色调；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
