# 梅丽莎·莫雷蒂 · 阳光下的仪式（★米白定型期）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄感与兄妹脸区分（第一识别点）：十六七岁清秀少女，脸型偏瘦、颊边浅浅酒窝、脸颊有淡淡血色；画成儿童稚气脸或成年老相脸即 fail；出现书卷气青年脸（克莱恩特征）或发际线后退、面容老相（班森特征）即 fail。
2. [硬] 黑发（正向锚点）：乌黑的长直发柔顺润泽、自然披垂至背心，发间无饰物；发色画成棕/金/银/红即 fail；画成辫发、挽发、盘发、短发即 fail（全书无辫发描写，挽发眼镜属尾声成年形象）。
3. [硬] 褐瞳：双眼为褐色眼眸、晶亮有神；瞳色画成蓝/绿/金/红/灰即 fail。
4. [硬] 米白长裙：一身米白色连衣长裙，双肩为时髦羊腿袖、袖口收束，裙身轻便日常、无繁琐堆砌，衬出青春感；主色画成黑/红/深蓝等深色即 fail（黑裙属丧期装）；画成华丽宫廷裙撑、繁复堆纱、珠宝镶满即 fail（节俭朴素为正向气质）。
5. [硬] 薄纱荷叶边与配套纱帽：领口与衣襟边缘镶一圈轻薄白色薄纱荷叶边，缺失即 fail；头戴与新裙配套的米白色薄纱小帽、细纱轻覆发顶帽檐，帽子缺失即 fail，画成黑色纱帽即 fail。
6. [硬] 银制天使羽毛护身符：颈间细银链坠一枚手工雕琢的银质护身符，周遭簇拥细小天使羽毛纹样，银光内敛；整体缺失即 fail；画成金质、宝石吊坠、十字架即 fail；天使羽毛纹样缺失计 partial。
7. [硬] 场景要素（教堂）：宁静教堂内——阳光透过高窗形成光柱、洒落在排列整齐的深色长椅上，长椅全部空置；教堂内＋空长椅＋高窗光柱＋无任何其他人形（剪影也算）四要素任一缺失即 fail；场景画成马戏团广场、墓园、车站、户外街道即 fail。
8. [硬] 独处红线：全画面除她外无任何其他人形（背景人群剪影也算 fail）——无神职人员、无宾客、无兄长，教堂空旷安静、长椅全部空置；出现任何清晰或半清晰第二人影（任何人物剪影均计）即 fail。
9. [硬] 全局负面：画面任何位置不出现文字、题字、印章、徽记符号（护身符雕纹细密但不得呈现可辨文字）；不出现火焰、明火、火光、烛火等任何燃烧元素（教堂光效一律为清亮天光与柔和辉光，出现烛台火苗即 fail）；不出现刀剑、枪械、手杖、雨伞、长杆类兵器物品；不出现骷髅、幽灵、鬼影、青灰死气、坟茔墓碑等亡灵元素与神秘学法术特效（「收敛亡灵」锚点无文本支持，全面禁用）；不出现眼镜；全画唯一点睛亮色为白花一束与护身符一抹银光，出现其他鲜艳色块即 fail。
10. [硬] 构图完整与静态：人物全身完整入画，头顶与双脚清晰可见，双脚不触画面底缘、脚下石板地面留白，全身约占画面三分之二，头顶或双脚被裁切即 fail；全画为静态定格，无奔跑、回眸、裙摆帽纱剧烈飞扬等动态混乱。
11. [软] FH-040 风格锚与自拟推定项：精密细腻的钢笔交错排线、暗调羊皮纸暖赭底色、做旧纸纹质感，如一页古老典籍中的整幅插图；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail，不得混入东方古风水墨写意笔触（软性风格提示）。双手捧着一小束白花为[软]项（花束缺失仅作提示、不计 fail）；深褐色低跟短靴（鞋履档案缺失自拟）、白日时辰（时段自拟）、纱帽垂纱细部（原文无细部描写）均为推定项，画法差异仅作提示、不计 fail。
