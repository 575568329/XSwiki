# 李曦治 · 礁海霞光（礁海诛迟炙虎）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄段：人物为成年盛年男性（青年末至壮年），丰神俊朗、气度雍容；画成少年稚气或老年衰态即 fail。
2. [硬] 灰黑眸与缓眉：双眼瞳色为灰黑色，眉形平缓舒展；瞳画成金/蓝/红/绿等彩色，或眉画成浓竖怒眉即 fail。
3. [硬] 白羽法衣：身穿以白色为主色的羽毛法衣，片片分明的洁白羽片层叠成衣、羽片边缘清晰可辨；画成普通布袍上印/缀羽毛图案即 fail，主色画成黑/红/蓝亦 fail。
4. [硬] 玄纹：羽衣上布满墨黑色玄纹，纹样为云水/羽翎状抽象线条；纹样画成文字、符文、篆字、徽记即 fail。
5. [硬] 霞光流转：羽衣领口、袖口或下摆边缘有虹彩流光缠绕，光效为柔亮流光；出现火苗、燃烧、火星形态即 fail。
6. [硬] 无兵器：画面中不出现任何兵器（剑/刀/矛/戟等一律不得出现），人物双手交叠拢于袖前、身上与场景中无任何持握或悬挂的兵器；出现任何兵器即 fail。
7. [软] 束发：长发在脑后束起成束或髻；披发飞散计 fail（软性提示，发色不作判定）。
8. [硬] 场景要素：画面为海面上一块黑色礁石，人物立于礁顶平坦岩台，背景为海天与橙红青紫霞云，海面有一圈圆环状淡彩光晕；光晕中出现符号图形，或人物被画成悬空飞行即 fail。
9. [硬] 全身完整：人物头顶到双脚完整入画、无裁切，全身约占画面三分之二，脚下留有一身位空白且脚下礁石岩台面完整可见。
10. [硬] 无文字：画面任何位置（含衣饰、礁石、云霞、光晕）不出现文字、题字、印章、符箓字样。
11. [软] 水墨风格：笔触潇洒写意、有大面积留白与宣纸纸纹质感、透明叠染色调；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
