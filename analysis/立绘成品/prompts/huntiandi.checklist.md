# 魂天帝 · 吞丹（帝品雏丹·暗殿静定）立绘 · 盲审清单

判定规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示不否决。逐项标 pass / fail / partial，并附画面证据。

1. [硬] 年龄气质：人物为成年壮年男性，面容冷峻俊拔，阴冷威压、不怒自威的帝者气度；画成少年稚气或龙钟老朽即 fail。
2. [硬] 黑袍正向：一袭墨黑长袍为全身主体服装，主色为黑，人物正面朝向观者端直而立；主色画成红/白/蓝/紫、画成铠甲或普通布衣、或呈侧身/背影即 fail。
3. [硬] 双臂与双手职责：人物仅有左右两条手臂，不得出现第三只手、多生手臂或手臂残影（旧批曾现六臂伪影，此项为防复发关键）；左手托着暗金丹丸、右手自然垂于体侧五指放松；双手职责互换、双手皆托或皆垂即 fail。
4. [硬] 圆丹形态：丹丸为一枚暗金色圆珠状丹丸，表面流转着内敛的辉光，呈完整正圆球状，悬于左手掌心上方；画成被咬、碎裂、爆裂、吞噬中、漩涡或光芒刺眼外放即 fail。
5. [硬] 暗殿场景：背景为幽暗深邃的大殿内部，人物端立于殿中高台之上，身后有高大石柱隐入黑暗，殿内静态肃穆、威压凝重；出现人群、其他人物、战斗痕迹或血液即 fail。
6. [硬] 面容神情：嘴角噙一抹妖异冷笑，眼神阴冷；画成慈眉善目、开怀大笑或表情茫然呆滞即 fail。
7. [软] 发式瞳色（自拟软项）：黑发束起、簪一枚暗金发簪，深黑眼眸；原文未详写发式与瞳色，按古风强者惯例自拟，样式偏差仅作提示不否决；不得据此计 fail。
8. [软] 衣饰细节（自拟软项）：双袖宽大垂坠，腰束玄色腰封且暗金纹线微亮，袍面有暗金丝线魂纹暗纹；原文仅「袖袍一挥」可佐宽袖，其余细节自拟，增减偏差仅作提示不否决。
9. [硬] 全身完整：人物头顶到双脚完整入画、无裁切，全身约占画面三分之二，脚下留出一身位空白。
10. [硬] 无文字：画面任何位置（含衣袍、腰封、丹丸、背景）不出现文字、题字、印章、徽记符号。
11. [硬] 无燃烧元素：画面任何位置无火焰、明火、火光、烛火、燃烧粒子或火星；丹丸与殿内一切光效只允许内敛的暗金辉光与流转微光，出现任何火苗形态即 fail。
12. [软] 水墨风格：笔触潇洒写意、有大面积留白与宣纸纸纹颜料肌理、透明叠染色调；呈现厚涂油画感/赛璐璐动画感/照片写实即计 fail（软性风格提示）。
