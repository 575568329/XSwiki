# 安格尔威德 r5 盲审评审

- 评审对象：analysis/立绘成品/angeerweide-angeerweide_nowm.jpg（同提示词重摇骰，前版 r4 已 accept）
- 评审依据：analysis/立绘成品/prompts/angeerweide.checklist.md（条款 4 含 2026-10-28 画法授权）
- 总判定：**reject**（条款 2 硬性一票否决）

## 逐项判定

| 条款 | 判定 | 证据（一句话） |
|---|---|---|
| 1. [硬] 主体判定 | pass | 画面主体为灰白色非人形巨龙，居中并占主要视觉比重，未画成空厅风景或人形神祇。 |
| 2. [硬] 盘绕巨柱构图 | **fail** | 龙身仅贴缠画面中央一根细长矮柱并在台基地面盘卷，左右合抱巨柱柱面光秃、无贴缠亦无爪扣石缝，属清单明示"绕细弱矮柱"fail 情形（r3 教训问题复发）。 |
| 3. [硬] 大厅场景 | pass | 西幻古典巨柱大厅，两侧彩饰挂毯环列、幽暗穹顶与顶部天窗清辉，非中式庙宇／洞窟／户外白昼。 |
| 4. [硬] 龙首朝向规避 | partial | 龙首为右侧侧脸、望向画面右前深处，无直视对视、无正面特写（fail 触发条件未出现，不否决）；但口部微张露齿，未严格达到"口微闭"的授权画法。 |
| 5. [硬] 无侵蚀态特征 | pass | 侧脸仅见一枚小巧深色眼瞳，无竖瞳、无第三竖眼、无双瞳异色。 |
| 6. [硬] 无衣物王冠 | pass | 龙体仅天然鳞片、鬃鳍与角须，无衣物、饰品、鞍具、王冠、权杖。 |
| 7. [硬] 无他人 | pass | 全画无人物兽类生灵，两侧挂毯仅圆形团花与几何纹样。 |
| 8. [硬] 无伪文字 | pass | 挂毯为漩涡团花、地面为几何镶嵌纹，未见字符、符文、印章、徽记。 |
| 9. [硬] 无火焰灯体 | pass | 无烛台、火盆、灯笼、火把，采光为顶部天窗清辉。 |
| 10. [硬] 构图完整 | pass | 远景构图，巨龙整体入画无明显裁切，四周留幽暗呼吸空间，重心沉稳。 |
| 11. [软] 风格锚（FH-040） | pass | 钢笔排线与羊皮纸暖赭色调明确，柱身与地面见交错线描肌理，无赛璐璐／厚涂油画／照片写实漂移。 |
| 12. [软] 史诗感 | partial | 巨龙体量与大厅恢弘尚可，但低踞细柱使"螺旋盘柱"的史诗张力明显弱于清单预期。 |

## 结论

硬性条款 2 fail，一票否决，总判定 **reject**。核心问题与 r3 同型：龙未沿左右合抱巨柱螺旋盘绕贴缠柱面、爪扣柱面，而是盘绕中央细柱与地面。条款 4 的直视规避本身达标（侧脸望向深处），仅口部微张记 partial 不否决；建议重摇时在提示词中强化"左右巨柱螺旋三匝以上、爪扣柱面、禁中央细柱"的约束。
