## 逐项判定

### 1. [硬] 年龄气质 — pass
成熟年轻女性，瓜子脸、肤色白皙，黑发盘束后发缕披垂肩后，神情沉静谨慎，具知识型神秘学者气场。无少女稚气、老态或浓妆妖媚。

### 2. [硬] 金边框眼镜 — pass
金色细圆框眼镜端正架于鼻梁，镜片覆盖双眼；右手抬起、指尖扶框，属清单允许的推镜微动作，镜片未离眼。

### 3. [硬] 眼眸 — pass
镜片后双眼虹膜呈清晰的紫色（深黑偏紫），放大可辨；无纯黑/棕/蓝/绿/金瞳色。

### 4. [硬] 黑袍本体 — pass
黑色古典巫师长袍为全身唯一服装，垂坠沉稳、满织银线纹样。备注：肩颈处有披叠式领巾/兜帽状布料垂落肩后，但未罩头，按长袍形制组成部分处理，不触发"带兜帽"否决。

### 5. [硬] 袍面符文与胸前徽记 — pass
胸前为银线绣制的眼睛图案：眼形、瞳孔清晰可辨，眼周为放射状睫毛细线并环绕细小星点与星芒点。**非环状罗盘徽、非指南针状徽，徽记内无文字字母**。备注：眼周放射线偏华丽（日芒眼风格），较"简洁"描述略有超出，但主体明确是眼睛，未触发任何 fail 条件。

### 6. [硬] 腰间器物限定 — pass
腰间仅垂挂一件黄铜星象仪小挂件（多环环架+中心球体+横环，链悬于腰带）。全图未发现权杖、法杖、刀剑等任何兵器杖类器物。

### 7. [硬] 半空悬立场景 — pass
人物悬空静立于夜海之上半空，周身环绕银白光带，右侧远处为黑暗中海岛宫殿剪影，天际阴沉而发亮；画面无桥体、栏杆、桥板、桩柱、道路、台阶，脚下无任何实体支承面。备注：下摆越出底缘问题归第 9 条判定，此处不重复计。

### 8. [硬] 光雾收敛 — **FAIL**
光带本体已收敛为柔白缎带状，但带上仍嵌有多处**尖锐四芒星爆/星芒**：
- 右侧光带交叉处一颗大型星爆（约原图 x≈82%、y≈63%），四条长芒锐利、带光晕，为全图最醒目星芒，属典型"星爆/放射光刺"形态；
- 左上光带上一颗四芒星 flare（约 x≈21%、y≈25%），垂直长芒尖锐；
- 另有左中（x≈11%、y≈60%）、右下沙滩（x≈92%、y≈91%）及袍摆前（x≈43%、y≈95%）等处小型尖芒光点。
"出现尖锐星芒、星爆形状即 fail"——不通过。

### 9. [硬] 静态构图与全身落点 — **FAIL**
长裙自腰带向下以连续垂直褶皱一直延伸出**画面底缘**：底缘处仍是袍料，下摆收口与脚部完全不可见，下摆下方没有夜空，袍摆被底缘裁切。人物静态、居中、无大动作均满足，但"下摆收在下三分之一、下方仍是夜空、任何部位不触边"不成立。顶/左/右三缘人物均未触边（头顶距上缘约 6%，两袖均留空隙；环绕光带出画不视为人物触边）。

### 10. [硬] 全局负面 — **FAIL**
文字、字母、题字、水印、印章符号：均未发现（袍面均为图案化纹样，符合豁免条款）；火焰明火：未发现。但"所有光效一律为柔和漫射月白光雾与朦胧光带"条款不成立，证据同第 8 条尖锐星爆，本条随之不通过。

### 11. [软] 体态自拟与 FH-040 风格锚 — pass
精密钢笔排线、暗调羊皮纸底、暖赭统调的中世纪暗黑奇幻墨线插画风格成立，淡金（星象仪、镜框）作点睛；非水墨写意/厚涂/赛璐璐/照片写实；无牛角铠甲骑士、石阶遗迹等残留意象。
