# 赫拉伯根 · 烛下圣像 —— 第三轮盲审（r3）

- 评审对象：`analysis/立绘成品/helabogen-烛下圣像_nowm.jpg`（2163×1938，低头隐眼姿态+捧书下沉 重生版）
- 依据清单：`analysis/立绘成品/prompts/helabogen.checklist.md`（已更新版）
- 评审方式：独立盲审，全图通读 + 对眼区（6x）、书册圣徽（4x）、白塔立柱（2.5x）、门楣（4x）四点放大取证。
- **总判定：REJECT（卡第 2 条 [硬]：低头姿态成立但双眼仍画出，帽檐未遮住眼部区域）**

---

## 逐项判定

### 1. [硬] 造像语境与老者身形 — pass
巨型石雕立于石殿高台，石材肌理、基座、殿内拱柱齐全，无活人显圣感；老者体态佝偻厚重，长须垂落至腹。证据：全图中央造像及底座台阶。

### 2. [硬] 兜帽覆面 / 低头隐眼 — **fail（本轮卡点，整图 reject 依据）**
低头幅度本身达标：头部深垂、下颌内收、面部朝向斜下方书册，非平视镜头。**但眼部仍完整画出**：6x 放大眼区可清晰辨认双侧眉弓、额纹，以及左右两片闭合下垂的眼睑——观者左侧眼睑呈杏仁形、具放射状睑褶与深色睑缘线，右侧眼睑弧线同样可辨；兜帽帽檐阴影线落在额头发际一带，未下压遮蔽眼带。观者所见为"整个面部"而非清单要求的"仅嘴角皱纹、脸颊与长白须"。按清单原文「抬眼正视观者/**眼部任何部分可见即 fail**」——闭合眼睑亦属眼部可见，判 fail。与前两轮同卡此项：三轮换姿态（低头+捧书下沉）已生效，但模型仍默认补画闭眼，未达成"帽檐物理遮眼"。

### 3. [硬] 持物：书册嵌眼圣徽一体 — partial
书册合一达标：双手腹前（略偏胸前）捧持唯一一本厚重书册，摊开、页面仅墨线纹理无可读字符，低头视线落于书册；黄铜色全知之眼圣徽嵌于书封/书脊正中，与书一体、未单持——一轮的双书册冗余与二轮的分持问题均已修复，书册为墨黑封面+纸黄页（符合第 4 条色彩体系"书册墨黑纸黄"）。**扣分点**：嵌眼画成睁目（金色虹膜+深色瞳孔清晰可辨），非清单 pass 条指定的"黄铜色闭合眼睑造型"；该细节属自拟补全范围，且不触及本条任何 fail 触发项（无第二书册、非卷轴石碑、圣徽有铜色），故记 partial 不否决。

### 4. [硬] 素白＋黄铜色系 — pass
袍服与长须为米白/纸白大亮色块，压住全画；金属仅黄铜点缀：书封嵌眼、袖缘铜线、门楣徽记、塔身铜睛，克制无蔓延；主调为墨线暖赭，无黑袍/金袍/红袍。证据：全身袍面与右袖口铜线。

### 5. [硬] 白塔背景 — pass
造像右后方有一通高白色方塔状浮雕壁柱，通体偏白、高耸入拱顶，塔身零星缀黄铜睛（柱身可见约 4–5 枚圆点铜睛，邻墙另有 1–2 枚），远未密布——符合"零星数枚点缀"的收敛约束；以殿内浮雕呈现白塔属清单自拟许可。证据：2.5x 放大塔柱，铜睛间距疏朗。

### 6. [硬] 场景要素与灯火约束 — partial
地下石殿、石阶高台（多级宽阶向下延展）、一线天光光柱带浮尘、右下阶边马灯一点昏黄玻璃光晕，齐备且灯火未蔓延。**扣分点**：门楣圣徽只有"独眼"浮雕，缺「摊开书本＋眼睛」合成徽记中的摊开书本半边；因 fail 触发项为"缺门楣圣徽"而圣徽本体存在且为铜色，记 partial 不否决。证据：4x 放大门楣，矩形石框内仅一睁目。

### 7. [硬] 禁龙形与逾矩持物 — pass
全图及各放大区域均无龙、鳞、角、翼或龙形剪影（塔柱浮雕为植物卷草纹，非龙纹）；除捧书外无武器/权杖/法球/第二书册，头部无冠冕头环。

### 8. [硬] 无文字无他人且静态 — pass
书页、门楣、塔身、袍面、墙面均无文字铭文字符；除圣像外无他人身影；光柱、灯晕、浮尘均为凝定静态。

### 9. [硬] 全身完整 — pass
头顶至基座双脚完整入画无裁切，造像连基座约占画面三分之二，像前石阶向下延展留出前景空区。

### 10. [软] 自拟细节 — pass
素白偏灰石材、铜线袍缘、殿内浮雕式白塔、书册形制均按自拟标注执行，风格协调无穿帮混搭。

### 11. [软] 风格（FH-040） — pass
中世纪暗黑奇幻墨线插画，钢笔交错排线细密，暗调羊皮纸暖赭、可见纸纹做旧；素白袍须为最亮块、铜眼一缕微光点睛；无厚涂/赛璐璐/照片写实感。

---

## 结论

**REJECT。** 唯一 fail 项为第 2 条 [硬]：低头与捧书下沉的姿态修正已生效（头深垂、视线向书、书册合一），但六倍放大下双眼（闭合眼睑+眉弓）仍被完整画出，帽檐停留在发际线而非遮蔽眼带，未满足「眼部任何部分可见即 fail」的物理遮眼要求。次级提示（不否决）：书封嵌眼宜改闭合眼睑造型（partial）、门楣圣徽缺摊开书本半边（partial）。建议下一轮在提示词中显式写明"帽檐压至鼻梁、眼带完全隐入兜帽硬阴影、不画眉与睑"并禁止 closed eyes 表述。
