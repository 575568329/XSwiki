## 逐项判定

### 1. [硬] 无脸铁律 — pass
全覆式封闭头盔，面甲完整无破损露肤；盔眼开缝内为纯暗色空白，未见任何五官、皮肤、眉眼口鼻或人形面孔轮廓。盔后长发（见第 3 条）不构成露脸。

### 2. [硬] 面甲无开缝无发光 — **fail（连续第三轮残留，整改第一优先级）**
发光半项通过：无缝内发光、无橘红光团、无双眼分立光点、无眼形亮斑、无眼球瞳孔。但**开缝本身仍在**：面甲眼位一道清晰的深色横向开缝，右端开口略宽、左端收窄，放大裁片下可见槽口深度与上下缘翻边，为实体开槽而非阴影或排线。清单明载"眼部位置就是面甲光滑的银白表面……出现任何开缝……即 fail"。整改：以光滑银白甲面整体填实眼位，面甲正面只保留棱线、铆钉与锻打磨痕，任何槽状暗线不得残留。

### 3. [硬] 银白盔甲与无发外露 — **fail（连续多轮残留）**
主色与包裹达标：全身银白哑光重型板甲、锁甲内衬、无黑金红蓝异色、非布袍皮甲裸身；甲面哑光素面方向正确。但**无发外露不通过**：盔后缘飘出多缕深色人形波浪长发，越过颈后披落左肩方向，发丝分缕清晰、另有碎发勾出盔缘轮廓。整改：整束长发与碎发全部去除，盔后缘直接衔接护颈、锁甲与披风，不得残留任何丝缕状深色笔触。

### 4. [硬] 长剑拄地 — pass
巨大的银灰长剑垂直拄地，剑尖扎入身前崖顶岩石（放大裁片确认尖端入石带落点阴影），双手板甲手合握于柄上、贴住剑首，十字护手在手下、剑尖向下——命中"拄地扶剑首为 pass"；非剑尖指天、非单手斜持扛肩；剑身宽厚素净，仅晨光暖金反照，无光斑、火花、缠绕光纹、剑气与血迹；非斧锤镰戟等其他武器。

### 5. [硬] 场景要素 — pass
黎明高崖：人物立于崖顶岩石边缘，天际一轮初升朝阳低悬金橘云霞间，银甲表面有初阳般柔和漫射的暖金光辉；右下低坡一具单膝跪地合掌膜拜的逆光纯黑剪影——低头合十、无面部细节、体量显著小于主体，不争夺视觉中心；无麦田麦穗果实等丰收意象。小提示（不扣分）：跪拜者位于近景低坡而非崖下远坡、体格近常人而非巨人。

### 6. [硬] 体量与气质 — pass
高大魁伟、肩宽背阔、甲裙披风层叠，拄剑静立，有神祇的静穆压迫感；未画成常人体格或瘦削少年，也未夸张为山岳级。

### 7. [硬] 全局负面 — pass
- 全画（含甲面）放大检查**无文字、题字、碑铭、印章、徽记符号与可辨图形**；十字护手中央一枚素净镂空小饰形属常规剑装装饰，不构成可辨徽记。
- 无火焰明火烛火、无剑气闪电能量特效；无血迹、骷髅、白骨；无三叉戟、黑镰、繁星长裙、藤蔓婴儿、太阳金球白袍等其他神祇标志物（天际朝阳为场景所需光源，不属标志物）。
- 全画唯一点睛亮色为天际初阳金橘晨光，其余为银白、铁灰、深褐与暖赭层次，无第二处鲜艳异色亮斑。

### 8. [硬] 构图完整与静态 — partial
头顶至双脚完整入画、无裁切，全身约占画高三分之二（约 0.68），一帧静止定格、无战斗挥剑、无衣甲剧烈飘动；脚下崖顶岩石向底缘延续约 0.43 身位，仍未满"留出一身位空白"。延续 r3 处理：不计入本轮 reject 主因，下一轮顺带放宽。

### 9. [软] 盔甲形制与甲面素面 — pass（软）
r3 记录的上胸甲 X/十字交叉线纹及沿线铆点在本版已不可辨，现甲面仅余锻痕、排线阴影与甲片接缝，无可辨涡卷/十字/徽记状纹样，"甲面素面"达标；朴素古式板甲形制（横向甲叶、锁甲内衬、层叠甲裙、破旧战披）与自拟推测相符。

### 10. [软] FH-040 风格锚 — pass（软）
精密钢笔交错排线（岩石、披风、甲面阴影均为排线塑形），暗调羊皮纸底色带做旧斑渍，暖赭统调，符合"巨人王庭古史诗抄本插图"观感；非厚涂油画、赛璐璐或照片写实；无牛角铠甲骑士、石阶遗迹残留，无东方水墨写意笔触。

## 结论与整改要点

**REJECT。** r3 的甲面十字线纹已清除（且该条按新清单已降软），拄剑姿势、跪拜剪影、无文字等项稳定达标；但两项最老的硬伤连续多轮残留，按优先级整改：

1. **面甲开缝（第 2 条）**：以光滑银白甲面填实眼位横向开缝，删除槽口与边缘翻边；面甲正面只允许棱线、铆钉与锻打磨痕。
2. **盔后长发（第 3 条）**：整束长发与盔缘碎发全部去除，盔后缘直接衔接护颈/锁甲/披风，不得残留丝缕状深色笔触。
3. （提示，非否决项）脚下岩石留白由约 0.43 身位向一身位靠拢。
