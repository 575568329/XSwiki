## 逐项判定

### 1. [硬] 年龄气质面相 — pass
证据：面部放大可见眉骨高耸压眼、眼窝深陷带横纹，法令纹深刻两道直落嘴角，额头有抬头纹与川字纹，下颌胡茬明显；目测约 35-40 岁，眼神锐利带风霜。无美型平滑青年脸迹象，亦无老年衰迈。殖民地混血面相可采。

### 2. [硬] 古铜肤色 + 风霜粗糙质感 — pass（本轮复核重点）
证据：原分辨率面部放大显示额、颊、鼻梁为暖调古铜棕色，覆以钢笔交叉排线形成粗粝皮肤纹理，颧骨与眼下周有风霜刻痕；眼周蓝灰为暴雨冷光阴影而非白皙底色。右手（掌心托雪）与左手（垂于体侧）放大后均为明确古铜棕色，手背青筋、指节褶皱与排线粗糙质感清晰。面部与手背均无白皙/苍白/浅肤色区域。上一轮"面部白皙"问题已修复。

### 3. [硬] 深蓝近黑乱发 — pass
证据：发丝粗硬凌乱、如海草般四散披垂至胸肩，数缕垂落额前；受光发丝呈明显蓝调中明度，暗部近黑。非柔顺梳理发型，无棕/灰白/亮蓝挑染，非纯黑无蓝调。

### 4. [硬] 闪电纹长袍 — pass
证据：袍为深蓝近黑垂至脚踝长袍；胸前、袖面与裙摆多处暗金色锯齿状分叉裂纹绣纹，闪电特征清晰可辨。领缘与下摆另有卷曲线条镶边，属装饰性缠枝纹而非明确海浪符号图标，主纹样判定仍为闪电，不触发 fail。袍底色深、无白/红浅亮色。

### 5. [硬] 掌心雪 — pass
证据：右手抬至胸前、掌心向上，掌心上方悬浮一片六角分支结构清晰的晶莹雪花，带冷白微光与少量细碎光点；未画成冰雪暴团/冰锥等夸张特效。

### 6. [硬] 场景要素 — pass
证据：古老多桅帆船甲板，两侧桅杆、横桁、帆影与侧支索/踏脚绳梯齐备；人物身后右侧木质船舵在位且无人操控；两舷外巨浪翻涌带白浪头；全画面斜向雨丝密集，乌云翻涌。静态定格，无其他人物。

### 7. [硬] 无兵器与无异化 — pass
证据：全画面未发现刀剑、匕首、枪械、权杖等兵器；皮肤无鱼鳞/鳞片纹路；头发为披垂乱发，无根根竖起的粗壮异化形态。

### 8. [硬] 天空无落雷 — pass
证据：天空仅见翻涌雨云、沉暗天色与云隙透出的暖金天光（为光感而非劈落闪电），全画面未见任何闪电落雷；闪电纹样仅出现在长袍绣纹上。

### 9. [硬] 全身完整 — **fail**
证据：对画面底部（原图 y 约 1770-1938 区域）放大并增亮复核：长袍裙摆布料连同金色绣纹一直延伸至画面底缘、被下边框直接裁断，全图内不见袍摆收口轮廓，更不见双脚；人物脚下无任何甲板留白，"一身位空白"不存在。实测人物从发顶（约 y 227 原图坐标）到袍底占画面高度约 85-88%，远超"约占三分之二"。多个子条件（完整入画无裁切/双脚不触底缘/脚下甲板留白/全身约 2/3）同时不满足，判 fail。

### 10. [硬] 无文字与禁入元素 — pass
证据：全图及帆面、船身、衣饰局部放大均未发现文字、题字、印章；袍面金纹为纹样装饰非徽记，无圆形徽章；无铠甲、牛角头盔、骑士等参考图元素。

### 11. [软] FH-040 风格锚 — pass
证据：全图为精密钢笔交错排线 + 暗调羊皮纸底色 + 暖赭色调 + 暗金点睛，氛围静谧压迫；无厚涂油画感/赛璐璐感/照片写实感。

### 12. [软] 眼眸 — pass（附提示）
证据：瞳色为清晰蓝色，非深红（不触发 fail）、非纯黑（不触发 partial）。提示：虹膜亮度偏高、呈明亮蓝，较"深色偏蓝"的目标描述更亮，属软性偏差，不否决。
