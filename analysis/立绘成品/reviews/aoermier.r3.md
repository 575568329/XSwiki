# 奥尔米尔 r3 盲审评审

- 图片：analysis/立绘成品/aoermier-aoermier_nowm.jpg
- 清单：analysis/立绘成品/prompts/aoermier.checklist.md
- 规则：[硬] 条款任一 fail 即整图 reject；[软] 仅作质量提示。

## 逐项判定

| 项 | 级 | 判定 | 画面证据 |
|---|---|---|---|
| 1 体量与灰蓝肤 | 硬 | pass | 巨人规格成立：人物远高于前景两块石碑（石碑仅及小腿/膝高），环绕枯树明显低矮；裸露头颈与手部皮肤为灰蓝色，非肉色。 |
| 2 银灰血斑旧甲 | 硬 | pass | 全身银灰盔甲，甲面斑驳、划痕与黯淡氧化层可见，肩胸臂散布大块暗红似血斑块，非崭新抛光。 |
| 3 头部双重红线（光团吞面） | 硬 | **fail** | 头部为实色灰蓝头颅，**完整实体面孔清晰刻画**：双眼、眉、鼻、口、下颌须髯阴影俱全——触发"出现实体面孔、眼睛……任一刻画即整图 reject"；且面部位置并无"车轮大小的落日光团吞没全脸"，取而代之的是悬于头顶后方的**实体轮形光环**（辐条车轮＋火舌状光芒）——r1"实色头颅＋发光开口"败点不仅未修正，本轮修订目标（光团完全取代整脸、盔帽银灰素面）亦未落实（头顶无盔帽，为裸露实体头颅）。 |
| 4 虚幻映射质感 | 硬 | **fail** | 身影轮廓为清晰锐利的实体勾线，盔甲、破披风均以写实衣纹肌理与精密细节刻画，边缘无晕散虚化、未与暮光交融——触发"画出清晰锐利的实体剪影、写实衣纹肌理即 fail"。 |
| 5 虚幻黄昏巨剑拄地静态 | 硬 | pass | 巨剑倒插身前地面，剑身由橘红光芒凝成、呈半透明光质，双手交叠拄于柄首；全画静态定格，无捶地、拔剑、震裂等动态。 |
| 6 衰败森林+树木弯折 | 硬 | pass | 黄昏枯败森林、橘红余晖自枝隙交织，灰褐枯树；左右树干枝条多向巨人方向弯折倾斜；巨人脚前两块灰白斑驳石碑。 |
| 7 无伪文字（含石碑素净） | 硬 | pass | 两块石碑素净平整，无十字浮雕、无成行刻痕、无可辨刻字；全画无文字、符文、徽记。 |
| 8 无火焰灯体 | 硬 | **fail** | 头顶轮形光环轮缘呈明显火舌状燃烧形态、全画漂浮火星状橘红光点，读作"燃烧元素"而非"凝固的落日余晖"；另按本条"面部位光团被画成……燃烧的火即 fail"之延展，头顶燃烧火轮同样踩线。 |
| 9 无他人 | 硬 | pass | 画面仅巨人一道身影，无信徒、无骑士、无第二人影。 |
| 10 构图完整与静态 | 硬 | pass | 头顶光环与双足盔靴完整入画，双足踏于枯败地面、不触底缘且脚下留白；主体约占画面七成、居中偏上、仰视；静态定格。 |
| 11 FH-040 风格锚 | 软 | pass | 钢笔交错排线、羊皮纸暖赭底色、做旧纸纹质感成立。 |
| 12 神话映射史诗感 | 软 | pass | 落日四色沉郁和谐，仰视压迫感与石像式静默达标。 |

## 总判定：**REJECT**

[硬] 第 3 条 fail：实色头颅上完整画出双眼鼻口等面孔细节，头顶悬实体燃烧轮形光环而非"车轮大小落日光团吞没全脸"，r1 败点原样延续、r3 修订目标（光团取代整脸＋银灰素面盔帽）双双落空；第 4 条 fail：轮廓锐利实体勾线＋写实甲衣肌理，无晕散虚化；第 8 条 fail：头顶火轮＋火星漂浮构成燃烧元素意象。
