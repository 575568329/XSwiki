# 欲望母树 立绘 r1 首审（盲审 · 绯月与滋长剪影）

- 图片：analysis/立绘成品/yuwangmushu-yuwangmushu_nowm.jpg
- 清单：analysis/立绘成品/prompts/yuwangmushu.checklist.md
- 判定规则：[硬] 任一 fail 即 reject；[软] 仅提示。
- 评审方式：整图判读 + 月面、右侧藤蔓、右下荆棘疑点、左下植物群四处局部放大复核。

## 逐项判定

1. [硬] 画面主体判定 — **pass**。一轮饱满浑圆的绯色圆月，通体绯红、月色浓郁胜血月，位于画面中央偏上、占主要视觉比重；月面放大复核为环形山/月海肌理，非灰白月、非月牙、无缺月，**全画仅此一月、无第二个月亮**。
2. [硬] 滋长剪影群像 — **pass**。月光所及处植物蓬勃：草叶向上伸展、大小蘑菇群破土错落（伞盖形态丰富）、卷须藤蔓攀卷舒展，呈鲜嫩新生、疯长滋长之势；非枯草干花、非稀疏萎缩，剪影群像完整。
3. [硬] 夜空场景 — **pass**。背景为漆黑夜空与疏落冷白星点，照明仅绯红月光与星点冷辉；无室内屋顶、无房屋墙壁、无地平线建筑轮廓，无火把、灯笼、烛火等任何火焰灯体光源。
4. [硬] 无怪树本体 — **pass**。无怪树、血肉之树、褐绿树瘤、食人巨花、白皙巨躯；右侧缠绕粗藤为藤本卷须意象，不构成树本体。
5. [硬] 无人形无面孔 — **partial**。放大复核全画植物：**无人形、无恩赐小人、无人体部位嵌入或缠绕、无面孔五官与器官细节**——fail 触发项全部不成立；但植物以暖赭色墨线在黑底上作逆光式绘制（内部保留钢笔排线与叶脉细节），并非清单口径的"纯墨色剪影"，呈现手法与文字规格存在偏差，计 partial。
6. [硬] 无信徒房屋 — **pass**。无信徒与任何人物，无房屋、室内、墙壁、祭坛等任何建筑元素。
7. [硬] 无玫瑰荆棘 — **pass**。右缘与右下藤蔓放大复核：卷须光滑缠绕，**无玫瑰花朵、无尖刺荆棘**（远看的细小突起经放大确认为叶芽与茎节，非尖刺）。
8. [硬] 无伪文字 — **pass**。月面为自然环形山肌理、星点为圆点、右下墨点飞溅属做旧纸纹；全画无文字、符文、题字、印章、徽记。
9. [硬] 构图完整 — **pass**。绯色圆月浑圆完整入画、无明显裁切；植物剪影铺陈于画面下方约三分之一与两侧边缘，克制不遮挡月轮；四周留出夜空呼吸空间，重心沉稳庄重。
10. [软] 风格锚（FH-040） — **pass**。中世纪暗黑奇幻墨线插画：钢笔交错排线细密、暗调羊皮纸暖赭色调、纸纹质感与留白兼备，版画典籍插图感强；无日式赛璐璐/厚涂油画/照片写实偏向。
11. [软] 诡异唯美滋长感 — **pass**。静态古老异象式构图，庄严静谧；诡异感来自饱和绯红月色与静谧疯长的生命力，无血腥惊吓元素，亦无轻快明丽化。

## 总判定

**PASS**（无 [硬] fail；含 1 项 partial 提示）。

非 pass 项汇总：
- 条款 5 [硬] partial — 植物为暖赭色墨线逆光剪影（带内部排线细节），非清单口径"纯墨色剪影"；无人形/面孔/器官等 fail 触发项，仅呈现手法偏差，后续可倾向压暗植物色阶贴近纯剪影。
