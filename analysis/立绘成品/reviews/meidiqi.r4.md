# 梅迪奇 · r4 盲审评审（meidiqi-meidiqi_nowm.jpg）

- 评审性质：独立盲审（与生成过程无关联），逐项对照 prompts/meidiqi.checklist.md
- 判定规则：[硬] 任一 fail 即整图 reject；[软] 仅提示
- 取证方式：整图通读 + 面部 4x/8x 局部放大（眉心、眼、发髻）、地面 1x 裁片（查石阶）

## 总判定：REJECT（硬3、硬8 两处 fail；硬9 同源连带）

r1-r3 败点"红发披散过肩"本轮确认修复（头顶偏后绾髻成立），但出现两处新的硬性败因：眉心血印缺失、双眼红光触发附身态红线。

## 逐项评审

1. [硬] 年轻英俊与苍白脸 — **pass**
   面容年轻、轮廓锋利、无胡须，肤色苍白欠血色，无苍老/棕红健康感。

2. [硬] 火红战士发髻 — **pass**（贴线，附警示）
   头顶偏后绾有明确发髻，髻形可见、火红色纯正；头发整体束起，不存在"披散"。fail 口径为"披散**且**发梢过肩"，本图不满足"披散"，不构成 fail。
   警示：两侧垂落鬓发明显长于"颊侧一缕短发"规格——观者左侧一缕沿颈侧垂至领口/肩头水平，发梢接近但未见明确搭过肩头；黑色皮绳在髻根不清晰可辨。r5 起该条款降软后此条即不再是风险点，本轮按 pass 锚（髻成立）放行并留痕。

3. [硬] 眉心旌旗状血色印记 — **fail**
   8x 眉心放大：眉间与前额正中无任何暗红旗帜剪影，仅有额上方一粒小黑痣样斑点与眉间极淡的川字纹阴影、一缕搭额发丝。四轮复现锚点缺失，硬性 fail → 整图 reject。

4. [硬] 黑色染血盔甲 — **pass**
   哑光黑甲覆盖躯干四肢，肩甲、胸甲、甲裙均有暗红陈血泼溅斑，色沉如干涸泼墨、非鲜亮新漆；无金色纹饰、兽首、牛角。

5. [硬] 双臂抱胸嚣张站姿 — **pass**
   双臂环抱胸前，下巴微抬、嘴角讥诮上扬，站姿挺拔静立。

6. [硬] 山巅余烬场景 — **pass**
   海边坍塌山峰之巅，立于碎石巨岩，四周巨石散落，身后天际暗红橘赭余烬微光沉沉晕染，非燃烧火海/云上飞焰。
   石阶复核：腿部后方水平板状岩层边缘破碎不规则，读作天然坍塌岩台/乱石，非人工凿刻台阶，无 FH-040 石阶回潮。

7. [硬] 腐烂痕迹仅隐约 — **pass**
   双眼下方有淡暗色条痕延至颊部，隐约克制，非溃烂见骨；亦非通体无痕。

8. [硬] 无附身态元素 — **fail**
   8x 眼部放大：双眼虹膜为鲜红发光态（红色有明显光晕溢出），构成条款明列的"眼中发光"，触发附身态甄别红线 → 整图 reject。
   其余附身态元素均未出现：无黑底红纹袍/兜帽/袍服，无两颊裂嘴/缝合痕，无翅/光环，无单片眼镜。

9. [硬] 全局负面 — **fail**（与硬8同源）
   条款要求全画唯一点睛亮色为"火红头发＋天际余烬暗橘呼应"；双眼红光构成额外鲜艳亮色点，违反该子句。
   其余子句全部通过：无文字/题字/印章/徽记（眉心、甲面均无字）；无火焰/火苗/火星（天际为余烬残光）；无第二人影、无乌鸦；无卷烟/皇冠/卡牌；无牛角铠甲/石阶残留。

10. [硬] 构图完整与静态 — **pass**
    全身完整入画，头顶与双脚清晰，双脚不触底缘、脚下碎石留白；静态定格，无衣甲飘飞、发丝狂舞。

11. [软] FH-040 风格锚 — pass
    钢笔排线细密、羊皮纸暖赭底、做旧纸纹，符合古典籍插图质感；无油画厚涂/赛璐璐/照片写实漂移。

12. [软] 气质锚 — pass
    抱胸＋讥诮笑，嚣张张扬、战意外露，压迫感来自气场而非阴森。

## 结论
**REJECT**。败因清单（供下轮修图）：
1. 补眉心旌旗状暗红血印（当前完全缺失）——最高优先级，四轮复现锚点。
2. 双眼去红光：改普通深色/暗瞳或至少去除发光光晕，消除"眼中发光"附身态嫌疑及额外亮色点。
3. 发髻 pass 但贴线：下一轮若再生成，可顺带收紧两侧鬓发长度（现垂至领口/肩头水平），规避口径争议。
