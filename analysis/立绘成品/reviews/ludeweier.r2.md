## 逐项判定

| 项 | 级 | 判定 | 画面证据 |
|---|---|---|---|
| 1 三角帽骷髅纹样+羽饰 | 硬 | pass | 黑色三角帽帽身绘白色骷髅交叉骨平面纹样（非实体骷髅、非文字/字母），帽侧插深色羽饰。 |
| 2 银白面具+眼洞苍白火焰 | 硬 | pass | 银白面具覆全脸、无真实五官外露；双眼洞各燃一团冷白偏灰蓝苍白火焰（r1 橙黄暖色已修正），两团俱在。 |
| 3 棕色短外套只到腰胯 | 硬 | **fail** | 棕色外套仍为长摆大衣剪裁，两侧下摆自腰胯继续下垂至大腿中段、接近膝部（约画面 78–83% 高度处），明显长过大腿——"只到腰胯"红线未修正（r1 败点原样保留）。 |
| 4 白紧身裤+牛皮腰带+细刺剑 | 硬 | pass | 白色紧身裤在画可见，腰间牛皮色腰带束裤并附斜挎背带；手持通体铁黑素面细直刺剑，非弯刀、无金银饰柄。 |
| 5 夜晚甲板场景 | 硬 | partial | 夜晚甲板、阴绿巨帆船、右舷火炮、黑沉海面俱在；但惨白主帆所绘为黑色鸢尾（fleur-de-lis）纹章花样，非清单要求的"漆黑郁金香"图案——纹样物种错位（未触及本条枚举的场景型 fail 触发器，故记 partial）。 |
| 6 亡灵船员仅剪影 | 硬 | pass | 远处甲板数个模糊暗影人形剪影，无面孔、无白骨细节；左下岸边小团黑影亦无清晰五官；无清晰第二人物。 |
| 7 无摘面具与异变态 | 硬 | pass | 面具全程覆脸；无缺血肉、枯脸、血红火焰眼等任何异变元素。 |
| 8 无伪文字 | 硬 | pass | 全画无可辨识文字、字母、数字、印章；帽上骷髅与帆上花样均为纯图案。 |
| 9 无火焰灯体/舷窗熄灭 | 硬 | pass | 未见灯笼、火把、烛火等燃烧光源；背景船楼为深色剪影，舷窗呈熄灭暗点，无暖黄透光（r1 舷窗暖光已修正）；唯一光效为眼洞苍白火焰（许可例外）。 |
| 10 构图完整：双脚踏甲板不触底缘 | 硬 | **fail** | 双脚与黑色长靴完全不可见，白色裤腿自膝下被画面底缘直接裁切，脚前无甲板留白——"双脚裁切即 fail"红线再次触发（r1 败点未修正）；头顶三角帽完整未裁。 |
| 11 FH-040 风格锚 | 软 | pass | 钢笔交错排线、羊皮纸暖赭底色、做旧纸纹质感成立。 |

## 总判定：**REJECT**

[硬] 第 3 条 fail（外套仍为长摆、超腰胯至大腿近膝）＋第 10 条 fail（双脚长靴被底缘裁切、未踏甲板）。r1 四败点中"眼洞橙黄""舷窗暖光"两点已修正，但"外套长款""双脚裁切"两点在 r2 中原样未动。另有第 5 条 partial：主帆纹样画成黑色鸢尾（fleur-de-lis）而非漆黑郁金香。
