## 统一锚点（各年龄不变）

- **面容**：五官端正、颇为顺眼，但"并不算出色"——耐看型而非惊艳型（#690/#698/#1400/#1423）；眉毛略长（#698/#1050）；黑发（#330）；皮肤白净（#687"皮肤也越显白净"、#864"洁白如玉的手掌"）
- **眸子**：常态为深色/灰瞳（#474"灰瞳"；幼年"透亮的眸子" #307）；**施法或情绪波动时泛金**——浅金→淡金→白金（#687/#688/#690/#811/#863/#1070），用毕"退回寻常色彩"（#811）。勿把淡金画成常态
- **眉心**：紫府后多一点白金色圆点天光，"非画非点，明晃晃如同天光照耀"（#687），此后"眉心点光"为常态标志（#1059/#1400）
- **气质**：温和为本色（#360 兄弟对比"李曦明温和"；#698"温和的笑意"；#1302"笑容平和，极为亲善"），成年叠加紫府威严——"凛然不可侵犯"（#1050）、无形威压（#994）；帝裔出身、举止正派（#893）
- **声音**：明朗清和（#690）

### 成年 · 紫府初期（#687-#900）★白金道袍定型（场景生图默认取此段）
- 突破瞬间：金白色道袍显得普通，"他越发年轻了，皮肤也越显白净"，眉心多出白金圆点天光；脑后彩色光晕，明阳神通之彩披身冲天高九尺有余（#687）
- **标准着装：白金道袍/白金道衣**——"一身着白金道袍的男子"（#690）、"身着白金道袍，眉心光辉熠熠，身上神通的彩光升腾，太虚之中负手而立"（#717）、"白金色道衣的真人……眉心点光"（#1059，同款 #970/#1002/#1085/#1090）。**全书 0 处"紫袍"——紫府≠紫袍，勿默认紫色**
- 外貌定妆：五官端正并不算出色、淡金色眼睛、眉心一点刺目天光（#690）；"脸庞五官端正，眉毛略长，浅金色的眸子……敛色而笑"（#698 萧元思所见，出关时天光未敛）
- 眸色变化谱：瞳孔亮红一闪→淡金→退回寻常（#811）；斗法时"两眼渐渐转化为白金色"（#863）；"那双金瞳"（#1070）
- 神通外观：驾神通浮湖面、金光自彩云显露（#690）；身披天光坐白阶（#733）；衣袍上天光、明阳神通痕迹（#794）；"驾彩云御天光的威风"湖上人尽皆知（#873）
- 神态：宣告证道时声波"明朗清和"（#690）；"昭景意气风发，望着如同三百余年前的自己"（#715 长奚语）；真人端坐，"哪怕不开口说话，亦有一股无形威压在殿中弥漫"（#994）
- 易容：对外行走常"换了张面孔""没有用真面目示人"（#777/#794）——生图注意：正式场合才是真容
- 兵器法宝：神通『谒天门』（亮白天门、金甲金衣）、明阳紫焰（外紫内金）、【上曜伏光】（眉心喷涌）、眉心天光/大璺金瞳、六合之光、【赶山玄幕】【艮土灵纳】（保命，#864）；坐遁【赶山赴海虎】艮虎（玄岳所留保命灵器，#759）；【冲阳辖星宝盘】银盘（奎祈寄存，#760/#864/#879）；【示川】青黄二色玉尺，自行挂在腰间（#886/#887）

### 紫府中后期（#1050-#1300）★威严定型
- 外貌变化（核心）："如今的李曦明竟然有些与记忆中的不同了，他的五官有了细微的变化……双眉略长，鼻梁更加挺拔，明明还是那个模样，却有了极为鲜明的威严之气"（#1050）；同场定妆："白金色道衣的中年男子！此人长眉舒缓，眼型威严，眉心金光灼灼，整张面孔线条自然，明明神情随意，却透着股凛然不可侵犯的威严"（#1050）

## 辨伪与注意

1. **"憨厚" only 童年**：#307"身体康健，憨厚老实"是李渊平看一岁婴儿；卡片 persona"外表憨厚"同源。成年后旁人观感是"平和亲善+威严"（#1302/#1050），**生图禁用憨厚脸**。
2. **同名辨伪**：书中另有听雷岛祖师"李曦明"（七百多年前人物，雷法与魔功合为一体，坐骑【坎宿蟒】，#560/#588 一带），与本主角毫无关系，检索时已剔除。
3. **紫袍误区**：全书他的着装 0 处"紫袍"，标志服色是**白金道袍**（白/金白色系），配眉心天光与金眸。
4. **乱码章**：#471/#516/#519/#550/#551/#566/#616/#631 等章正文存在"是↔没、上↔下、他↔我"同音讹误，引用均已核对上下文并择可靠短句；#550/#616 两条存疑项已降级为待核。
5. **眸色**：淡金/浅金是神通态；常态灰瞳/深色（#474），幼年"透亮"（#307）。仅 #698 出关时被师尊见"浅金色的眸子"（天光未敛）。
